# JSON Usage Tutorial

## Basic Formatting

The JSON formatter tool helps you organize and beautify JSON data, making it more readable and understandable.

### Step 1: Input JSON Data

Paste your JSON data in the left input box, for example:

```json
{"name":"ToolHub","version":"1.0.0","features":["format","encrypt","convert"],"config":{"theme":"dark","language":"en"}}
```

### Step 2: Choose Formatting Options

- **Indent Size**: Choose 2 spaces or 4 spaces indentation
- **Sort Keys**: Optionally sort object keys alphabetically
- **Compressed Format**: Remove all spaces and line breaks

### Step 3: Format Result

Click the "Format" button, and the formatted result will appear on the right:

```json
{
  "name": "ToolHub",
  "version": "1.0.0",
  "features": [
    "format",
    "encrypt",
    "convert"
  ],
  "config": {
    "theme": "dark",
    "language": "en"
  }
}
```

## Advanced Features

### Syntax Validation

The tool automatically checks for JSON syntax errors and displays specific error messages when issues are found.

### Copy Function

Click the "Copy" button to quickly copy the formatted JSON to your clipboard.

### Clear Function

Use the "Clear" button to quickly clear both input and output areas.
