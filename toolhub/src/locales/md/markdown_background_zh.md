# Markdown技术背景

## 概述

Markdown是一种轻量级标记语言，专为易于阅读和编写而设计。由John Gruber于2004年创建，它使用纯文本格式化语法，可以转换为HTML和其他格式。Markdown强调可读性和简洁性，同时提供强大的格式化功能。

## 核心原则

### 纯文本哲学
- **人类可读**：源代码无需处理即可阅读
- **可移植**：跨平台和应用程序工作
- **面向未来**：不绑定特定软件或格式
- **最小语法**：简单直观的格式化规则

### 设计目标
- **易学**：模仿自然写作的直观语法
- **快速编写**：最小的标记开销
- **清晰输出**：生成干净、语义化的HTML
- **可扩展**：支持额外功能和扩展

## 基本语法结构

### 文本格式化
- **粗体**：`**文本**` 或 `__文本__`
- **斜体**：`*文本*` 或 `_文本_`
- **删除线**：`~~文本~~`
- **代码**：`` `代码` ``（行内）或代码块

### 标题
- **H1**：`# 标题`
- **H2**：`## 标题`
- **H3**：`### 标题`
- **H4-H6**：额外的 `#` 符号

### 列表
- **无序**：`- 项目` 或 `* 项目`
- **有序**：`1. 项目`
- **嵌套**：缩进用于子列表

### 链接和图片
- **链接**：`[文本](url)`
- **图片**：`![alt](url)`
- **引用链接**：`[文本][ref]` 配合 `[ref]: url`

### 块级元素
- **段落**：用空行分隔
- **代码块**：缩进或用 ``` 包围
- **引用**：`> 文本`
- **水平线**：`---` 或 `***`

## 高级功能

### 表格
```
| 表头 | 表头 |
|------|------|
| 单元格 | 单元格 |
```

### 代码块
- **围栏式**：```语言
- **缩进式**：4个空格
- **语法高亮**：语言规范

### 任务列表
- `- [x] 已完成任务`
- `- [ ] 待完成任务`

### 转义
- **反斜杠**：`\*字面星号\*`
- **代码跨度**：`` `字面反引号` ``

### CommonMark
