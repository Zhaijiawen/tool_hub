# 文本反转 — 使用示例

## 检测回文字符串

字符反转让你一眼就能判断回文。如果翻转后跟原文一模一样，那就是回文。

**输入：** `racecar`
**反转后：** `racecar`
结论：是回文。

**输入：** `hello`
**反转后：** `olleh`
结论：不是回文——翻转后肉眼可见地不同。

正经的回文检测通常要先去掉空格和标点。`A man, a plan, a canal: Panama` 逐字符反转后是 `amanaP :lanac a ,nalp a ,nam A`——对不上。但去掉非字母字符并统一小写后，得到 `amanaplanacanalpanama`，正是自己的反转。反转工具给你原始翻转结果，归一化是你自己的事。

## 姓名顺序翻转

这是单词反转最实用的场景。把一列全名丢进去，立刻得到姓在前的结果。

**输入：**
```
张三 李四
王五 赵六
孙七 周八
```
**反转单词输出：**
```
李四 张三
赵六 王五
周八 孙七
```

每行独立处理，所以多行姓名列表干净利落。不需要公式、不需要脚本——粘贴、点击、复制。

## 让最近日志条目排在最前面

日志文件总是最新条目在最底下。行反转把最新数据放到最上面。

**输入：**
```
2024-01-01 服务器启动
2024-01-02 收到请求
2024-01-03 发生错误
```
**反转行输出：**
```
2024-01-03 发生错误
2024-01-02 收到请求
2024-01-01 服务器启动
```

这在只能用静态快照的工具里看日志时确实有用。不用每次都滚到底部，反转行之后就从上往下按时间顺序读了。处理超大日志时，只反转最后 N 行比加载整个文件快得多——用 `tail -n 50 log.txt` 然后粘贴再反转。

## 演示用的简单混淆

需要在截图中展示「真实」数据但又不想暴露实际值？字符反转是让文本一眼看不出来的快速土办法。

**输入：** `zhangsan@company.com`
**反转后：** `moc.ynapmoc@nasgnahz`

显然这不叫加密——谁都能再反转回来。但截图、演示、分享调试输出不想露出真实值时，这比手动把每个字符换成 `x` 快多了。

## 反转代码片段（玩一下）

字符反转代码会产生一种看起来隐约还像代码的奇妙效果。

**输入：**
```
function hello() {
  console.log("world");
}
```
**反转后：**
```
}
;)dlrow"(gol.elosnoc  
{ )(olleh noitcnuf
```

同一段代码用单词反转看起来稍微能读一点但作为代码同样没用——`} { )"world"(log.console hello() function`——这也算是验证不同反转模式确实在工作的一种有趣方式。
