# 文本反转 — 使用示例

## 回文检测

**输入：** `racecar`
**反转后：** `racecar`
→ 是回文字符串！

**输入：** `hello`
**反转后：** `olleh`
→ 不是回文字符串。

## 反转句子单词

**输入：**
```
JavaScript is awesome
```
**反转单词输出：**
```
awesome is JavaScript
```

## 反转日志行顺序

**输入：**
```
2024-01-01 服务器启动
2024-01-02 收到请求
2024-01-03 发生错误
```

```
