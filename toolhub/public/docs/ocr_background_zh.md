# 图片文字识别 (OCR) — 技术背景

这个工具用 **Tesseract.js**（Tesseract OCR 引擎的 WASM 版）在浏览器里识别图片里的文字，全程本地、不上传。

## 怎么用

1. 上传一张图片（PNG / JPEG / WebP / GIF / BMP / TIFF 等）。
2. 选识别语言（可多选，比如中英混排选 `chi_sim` + `eng`）。
3. 选页面分割模式（PSM，控制怎么理解版面：单行、单词、整块、自动等）。
4. 点「识别」，结果以可编辑文本显示，可复制或下载 `.txt`。

## 语言包

每种语言对应一个训练数据文件（`.traineddata.gz`），首次选某语言时会下载并缓存。语言越多，下载越大、识别越慢。

## 进度与信心

识别分三个阶段，进度条会随之走：

- **下载引擎/语言包**（0-50%）
- **初始化**（50-85%）
- **识别文字**（85-100%）

结果区显示：识别出的字符数、**置信度**（越高越准，≥80% 绿、60-80% 黄、<60% 红）、耗时。

## 限制

- 手写、艺术字、严重倾斜或低分辨率图片识别率会下降。
- 引擎和语言包都是 WASM，首次使用需下载，带进度条、可取消。
- 图片不上传，适合含敏感信息的截图。
