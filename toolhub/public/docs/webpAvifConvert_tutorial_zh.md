# WebP / AVIF 转换 — 使用教程

1. 上传一张图片（任意常见格式）。工具显示预览、原始大小和尺寸。
2. 选目标格式：**WebP** 或 **AVIF**。
3. 调参数：
   - WebP：质量滑块，或开关「无损」。
   - AVIF：质量滑块、速度滑块，或开关「无损」。
4. 点「转换」。首次用某格式会下载对应 WASM 编码器（带进度、可取消）。
5. 完成后显示原始大小、结果大小、体积变化百分比和耗时，可直接预览结果并下载。

> 体积变化：正数表示省了，负数表示变大了（比如把已经很小的图转成更慢的 AVIF 无损可能反而变大）。

## 小提示

- 网页图片优先 **WebP**，兼容好、体积小。
- 追求极致压缩率且目标浏览器够新，用 **AVIF**（质量 50 左右通常够）。
- AVIF 速度档调高（如 8-10）能明显加快，体积只略增。
