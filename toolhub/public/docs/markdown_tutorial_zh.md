# Markdown 转换器 — 使用教程

## 使用步骤

### 第一步：编写或粘贴 Markdown
在左侧编辑器面板中输入或粘贴 Markdown 文本。

### 第二步：预览渲染效果
右侧面板实时显示 HTML 预览，随输入即时更新。

### 第三步：复制或导出
- 点击**复制 HTML** 复制渲染后的 HTML 源码
- 点击**复制 Markdown** 复制原始 Markdown 文本

## Markdown 快速参考

| 元素 | 语法 | 效果 |
|---|---|---|
| 粗体 | `**文本**` | **文本** |
| 斜体 | `_文本_` | *文本* |
| 一级标题 | `# 标题` | 大标题 |
| 二级标题 | `## 标题` | 中标题 |
| 链接 | `[文字](url)` | 可点击链接 |
| 图片 | `![alt](src)` | 图片 |
| 行内代码 | `` `代码` `` | `代码` |
| 引用块 | `> 文本` | 缩进引用 |
| 水平线 | `---` | 分隔线 |

## 带语法高亮的代码块

使用三个反引号加语言名称：
    
````markdown
```python
def hello():
    print("你好，世界！")
```
````

## 使用技巧

- 使用 `---` 插入水平分隔线
- 用 2 个空格缩进可嵌套列表
- 使用 `> > 嵌套引用` 表示嵌套引用块
- 大多数 Markdown 渲染器支持 GitHub Flavored Markdown（GFM）——包括表格、任务列表和删除线
