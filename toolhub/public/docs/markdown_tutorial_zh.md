# Markdown 预览 — 使用指南

## 三步上手

在上方输入区粘贴 Markdown 文本，下方实时渲染 HTML 预览——打字即刷新，不用手动触发。

满意了就：

- 点**复制**，把渲染后的 HTML 源码拷贝到剪贴板
- 点**加载示例**，快速体验不同类型的 Markdown 渲染效果

没了。转换全在浏览器里跑，不用装任何东西。

## 速查表

| 想要的效果 | 这么写 | 出来是 |
|---|---|---|
| 粗体 | `**文本**` | **加粗文本** |
| 斜体 | `_文本_` | *倾斜文本* |
| 一级标题 | `# 标题` | 大号标题 |
| 二级标题 | `## 标题` | 中号标题 |
| 三级标题 | `### 标题` | 小号标题 |
| 链接 | `[文字](url)` | 可点击链接 |
| 图片 | `![alt](src)` | 嵌入图片 |
| 行内代码 | `` `代码` `` | `等宽字体` |
| 代码块 | ` ```语言 ` | 带语法高亮的代码区 |
| 引用 | `> 文本` | 缩进引用块 |
| 分隔线 | `---` | 水平分割线 |
| 无序列表 | `- 项目` | 圆点列表 |
| 有序列表 | `1. 项目` | 数字列表 |
| 表格 | `\| 列 \| 列 \|` | HTML 表格 |
| 任务列表 | `- [ ] 任务` | 复选框列表 |

## 带语言标签的代码块

三个反引号加语言标签：

````markdown
```python
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b
```
````

语言标签会保留在输出的 HTML 中（`class="language-python"`），复制出去放到博客或文档站里，配合 highlight.js 就能实现语法高亮。常见标签：`javascript`、`python`、`bash`、`json`、`yaml`、`css`、`html`、`sql`、`java`、`ruby`、`go`、`rust`。

不加语言标签也行，出来就是纯预格式化文本。

## 实用技巧

- `---` 单独一行就是分隔线，长文档里用来切分区段很方便
- 子列表用 2 个空格缩进（嵌套到有序列表里用 3 个空格）
- 不想被解析的内容用反引号包起来：`` `**这不会变粗**` ``
- 主流平台都支持 GFM 表格，README、Issue、PR 里放心用
- 长文档用 `##` 做章节标题，GitHub 上会自动生成锚点链接
- 行末加两个空格相当于 `<br>` 换行，不用另起段落
