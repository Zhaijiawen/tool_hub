# Markdown 格式化器 — 使用指南

## 三步上手

1. 把 Markdown 内容粘贴到编辑器里
2. 点击**格式化**按钮
3. 复制结果，或下载为 `.md` 文件

格式化全在浏览器里完成，不上传任何内容到服务器。

## 格式化具体改了什么

| 你看到的改变 | 例子 |
|---|---|
| 表格对齐 | `\|a\|b\|` → `\| a \| b \|`，分隔行自动补全 |
| 多余空行合并 | 连续 3 个空行变成 1 个 |
| 标题前补空行 | 标题紧贴上文时，自动插入一个空行 |
| 代码块前后留白 | 围栏代码块与相邻文字之间加空行 |

## 实用技巧

- **格式化是幂等的**——连续点两次格式化，结果不变
- 多人协作的文档格式化后统一空行间距，diff 里不会全是无意义的空行改动
- 手工写的表格格式化后分隔符整齐对齐，源码阅读舒适很多
- 点击**下载**直接保存为 `.md` 文件，比手动复制粘贴省一步
- 格式化不改列表符号和段落文字，放心用，不会丢信息
