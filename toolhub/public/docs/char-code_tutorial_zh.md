# 字符编码转换器 -- 使用指南

输入字符看编码，或者反过来：输入码点查字符。双向都能用。

## 正向查询：字符到编码

在输入框输入或粘贴一个字符（或一整个字符串），工具即时显示：

- **十进制** -- Unicode 码点的纯数字形式
- **十六进制** -- 代码里最常用的表示法
- **二进制** -- 最底层的位表示
- **HTML 实体** -- 十进制（`&#65;`）和十六进制（`&#x41;`）两种
- **URL 编码** -- 百分号编码形式
- **八进制** -- 偶尔在遗留系统里用到

多字符字符串会逐个展示每个字符的编码，排查编码问题的时候特别管用。

## 反向查询：编码到字符

输入任意一种格式的码点，工具告诉你对应哪个字符：

| 格式 | 示例 | 结果 |
|---|---|---|
| 十进制 | `65` | `A` |
| 十六进制 | `0x41` 或 `41` | `A` |
| Unicode 表示法 | `U+0041` | `A` |
| HTML 实体 | `&#65;` 或 `&#x41;` | `A` |

## 什么时候用这个工具

- **排查不可见字符**：零宽空格（U+200B）、BOM（U+FEFF）、不间断空格（U+00A0）-- 这些鬼东西经常引发莫名其妙的 bug。把文本扔进来，工具帮你把它们揪出来。
- **编码乱码调试**：看到乱码了？逐字符检查实际码点是什么，跟预期的对照。
- **写涉及 Unicode 的正则**：需要匹配 emoji 或 CJK 字符？先查清楚码点范围。
- **URL 编码**：想知道某个字符的百分号编码形式，查一下就有。
- **HTML 安全**：确认哪些字符需要实体编码，它们的实体形式是什么。
