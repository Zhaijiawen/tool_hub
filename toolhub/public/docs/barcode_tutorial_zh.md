# 条码识别 · 使用教程

## 上传图片识别
1. 打开 **条码识别** 工具，默认在「上传图片」标签。
2. **上传图片**：点击虚线框，或把图片拖拽到框内（支持常见图片格式）。
3. 点击 **「识别」**。识别成功后，下方列出每条结果：码制类型 + 内容文本。
4. 点击结果右侧 **「复制」** 即可复制内容文本。

## 摄像头实时扫描
1. 切到 **「摄像头」** 标签。
2. 点击 **「开启摄像头」**，浏览器会请求摄像头权限，允许后进入实时取景。
3. 将条码对准镜头，扫到即自动解码并追加到结果列表（自动去重）。
4. 点击 **「停止」** 关闭摄像头；点击 **「清空」** 清除结果列表。

## 常见问题
- **识别不到？** 条码可能模糊 / 反光 / 变形，换清晰图或调整角度与光照后重试。
- **摄像头打不开？** 检查浏览器是否已授予摄像头权限，且未被其他程序占用。
- **想要批量？** 可连续扫描，结果会依次追加；也可分别上传多张图片逐个识别。
