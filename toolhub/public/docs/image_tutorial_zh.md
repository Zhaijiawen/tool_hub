# 图像处理 — 使用教程

图像工具让你转换格式、缩放、裁剪、旋转和压缩图片——全在浏览器里完成。每种操作有自己的 Tab，互相独立。

## 格式转换

把图片拖到页面上或者点击浏览选择。工具显示原始格式和文件大小。从下拉菜单选目标格式——JPEG、PNG、WebP、AVIF 或 BMP。对于有损格式（JPEG、WebP、AVIF），质量滑块让你在文件大小和视觉质量之间做取舍。调整时输出实时更新。

点下载保存转换后的图片。文件从头到尾没离开过浏览器。

快速格式建议：
- PNG 转 JPEG：透明区域变白色。如果 PNG 有透明通道，要么选 WebP，要么接受白色背景。
- JPEG 转 PNG：文件会变大，因为 PNG 是无损的。但质量不会提升——JPEG 的瑕疵已经固化在图像里了。
- 任意格式转 WebP/AVIF：压缩率最好，但如果要发给用老软件打开的人，先确认对方能打开。

## 缩放

输入目标像素尺寸。默认锁定宽高比——改宽度高度跟着变。如果需要特定非等比尺寸，解锁就行，但画面会拉伸。

缩放用的是浏览器内置的插值算法。缩小完全没问题。放大会偏软——这是物理限制，没有 AI 超分的话没办法。

常用预设：一半大小、缩略图（150px）、社交媒体尺寸。

## 裁剪

在图像上点击拖拽画出选中矩形。选区实时显示像素坐标和尺寸。如果需要精确裁剪——比如头像要求特定尺寸——可以直接输入像素值。

可用约束模式：
- **自由**：任意宽高比
- **正方形**（1:1）：头像、资料照片、Instagram
- **4:3 / 16:9 / 3:2**：常见照片和视频宽高比
- **自定义**：锁到你指定的任意比例

## 旋转与翻转

以 90 度步进旋转或输入自定义角度。90 度旋转是无损的——像素只是重新排列，不重新采样。自定义角度需要插值，所以非直角旋转会有轻微的质量变化。

水平翻转和垂直翻转可以瞬间完成。水平翻转带文字的照片会把文字镜像——自拍好用（前置摄像头经常镜像预览），文档就别翻。

## 压缩

如果只想缩小文件不改变其他属性，用压缩 Tab。加载任意图像，调质量滑块。工具显示前后对比，包含文件大小和视觉预览，你可以清楚看到正在做什么取舍。

对 JPEG 来说，从质量 100 降到 80 通常文件减半且看不出区别。低于 60 瑕疵开始显现——留意渐变区域的块状感和锐利边缘周围的模糊。
