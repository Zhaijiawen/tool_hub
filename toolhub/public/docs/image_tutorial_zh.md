# 图像处理 — 使用教程

图像相关操作拆成了多个独立工具，每个专注一件事。全在浏览器里完成，图片不出设备。

## 格式转换

上传图片（可多选，最多 10 张），选目标格式——JPEG、PNG 或 GIF。有损格式（JPEG）会出现质量滑块；PNG 和 GIF 是无损的，没有质量选项。需要改尺寸的话，展开「尺寸调整」：按像素或百分比输入宽高，默认锁定宽高比。处理完点「下载全部」。

WebP 和 AVIF 不在这里——那两种现代格式由「WebP / AVIF 转换」工具用 WASM 编码器处理，同画质下体积更小。

快速格式建议：
- PNG 转 JPEG：透明区域变白色。如果 PNG 有透明通道，要么选 WebP，要么接受白色背景。
- JPEG 转 PNG：文件会变大，因为 PNG 是无损的。但质量不会提升——JPEG 的瑕疵已经固化在图像里了。

## WebP / AVIF 转换

上传图片，选 WebP 或 AVIF，调质量滑块，实时预览压缩效果。用 WASM 编码器在本地生成，画质相近时通常比原 JPEG/PNG 小 25-50%。适合给网站减重。

## PNG 优化

只压 PNG，而且是**无损**的——像素一个不变，文件变小。7 档压缩级别，级别越高压得越狠、耗时越长。工具显示前后体积对比。已经优化过的 PNG 收益会很小，这很正常。

## 裁剪

上传图片，在预览区拖拽画出选区，实时显示像素坐标。需要精确尺寸时直接输入宽高值，或用预设宽高比锁定选区。裁完下载。

## 旋转

上传图片，拖角度滑块（0-360°，90 度步进）。左右并排对比原图与旋转结果，满意就下载。自定义角度需要插值，非直角旋转会有轻微质量变化；90 度步进是无损的。

## 水印

上传图片，输入水印文字，调颜色、字号、透明度和旋转角度。适合给样片打标或者加简单的版权声明。水印会画进像素里，不是浮层——下载即固化。

## EXIF

查看照片的完整 EXIF 信息（相机、镜头、曝光参数、GPS 等），也可以一键擦除。分享照片前擦一遍是个好习惯——GPS 坐标和机型信息都属于你大概不想广播的内容。
