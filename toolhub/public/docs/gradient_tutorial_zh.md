# 渐变色生成器 - 使用教程

可视化调 CSS 渐变，实时预览，调好了直接复制 CSS 代码贴到项目里。不用手写，不用脑补。

## 操作流程

### 选渐变类型

顶部三个选项：

- **线性（Linear）** -- 最常用的，颜色沿直线过渡。
- **径向（Radial）** -- 从中心向外扩散，适合聚光灯效果、头像背景。
- **锥形（Conic）** -- 颜色绕中心旋转，做饼图、色轮、环形进度条合适。

### 调颜色

默认两个色点。点一下色块打开取色器选颜色。点 "+" 加色点（最多 5 个），点 "x" 删掉一个。每个色点下面有位置滑块，拖动控制这个颜色在渐变中出现的位置。

一个实用技巧：做多色渐变时注意色点的节奏。均匀分布（0%、33%、66%、100%）看起来平衡；把色点挤在一起会产生突然的颜色跳变，有时候要的就是这个效果。

### 调方向和角度

线性渐变可以转角度旋钮或者点方向预设按钮（向右、向下、对角）。径向渐变可以移动中心点位置。锥形渐变可以调整起始角度。

### 预览和复制

中间的大色块实时更新。调满意了，底部代码区直接复制，贴到你的 CSS 文件里就行。

## 方向预设

| 按钮 | 方向 | CSS |
|------|------|-----|
| -> | 向右 | `to right` |
| v | 向下 | `to bottom` |
| 斜上 | 右上 | `to top right` |
| 斜下 | 右下 | `to bottom right` |

预设覆盖了最常用的角度。特殊角度用滑块微调就行。

## 几种不会翻车的配色

**近似色（安全、专业）：**
- 蓝紫：`#667eea` 到 `#764ba2`
- 橙金：`#f7971e` 到 `#ffd200`
- 青绿：`#11998e` 到 `#38ef7d`

**互补色（抢眼、有冲击力）：**
- 紫到绿：`#8360c3` 到 `#2ebf91`
- 蓝到珊瑚：`#4facfe` 到 `#f77062`

**彩虹（好玩但容易翻车）：**
4-5 个色点按红橙黄绿蓝紫排。锥形渐变上很好看，线性渐变上容易显得乱，悠着点用。

## 输出结果

工具生成标准的 CSS `background` 属性：

```
/* 线性 */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* 径向 */
background: radial-gradient(circle, #f7971e 0%, #ffd200 100%);

/* 多色点 */
background: linear-gradient(to right, #f7971e 0%, #ffd200 33%, #21d4fd 66%, #b721ff 100%);
```

## 实用建议

相信预览而不是数字。47 度好看不代表 45 度也好看 -- 预览骗不了人。喜欢的渐变存成 CSS 自定义属性放到代码片段库里，下个项目直接用，不然每次都重新调。还有一点，一定要在明暗两种模式下都看一眼 -- 浅色背景上很隐晦的渐变，到了暗色模式可能完全看不出来，反之亦然。
