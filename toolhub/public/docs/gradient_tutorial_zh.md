# 渐变色生成器 - 使用教程

## 快速开始

渐变色生成器让你无需手写 CSS 代码，通过可视化界面创建美观的渐变效果，并直接获得可复用的 CSS 代码。

## 基本使用流程

### 步骤 1：选择渐变类型

顶部选择渐变类型：
- **线性（Linear）**：颜色沿直线过渡，最常用
- **径向（Radial）**：从中心向外辐射
- **锥形（Conic）**：颜色围绕中心旋转

### 步骤 2：设置颜色

工具默认提供 2 个色点。点击颜色块打开颜色拾取器，选择你想要的颜色。

- **添加色点**：点击 "+" 按钮，最多支持 5 个
- **删除色点**：点击色点旁的 "×" 按钮
- **调整位置**：拖动滑块调整色点在渐变中的位置百分比

### 步骤 3：调整方向/角度

- **线性渐变**：通过角度旋转器（0°-360°）或方向快捷按钮选择方向
- **径向渐变**：可调整渐变中心位置（水平/垂直百分比）
- **锥形渐变**：可调整起始角度

### 步骤 4：预览效果

中间的大色块实时展示渐变效果，调整参数时即时更新。

### 步骤 5：复制 CSS 代码

底部的代码区域展示最终的 CSS 属性，点击 **"复制"** 按钮一键复制到剪贴板，直接粘贴到你的 CSS 文件中使用。

## 常用方向预设

| 按钮 | 方向 | CSS 等价 |
|------|------|---------|
| → | 向右 | `to right` |
| ↓ | 向下 | `to bottom` |
| ↗ | 右上 | `to top right` |
| ↘ | 右下 | `to bottom right` |

## 颜色选择技巧

### 同色系渐变（推荐新手）
选择相近的颜色，比如浅蓝→深蓝，视觉效果自然和谐。

示例色组：
- 蓝紫系：`#667eea` → `#764ba2`
- 橙红系：`#f7971e` → `#ffd200`
- 青绿系：`#11998e` → `#38ef7d`

### 对比色渐变（活力感）
使用色轮上相对的颜色，视觉冲击力强。

示例色组：
- 紫→橙：`#8360c3` → `#2ebf91`
- 蓝→粉：`#4facfe` → `#f77062`

### 多色彩虹渐变
添加 4-5 个色点，按彩虹顺序排列（红→橙→黄→绿→蓝→紫）。

## 输出的 CSS 代码示例

工具会根据你的设置生成如下 CSS：

线性渐变：
```
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

径向渐变：
```
background: radial-gradient(circle, #f7971e 0%, #ffd200 100%);
```

多色点：
```
background: linear-gradient(to right, #f7971e 0%, #ffd200 33%, #21d4fd 66%, #b721ff 100%);
```

## 最佳实践

1. **先看整体预览**：调整参数时关注大色块预览，而非只盯着参数数值
2. **保存常用渐变**：复制 CSS 代码保存到代码片段库，方便复用
3. **测试深色模式**：在你项目的深色模式下检查渐变是否仍然好看
4. **注意文字可读性**：叠加文字时，避免在颜色过渡的中间区域放置重要文字
