# AI 抠图 · 使用教程

## 步骤
1. 打开 **AI 抠图** 工具。
2. **上传图片**：点击虚线框区域，或把图片拖拽到框内（支持常见图片格式）。
3. **选择模型**：
   - 轻量（isnet_quint8）：约 40MB，速度快；
   - 高清（isnet_fp16）：约 80MB，精度更高。
4. 点击 **「去除背景」**。首次使用会下载模型权重（约 40–80MB，进度条可见），之后由浏览器缓存。
5. 处理完成后，页面显示 **原图 / 去背景后** 对比。去背景结果带棋盘格底，表示透明区域。
6. 点击 **「下载 PNG」** 保存透明背景图片。

## 常见问题
- **处理很慢？** 模型推理依赖本机 CPU/GPU，大图或高清模型会更慢，可换轻量模型或先缩小图片。
- **边缘不干净？** 对发丝、玻璃等半透明物体，可导出后用图像编辑工具微调。
- **模型下载失败？** 确保本站 `/imgly-bg/` 资源可访问（自托管权重），必要时重新加载页面。
