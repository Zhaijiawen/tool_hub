# Cron 表达式解析 - 使用教程

## 快速开始

Cron 表达式解析工具帮助开发者和运维人员快速理解、验证和生成 Cron 时间表达式，无需记忆复杂的语法规则。

## 解析 Cron 表达式

### 步骤 1：输入表达式

在输入框中粘贴或手动输入 Cron 表达式：

- **5位格式（Unix 标准）**：`0 9 * * 1-5`
- **6位格式（Quartz，含秒）**：`0 0 9 * * MON-FRI`

### 步骤 2：查看人话描述

工具会实时翻译表达式为人类易读的描述，例如：
- `0 9 * * 1-5` → "每周工作日（周一至周五）上午 9:00"
- `*/5 * * * *` → "每 5 分钟"
- `0 0 1 * *` → "每月第一天的午夜 12:00"

### 步骤 3：查看下次执行时间

工具会列出未来 5 次执行时间，帮助你确认调度规则是否符合预期：

```
下次执行时间：
1. 2024-04-15 09:00:00（周一）
2. 2024-04-16 09:00:00（周二）
3. 2024-04-17 09:00:00（周三）
4. 2024-04-18 09:00:00（周四）
5. 2024-04-19 09:00:00（周五）
```

## 反向生成 Cron 表达式

### 使用可视化面板

如果你不熟悉 Cron 语法，可以使用可视化选择面板：

1. **分钟**：选择固定分钟（如 `:00`、`:30`）或步进（如每5分钟）
2. **小时**：选择具体小时或每N小时
3. **日期**：选择每天、固定日期、或每月最后一天
4. **月份**：选择全年或特定月份
5. **星期**：选择工作日、周末或特定星期

面板选择后，下方会自动生成对应的 Cron 表达式，可以直接复制使用。

## 常用 Cron 场景

### 每天定时任务

| 需求 | Cron 表达式 |
|------|------------|
| 每天凌晨2点备份 | `0 2 * * *` |
| 每天早上8点发送报告 | `0 8 * * *` |
| 每天中午和下午6点 | `0 12,18 * * *` |

### 每周定时任务

| 需求 | Cron 表达式 |
|------|------------|
| 每周一上午9点 | `0 9 * * 1` |
| 每周五下午5点 | `0 17 * * 5` |
| 工作日每小时 | `0 * * * 1-5` |

### 每月定时任务

| 需求 | Cron 表达式 |
|------|------------|
| 每月1号发工资通知 | `0 9 1 * *` |
| 每月最后一天 | `0 23 L * *`（Quartz）|
| 每季度第一天 | `0 0 1 1,4,7,10 *` |

### 高频任务

| 需求 | Cron 表达式 |
|------|------------|
| 每5分钟检查 | `*/5 * * * *` |
| 每10分钟 | `*/10 * * * *` |
| 每30分钟 | `0,30 * * * *` |

## 错误诊断

### 常见错误及修复

**错误：月份字段超出范围**
```
输入：0 9 * 13 *
错误：月份字段值 13 超出合法范围 [1-12]
修复：0 9 * 12 *（12月）
```

**错误：星期字段值不合法**
```
输入：0 9 * * 8
错误：星期字段值 8 超出合法范围 [0-7]
修复：0 9 * * 1-5（工作日）
```

**错误：步进值为0**
```
输入：*/0 * * * *
错误：步进值不能为 0
修复：*/1 * * * *（每分钟）
```

## 最佳实践

1. **始终用人话描述验证**：生成或收到 Cron 表达式后，先用本工具的人话描述确认含义
2. **检查下次执行时间**：特别是月末、年末等边界情况，直接看时间列表最准确
3. **注意时区**：本工具基于浏览器本地时区显示，部署服务器可能使用 UTC 时区
4. **记录 Cron 含义**：在代码注释中写明 Cron 的人话含义，方便后人维护
