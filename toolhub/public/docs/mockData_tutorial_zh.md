# Mock 数据生成 - 使用教程

## 快速开始

工具默认预置了一套典型的用户数据结构，直接点击"生成"即可看到效果。可以以此为基础修改，或点击"清空"从零配置。

## 配置字段

### 添加字段

点击"+ 添加字段"按钮，在字段列表末尾新增一行。每个字段需要填写：

1. **字段名（Name）**：生成结果中的 JSON key，如 `id`、`name`、`createdAt`
2. **字段类型（Type）**：决定生成的数据内容（见下方类型说明）

### 字段类型说明

#### 基础类型

| 类型 | 生成内容 | 额外配置 |
|------|---------|---------|
| 整数（int）| 指定范围内的随机整数 | 最小值 / 最大值 |
| 浮点数（float）| 指定范围内的随机小数 | 最小值 / 最大值 / 小数位数 |
| 字符串（string）| 随机字母数字字符串 | 无 |
| 布尔值（bool）| `true` 或 `false` | 无 |
| UUID | 标准 UUID v4 格式 | 无 |

#### 常用 Faker 类型

| 类型 | 示例输出 |
|------|---------|
| 姓名（name）| 张伟（中文）/ Alice Smith（英文）|
| 邮箱（email）| user123@example.com |
| 手机号（phone）| 13812345678 |
| 日期（date）| 2024-03-15 |
| 日期时间（datetime）| 2024-03-15T14:30:00Z |
| 网址（url）| https://example.com/page |
| IP 地址（ip）| 192.168.1.42 |
| 颜色（color）| #3a7bd5 |

#### 枚举（enum）

从自定义列表中随机选一个值。在输入框中填写逗号分隔的选项：

```
active,inactive,pending,deleted
```

#### 自定义模板（template）

使用 `{{}}` 占位符自由组合生成内容：

| 占位符 | 含义 |
|--------|------|
| `{{int(1,100)}}` | 1~100 的随机整数 |
| `{{float(0,1,2)}}` | 0~1 的随机小数，保留 2 位 |
| `{{uuid}}` | UUID |
| `{{name}}` | 随机姓名 |
| `{{email}}` | 随机邮箱 |

示例：`USER_{{int(10000,99999)}}_{{name}}`

#### 嵌套结构

- **Object**：生成嵌套对象，可在其下添加子字段
- **Array**：生成数组，可配置元素类型（基础类型或枚举）及元素数量范围

### 删除字段

点击字段右侧的 **×** 按钮删除该字段。嵌套字段的子级删除同理。

## 设置生成数量

在"数量"输入框填写需要生成的记录条数（1~1000）。

## 生成与导出

- **生成**：根据当前字段配置生成 JSON 数据
- **复制**：将生成的 JSON 复制到剪贴板
- **JSON**：将生成的数据下载为 `.json` 文件

## 提示

- 字段名支持任意字符，包括中文，但建议使用驼峰或下划线命名以兼容各类 JSON 解析器
- Object / Array 字段可以折叠/展开，方便管理复杂结构
- 工具使用浏览器本地时区生成日期时间数据
