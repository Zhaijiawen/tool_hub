# Mock 数据生成 — 怎么用

工具默认带了一套用户数据 schema，点「生成」就能立刻看到效果。可以在这个基础上改，也可以清空自己从头配。

## 配置字段

点「+ 添加字段」新增一行。每个字段要填名称（JSON key）和类型（生成什么数据）。

### 字段类型

**基础类型 —**

| 类型 | 生成什么 | 额外配置 |
|------|---------|---------|
| 整数 | 指定范围内的随机整数 | 最小值 / 最大值 |
| 浮点数 | 指定范围内的随机小数 | 最小值 / 最大值 / 小数位数 |
| 字符串 | 随机字母数字 | — |
| 布尔值 | `true` 或 `false` | — |
| UUID | 标准 UUID v4 | — |

**Faker 类型 —**

| 类型 | 示例输出 |
|------|---------|
| 姓名 | 张伟 |
| 邮箱 | user123@example.com |
| 手机号 | 13812345678 |
| 日期 | 2024-03-15 |
| 日期时间 | 2024-03-15T14:30:00Z |
| 网址 | https://example.com/page |
| IP | 192.168.1.42 |
| 颜色 | #3a7bd5 |

**枚举 —** 自定义候选值，逗号分隔：`active,inactive,pending,deleted`。生成时随机挑一个。

**自定义模板 —** 用 `{{}}` 占位符拼出想要的值：

| 占位符 | 效果 |
|--------|------|
| `{{int(1,100)}}` | 1 到 100 随机整数 |
| `{{float(0,1,2)}}` | 0 到 1 随机小数，两位精度 |
| `{{uuid}}` | UUID v4 |
| `{{name}}` | 随机姓名 |
| `{{email}}` | 随机邮箱 |

比如 `USER_{{int(10000,99999)}}_{{name}}` 生成 `USER_45892_张伟`。

**嵌套结构 —** Object 生成嵌套对象，下面可以加子字段。Array 生成数组，配置元素类型和数量范围。

### 管理字段

点 × 按钮删字段。拖拽调整字段顺序（影响输出 JSON 的 key 顺序）。Object 和 Array 字段可以折叠，管理复杂结构时清爽很多。

## 生成与导出

设好数量（1 到 1000），点「生成」。输出区展示格式化后的 JSON。点「复制」贴到剪贴板，点「JSON」下载为 `.json` 文件。

## 提示

字段名支持中文等任意字符，但建议用驼峰或下划线命名，兼容各类 JSON 解析器。Object 和 Array 字段产出的结构与真实 API 响应一致。日期时间用的是浏览器本地时区。
