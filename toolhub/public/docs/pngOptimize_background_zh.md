# PNG 优化 — 技术背景

这个工具用 **Oxipng**（通过 jsSquash 的 WASM 封装）无损压缩 PNG 图片。文件不上传，在你浏览器里完成。

## 为什么能压小 PNG

PNG 本身是无损的，但很多 PNG 在生成时残留了冗余：比如不必要的元数据块、次优的压缩参数、没用上的调色板条目。Oxipng 会重新编码像素数据、清理冗余，在不损失任何一个像素的前提下把文件变小。

## 三个参数

- **级别（1-6）**：压缩强度。1 最快、压得少；6 最慢、压得最狠。默认 3 是平衡点。
- **交错（interlace）**：开启后图片可以边下载边从上到下逐行显示（渐进式 PNG），但会略微增大体积。一般关掉。
- **优化 Alpha（optimiseAlpha）**：对透明通道做更精细的优化。默认开启。

## 什么时候没收益

如果 PNG 已经被好好压过（比如用 Oxipng/squoosh 处理过），再压几乎不会更小，工具会如实显示「无收益」。已压缩过的 JPEG 不能当 PNG 优化输入——本工具只接受 PNG。

## 隐私

图片只在本地处理。
