# Number Base Converter — Usage Tutorial

## How to Use

### Step 1: Enter the Input Value
Type the number you want to convert in the input field.

### Step 2: Set the Input Base
Specify the base of the number you entered (e.g., 10 for decimal, 16 for hexadecimal).

### Step 3: Set the Target Base
Specify the base you want to convert to.

### Step 4: View the Result
The converted number is shown instantly. Copy it using the copy button.

## Supported Bases

This tool supports any integer base from 2 to 36. For bases above 10, letters A–Z represent values 10–35.

## Examples

| Input | From Base | To Base | Result |
|---|---|---|---|
| `255` | 10 | 16 | `FF` |
| `FF` | 16 | 2 | `11111111` |
| `42` | 10 | 8 | `52` |
| `z` | 36 | 10 | `35` |

## Tips
- Hexadecimal letters are case-insensitive
- Use base 2 to visualize binary representations of values
- Base 36 is useful for compact alphanumeric codes
