# CIDR 网段计算 - 使用示例

## 示例 1：家庭 / 办公网络（/24）

**输入：** `192.168.1.0/24`

| 字段 | 值 |
|------|-----|
| 网络地址 | 192.168.1.0 |
| 广播地址 | 192.168.1.255 |
| 子网掩码 | 255.255.255.0 |
| 可用 IP 数量 | 254 |
| IP 范围 | 192.168.1.1 ~ 192.168.1.254 |
| 类型 | 私有地址（C 类）|

---

## 示例 2：企业内部网络（/16）

**输入：** `10.0.0.0/16`

| 字段 | 值 |
|------|-----|
| 网络地址 | 10.0.0.0 |
| 广播地址 | 10.0.255.255 |
| 子网掩码 | 255.255.0.0 |
| 可用 IP 数量 | 65,534 |
| IP 范围 | 10.0.0.1 ~ 10.0.255.254 |
| 类型 | 私有地址（A 类）|

---

## 示例 3：等分子网划分（/24 → /25）

将 `192.168.100.0/24`（254 个主机）划分为两个 `/25` 子网：

| 子网 | 网络地址 | 广播地址 | 可用主机 |
|------|---------|---------|---------|
| 第一子网 | 192.168.100.0/25 | 192.168.100.127 | 126 个 |
| 第二子网 | 192.168.100.128/25 | 192.168.100.255 | 126 个 |

---

## 示例 4：云服务 VPC 规划

**场景：** 在阿里云 / AWS 创建 VPC，需要为不同服务分配子网

```
VPC 总网段：  10.0.0.0/16  （65,534 个可用 IP）

├── 公有子网 A：10.0.0.0/20   （4,094 个 IP）  ← 对外服务
├── 公有子网 B：10.0.16.0/20  （4,094 个 IP）  ← 对外服务
├── 私有子网 A：10.0.32.0/20  （4,094 个 IP）  ← 应用层
├── 私有子网 B：10.0.48.0/20  （4,094 个 IP）  ← 应用层
└── 数据库子网：10.0.64.0/24  （254 个 IP）    ← 数据层
```

## 示例 5：点对点链路（/30）

路由器之间的点对点链路通常使用 /30，只有 2 个可用地址：

| 广播地址 | 10.1.1.3 |
| 可用主机 | 10.1.1.1 和 10.1.1.2 |

## 示例 6：IP 归属判断

**判断 `10.50.20.100` 是否属于 `10.50.0.0/16`：**

- 网段范围：`10.50.0.1` ~ `10.50.255.254`
- `10.50.20.100` ✅ 在范围内

**判断 `172.31.255.250` 是否属于 `172.16.0.0/12`：**

- 网段范围：`172.16.0.1` ~ `172.31.255.254`
- `172.31.255.250` ✅ 在范围内（172.16.0.0/12 覆盖 172.16~31.x.x）
