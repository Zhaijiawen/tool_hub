# 图片文字识别 (OCR) — 使用示例

## 识别一张中文截图

**输入：** `note.png`（手机截图，含中文段落）
**操作：** 语言选 `chi_sim`，PSM 自动
**输出：** 可编辑中文文本，置信度 ~92%

提取截图里的文字贴进笔记，比手打好太多。

## 中英混排的文档

**输入：** `doc.png`（英文正文夹中文术语）
**操作：** 语言选 `chi_sim` + `eng`
**输出：** 中英文都识别出来

只选一种语言会漏掉另一种，混排务必两种都选。

## 识别一行验证码/序列号

**输入：** `sn.png`（单行数字字母）
**操作：** 语言 `eng`，PSM 选单行
**输出：** 准确提出那串字符

限定单行模式能减少误识别。

## 低质量图识别率下降

**输入：** `blurry.jpg`（模糊照片）
**操作：** `eng` 自动
**结果：** 置信度 ~45%，多处错字

模糊或手写时 OCR 会翻车，结果仅供参考，务必核对。
