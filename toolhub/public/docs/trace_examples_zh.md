# 实用示例：图片转 SVG

## 示例一：白底黑色 Logo → 矢量素材

**场景**：手上有一个旧版 Logo 的 PNG（白底黑字，800×600），想用在需要高清输出的物料上。

**参数**：
```
输入: logo.png  800×600  46 KB
阈值: 128（默认）
反色: 关闭
处理宽度: 原图尺寸（800px 较小，无需降采样）
```

**操作**：上传 → 保持默认参数 → 点击「转为 SVG」

**结果**：得到单色路径的 SVG，体积通常只有十几 KB，且可以放大到任意尺寸用于海报、喷绘而不失真。

---

## 示例二：手写签名扫描件 → 透明背景矢量签名

**场景**：纸质文件上手写的签名，扫描成图片后需要放进电子文档。

**参数**：
```
输入: signature.jpg  扫描件
阈值: 150  ← 提高阈值
反色: 关闭
处理宽度: 1600 px
```

**为什么调高阈值**：扫描件往往墨色偏浅，且纸张底色不是纯白。把阈值提高到 150 左右能让较浅的笔迹也纳入图形，笔画更连贯。

**结果**：下载 SVG 后可用编辑器替换 `fill="#000000"` 为品牌色，并直接嵌入 PDF 或网页。

---

## 示例三：黑底白色图标 → 必须开启反色

**场景**：一个深色背景上的白色线性图标（常见于深色主题 UI 截图）。

**参数**：
```
输入: icon-white-on-black.png
阈值: 128
反色: 开启  ← 关键
处理宽度: 原图尺寸
```

**不开启反色的结果**：会得到一块填满的黑色矩形，因为算法把大面积深色背景当成了图形主体。

**开启反色后**：深浅关系翻转，白色图标笔画成为图形，输出正确。

---

## 示例四：大尺寸线稿 → 限制处理宽度提速

**场景**：一张 4000×3000 的线稿扫描件。

**参数**：
```
输入: drawing.jpg  4000×3000
阈值: 128
反色: 关闭
处理宽度: 1000 px  ← 关键
```

**原因**：追踪算法的耗时随像素面积增长。4000px 宽的原图约 1200 万像素，限制到 1000px 宽后约 90 万像素，处理量减少到原来的 1/13，速度提升非常明显；对线稿而言 1000px 宽的输出细节通常已经足够。

---

## 示例五：不适合的情况（反面示例）

**场景**：想把一张彩色人像照片转成矢量。

**结果**：照片被强制二值化后，明暗层次丢失，输出大量零碎且无法辨认的黑色斑块，SVG 体积甚至可能超过原图。

**结论**：本工具适合处理线条稿与图形，不适合照片。照片场景应考虑：
- 需要**去背景** → 使用「AI 抠图」工具
- 需要**放大且不失真** → 这属于超分辨率范畴，与本工具的路线不同

---

## 参数速查表

| 输入类型 | 阈值 | 反色 | 处理宽度 |
| --- | --- | --- | --- |
| 白底黑线 Logo / 图标 | 128 | 关 | 原图 |
| 浅色手写签名扫描件 | 140–160 | 关 | 1000–1600 |
| 深色铅笔草图（笔迹浅） | 150–180 | 关 | 原图 |
| 黑底白线图标 | 128 | **开** | 原图 |
| 超大线稿扫描件（>3000px） | 128 | 关 | 1000 |
| 彩色照片 | 不适用 | 不适用 | 建议不要使用本工具 |
