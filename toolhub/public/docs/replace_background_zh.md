# 查找与替换 — 技术背景

## 概述

查找与替换是最基础的文本编辑操作之一。它在文本中定位搜索词的出现位置，并用指定字符串替换。现代实现同时支持纯文本和正则表达式（regex）模式。

## 纯文本 vs. 正则表达式

### 纯文本搜索
直接匹配字面字符串，速度快、操作简单，适合大多数日常任务。

### 正则表达式搜索
正则表达式提供强大的模式匹配语言，可以描述复杂的搜索条件：

```
\d+        → 匹配一个或多个数字
[a-z]+     → 匹配一个或多个小写字母
\bword\b   → 匹配完整单词 "word"
(foo|bar)  → 匹配 "foo" 或 "bar"
```

## 替换的工作原理

当找到匹配时，匹配的文本被替换字符串替代。使用正则表达式时，替换字符串还可以通过 `$1`、`$2` 等引用捕获组。

### 示例
```
模式：    (\w+)\s(\w+)
输入：    John Doe
替换为：  $2, $1
结果：    Doe, John
```

## 大小写敏感

- **区分大小写**：`hello` 不匹配 `Hello` 或 `HELLO`
- **忽略大小写**：`hello` 可匹配 `Hello`、`HELLO`、`hElLo`

## 全部替换 vs. 仅首次

- **全部替换**：替换文本中所有出现的位置
- **替换首个**：仅替换第一个匹配

## 常见应用场景

| 使用场景 | 示例 |
|---|---|
| 变量重命名 | 将 `oldVar` 替换为 `newVar` |
| 修正拼写错误 | 将 `teh` 替换为 `the` |
| 日期格式转换 | 将 `(\d{4})-(\d{2})-(\d{2})` 替换为 `$3/$2/$1` |
| 去除 HTML 标签 | 将 `<[^>]+>` 替换为空 |
