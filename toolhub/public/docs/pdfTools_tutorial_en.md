# PDF Tools — Usage Tutorial

The three tabs at the top map to the three features; at the bottom there is an optional **password** box that applies to the current operation.

## PDF to image

1. In the **To image** tab, upload a PDF.
2. Pick format (PNG / JPEG) and scale (1x/2x/3x).
3. Pick range: all pages, or custom (e.g. `1-3,5`).
4. Click **Start render**; pages show in a grid afterward, download individually or **Download all**.

## Merge PDF

1. Switch to the **Merge** tab, upload at least 2 PDFs.
2. Reorder with the up/down arrows on each row (order decides the merged sequence).
3. Click **Start merge** and download.

## Split PDF

1. Switch to the **Split** tab, upload a PDF.
2. Pick a mode:
   - **Split each page**: one file per page.
   - **Split by range**: enter a range (e.g. `1-3,5`).
3. Click **Start split**, download individually or **Download all**.

## Encrypted files

Fill the password box at the bottom, then run the operation above to open an encrypted PDF.

## Tips

- Only need a certain page as an image? In To image, use a custom range to render just those pages — faster.
- Reorder before merging; the result is not reversible (unless you merge again).
- Many pages produce many files when rendering; pick a range when possible.
