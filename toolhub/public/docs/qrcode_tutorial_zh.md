# 二维码 — 怎么生成

## 快速生成

1. 把内容（URL、文本等）输入或粘贴到输入区，二维码实时生成
2. 需要的话调尺寸、纠错级别、颜色，或在高级选项里叠加 Logo
3. 点「下载 PNG」或「下载 SVG」保存结果

就这些。版本和编码模式工具自动选。

## 参数说明

**纠错级别 —** 四个级别，越高越耐造但能装的数据越少。M 做默认。要叠加 logo 或者码会被恶劣对待就用 H。想把更多数据塞进小码就用 L。

**模块大小 —** 每个方块的像素尺寸。越大越容易扫但文件也大。数字展示用 10px 不错，嵌入文档用 5-8px。

**静区 —** 码四周的白边。规范说至少 4 个模块宽度。大多数 QR 库默认 4。可以为美观加宽，别缩窄就好。

**前景/背景颜色 —** 默认黑底白字，给扫描器最大的对比度。可以自定义颜色，但深色在前浅色在后的原则别违背。低对比度或反着来扫描很不靠谱。

## 常见场景

**URL —** 最常见。直接粘贴完整 URL。不要用短链接服务——把最终目标 URL 编码进去，这样二维码永远有效。

**WiFi 凭证 —** 用这个格式：`WIFI:S:网络名;T:WPA;P:密码;;` 把网络名换成你的 SSID，WPA 换成你的加密方式（WPA、WEP 或不填表示开放网络），密码换成 WiFi 密码。大多数手机认得这个格式并提示自动连接。

**联系信息（vCard）—**

```
BEGIN:VCARD
VERSION:3.0
FN:张三
TEL:+86-138-1234-5678
EMAIL:zhangsan@example.com
END:VCARD
```

**纯文本 —** 任意文本都行。手机扫出来会展示或提示复制。内容尽量短——长文本产出的二维码密，难扫。

## 数据量和尺寸的关系

数据越多二维码越大，越难扫。100 字符以内的 URL 产出的码干净利落，各种尺寸都行。如果是大段文字，先在几种手机上测试一下能不能稳定识别。

## 下载和使用

两种格式可选：

**PNG —** 位图，数字场景直接用。256-512px 总尺寸合适，贴到任何页面都干净。打印用就把尺寸滑到大一档，别缩小。

**SVG —** 矢量，放大多少都不糊。印刷、大幅海报、后续要用设计软件（Illustrator、Figma）继续编辑时选它。配置了 Logo 的话 SVG 里会一并内嵌，比例、圆角、透明度和 PNG 完全一致。
