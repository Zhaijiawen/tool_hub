# 文本统计 - 使用教程

## 快速开始

将任意文本粘贴进输入框，统计结果会实时更新，无需任何操作。

## 统计指标说明

### 基础字符统计

| 指标 | 说明 |
|------|------|
| 总字符数 | 文本中所有字符的数量，包含空格和换行 |
| 去空格字符数 | 去除空格、换行等空白字符后的纯内容字符数 |
| 单词数 | 英文按空格分词，中文按汉字数统计 |
| 行数 | 文本中的行数（包含空行） |
| 段落数 | 以空白行分隔，非空段落的数量 |
| 句子数 | 以句号、问号、感叹号等结尾的片段数量 |

### 阅读时间

基于平均阅读速度自动估算完整阅读所需时间：
- 中文按 350 字/分钟计算
- 英文按 200 词/分钟计算

### 词频统计

展示出现频率最高的前 20 个词，帮助你了解文章的核心主题，
并识别是否存在重复啰嗦的表达。

## 使用场景示例

### 场景 1：检查微信公众号文章长度

微信推文正文建议 800~2000 字，可粘贴文章后查看"去空格字符数"。

### 场景 2：估算翻译费用

翻译通常按词数或字数计费，粘贴原文即可快速得到单词/字符数量，便于估算费用。

### 场景 3：简历优化

将自我介绍粘贴进来，通过词频统计确认是否有重复使用的词语，保持描述的多样性。

### 场景 4：内容质量检查

查看段落数量和句子数量，判断段落是否过长、单句是否太短碎，优化文章节奏。

## 操作提示

- 结果**实时更新**，边写边看数据变化
- 支持中英混排文本，各语言词数分别统计
- 最大支持约 100 万字符，超出部分截取处理
