# 文本统计 — 怎么用

把任意文本贴进输入框，统计结果即时更新。不用点按钮，不用调设置。

## 各个指标的意思

| 指标 | 统计什么 |
|------|---------|
| 总字符数 | 所有内容——字母、空格、换行、标点 |
| 去空格字符数 | 去掉所有空白字符后的纯内容 |
| 单词/字数 | 英文按空格分词，中文按字统计 |
| 行数 | 包括空行在内的总行数 |
| 段落数 | 由空行分隔的非空段落数 |
| 句子数 | 以 `.` `!` `?` `。` `！` `？` 结尾的片段数 |

## 阅读时间

显示在指标上方。中文按 350 字/分钟，英文按 200 词/分钟。混合文本加权平均。

## 词频统计

展示出现频率最高的前 20 个词和次数。快速了解文章在讲什么，同时发现有没有词用得太频繁。

## 实际用法

**检查公众号文章长度 —** 把草稿贴进来，看「去空格字符数」。微信读者对 800-2000 字的文章互动最好。

**估算翻译费用 —** 翻译公司按词数或字数计费。正式报价前把原文贴进来，心里先有个数。

**简历优化 —** 把自我介绍或岗位描述贴进来。词频统计能看出某些词是不是用得太多了。200 词里「负责」出现了 8 次，就该翻翻同义词了。

**内容节奏检查 —** 看句段比。每个段落都是一句话，文章就碎了。每个段落 8 句话以上，就是一堵字墙。

## 技术限制

输入即更新，实时统计。支持中英混排，各语言分别合理计数。最大处理约 100 万字符，超出的部分截断。
