# IP 查询工具 - 使用教程

打开工具，自动检测当前公网 IP 并拉取归属地信息。不用注册，不用配置。

## 打开后发生了什么

工具立刻用你的当前连接调用 IP 地理位置 API，返回：

- 你的公网 IP 地址
- 国家和区域（带国旗图标）
- 大概的城市
- ISP 和 ASN（自治系统编号）
- 时区
- 经纬度 -- 可点击跳转地图
- 货币和语言信息

## 查指定 IP

在输入框里输入 IP，点查询。支持 IPv4 和 IPv6：

- `8.8.8.8` -- Google 公共 DNS
- `1.1.1.1` -- Cloudflare DNS
- `2001:4860:4860::8888` -- Google IPv6 DNS

## 怎么理解这些结果

地理字段（国家、城市、经纬度）来自 API 用的 IP 数据库。网络字段（ISP、ASN、组织）来自 WHOIS 和 BGP 数据。这两个数据源不一定一致 -- 有时候地理位置是 ISP 注册 IP 段的地址，而网络信息反映的是实际运营者。

经纬度链接很实用 -- 点一下直接打开地图看数据库认为这个 IP 在哪。

## 实际用途

**检查 VPN 是否生效。** 开 VPN 前后各打开工具看一眼。国家变了说明流量走 VPN 了。没变说明 VPN 可能漏了（或者你连了本国的节点）。

**确认服务器的实际位置。** 云厂商说你的虚拟机在法兰克福？查一下公网 IP 确认。偶尔云厂商的"区域"和物理位置对不上。

**排查地理封锁。** 某个服务报了地理限制错误，查一下你的 IP 归属哪个国家。能帮你判断封锁是针对你的位置还是有什么配置问题。

**脚本里用。** shell 脚本里需要知道服务器的公网 IP？`curl -s https://ipapi.co/json/` 返回 JSON，包含 IP、国家、城市等信息。配合 `jq` 一行搞定。

## 注意事项

私有 IP（`192.168.x.x`、`10.x.x.x`）查不出有用信息 -- 局域网地址没有归属地数据。免费 IP API 有频次限制（ipapi.co 免费版每天 1000 次）。还有，结果只是大概位置。如果工具显示你在 200 公里外的城市，这在 IP 定位的精度范围内，不是坏了，是 IP 数据库就是这么工作的。
