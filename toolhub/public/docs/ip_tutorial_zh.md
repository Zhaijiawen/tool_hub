# IP 查询工具 - 使用教程

## 快速开始

IP 查询工具无需注册，打开即用。工具会自动检测并显示你当前的公网 IP 信息。

## 基本使用流程

### 自动查询当前 IP

打开工具后，页面自动调用接口获取你当前的公网 IP 及其归属信息，无需任何操作。

显示信息包括：
- 📍 **IP 地址**：你的公网 IP
- 🌍 **国家/地区**：IP 注册所在的国家和地区
- 🏙️ **城市**：大致所在城市
- 🏢 **ISP/运营商**：互联网服务提供商（如 中国电信、中国联通）
- 📡 **ASN**：自治系统编号
- 🕐 **时区**：当前时区
- 📍 **经纬度**：可点击链接在地图中查看

### 查询指定 IP

1. 在输入框中输入要查询的 IP 地址（支持 IPv4 和 IPv6）
2. 点击 **"查询"** 按钮
3. 等待结果展示

**IPv4 示例：**`8.8.8.8`（Google DNS）

**IPv6 示例：**`2001:4860:4860::8888`

## 查询结果解读

### 地理位置信息

| 字段 | 说明 |
|------|------|
| 国家 | IP 注册所在国家（含国旗图标） |
| 地区/省 | 所在省或州 |
| 城市 | 所在城市（误差可能较大） |
| 邮政编码 | 所在区域邮编 |
| 经纬度 | 地理坐标，点击可跳转地图 |

### 网络信息

| 字段 | 说明 |
|------|------|
| ISP | 互联网服务提供商名称 |
| 组织 | IP 实际归属的组织 |
| AS 编号 | 自治系统编号，格式如 AS13335 |
| 连接类型 | 如宽带、企业、移动等 |

## 常见使用场景

### 验证 VPN 是否生效

打开工具，查看当前显示的国家和城市。如果与你实际所在地不同，说明 VPN 已生效，流量正通过 VPN 出口节点路由。

### 查询服务器 IP 归属

输入你的服务器公网 IP，确认服务器所在数据中心的城市和运营商信息。

### 网络排查

当遇到某些网站或服务无法访问时，查询你的 IP 归属地，判断是否属于被目标服务地理封锁的区域。

### 自动化脚本中获取公网 IP

```javascript
// 直接调用 ipapi.co 获取当前公网 IP
const response = await fetch('https://ipapi.co/json/')
const data = await response.json()
console.log(data.ip)      // 当前 IP
console.log(data.country) // 国家代码
console.log(data.city)    // 城市
```

## 注意事项

1. **私有 IP 无法查询**：如 `192.168.x.x`、`10.x.x.x` 等局域网地址无归属地信息
2. **免费接口有频次限制**：ipapi.co 每天免费 1000 次，避免频繁调用
3. **结果仅供参考**：地理位置精度有限，城市可能不准确
4. **企业 VPN 影响**：使用企业 VPN 时，显示的是公司出口 IP，而非个人位置
