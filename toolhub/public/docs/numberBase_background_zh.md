# 进制转换器 - 技术背景

进制（radix）指的是一个数字系统用了多少个不同的数字符号，"用完了"就进位。十进制有 10 个符号，二进制只有 2 个，十六进制有 16 个。但数学上任何正整数都能当进制用，原理都一样。

## 常见的几种

| 进制 | 名称 | 数字 | 哪里出现 |
|---|---|---|---|
| 2 | 二进制 | 0-1 | 硬件、位运算、底层协议 |
| 8 | 八进制 | 0-7 | Unix 权限、遗留系统 |
| 10 | 十进制 | 0-9 | 人类所有的地方 |
| 16 | 十六进制 | 0-9, A-F | 内存、颜色、字节 dump、加解密 |

## 进制转换怎么算的

两个方向，两个算法。

### 十进制转目标进制：重复除法

不断除以目标进制，记下余数，商变成 0 后把余数从下往上读（最后一个余数是最高位）。

42 转二进制：
```
42 / 2 = 21 余 0
21 / 2 = 10 余 1
10 / 2 =  5 余 0
 5 / 2 =  2 余 1
 2 / 2 =  1 余 0
 1 / 2 =  0 余 1
倒着读：101010
```

### 任意进制转十进制：位权求和

每位数字 x（进制^位置），求和：
```
十六进制 2A -> 2 x 16^1 + 10 x 16^0 = 32 + 10 = 42
```

## 任意进制

本工具支持 2 到 36 进制。10 以内用数字 0-9。11 到 36 加上字母 A-Z，A=10, B=11, ..., Z=35。这是 JavaScript `parseInt` 和 `toString` 使用的标准约定。

超过 36 进制理论上可行但需要更多符号（小写字母、特殊字符）。Base 62（0-9 + A-Z + a-z）常见于短链接服务如 Bitly。Base 64 用于数据编码。本工具停在 36，因为这是标准字母数字范围。

Base 36 特别有意思：它是仅用 0-9 和 A-Z 能表达的最大进制，数字的字符串表示非常紧凑。一个 64 位整数大概只需要 13 个 base-36 字符。有些系统用它生成短小的人类可读 ID。
