# Number Base Converter — Examples

## Example 1: Decimal to Hexadecimal

**Input:** `255`  **From:** Base 10  **To:** Base 16
**Result:** `FF`

**Input:** `4096`  **From:** Base 10  **To:** Base 16
**Result:** `1000`

## Example 2: Hexadecimal to Binary

**Input:** `A5`  **From:** Base 16  **To:** Base 2
**Result:** `10100101`

## Example 3: Octal to Decimal

**Input:** `755`  **From:** Base 8  **To:** Base 10
**Result:** `493`

*(This is the numeric value of the common Unix permission `chmod 755`)*

## Example 4: Base 36 to Decimal

**Input:** `z`  **From:** Base 36  **To:** Base 10
**Result:** `35`

**Input:** `10`  **From:** Base 36  **To:** Base 10
**Result:** `36`
