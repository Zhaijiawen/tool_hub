# 数字大写转换 使用教程

## 快速开始

1. 在输入框输入数字（或点击快速示例）
2. 选择转换模式
3. 查看结果并复制

## 模式选择

| 模式 | 适用场景 |
|------|---------|
| 大写（壹贰叁） | 正式文书、合同金额 |
| 小写（一二三） | 日常书写、非正式场景 |
| 财务金额 | 支票、银行汇款、发票 |

## 支持的输入格式

- **整数**：`100`、`12345`、`100000000`
- **小数**：`100.50`、`1234.99`（财务模式只识别两位小数）
- **负数**：`-100`、`-1234.56`

## 财务金额格式规则

| 输入 | 结果 |
|------|------|
| 100 | 壹佰元整 |
| 100.50 | 壹佰元伍角 |
| 100.05 | 壹佰元零伍分 |
| 100.55 | 壹佰元伍角伍分 |
| 0 | 零元整 |
