# 数字大写转换 - 使用教程

把阿拉伯数字转成中文汉字表达，支持三种模式：大写（正式）、小写（日常）、财务金额（银行格式带货币单位）。

## 怎么用

1. 在输入框输入（或粘贴）数字
2. 选模式：大写、小写或财务金额
3. 复制结果

也可以点快速示例按钮，一个数字看三种模式的结果。

## 模式怎么选

| 模式 | 用在哪 | 字符 |
|---|---|---|
| 大写 | 合同、法律文件、正式收据 | 壹贰叁肆伍陆柒捌玖 |
| 小写 | 日常书写、笔记、非正式场景 | 一二三四五六七八九 |
| 财务金额 | 支票、银行汇款、发票、税务文件 | 壹贰叁...元角分整 |

## 支持什么输入

整数、小数、负数都行：

- `100` -- 普通整数
- `12345` -- 大整数（自动处理万和亿的分组）
- `100000000` -- 一亿，变成壹亿
- `100.50` -- 小数，财务模式出伍角
- `1234.99` -- 财务模式只取两位小数（角和分）
- `-100` -- 负数，前面加负
- `-1234.56` -- 负数财务金额

## 财务金额规则详解

这些是标准的中文银行约定：

| 输入 | 输出 | 规则 |
|---|---|---|
| `100` | 壹佰元整 | 无小数末尾加"整" |
| `100.50` | 壹佰元伍角 | 有角无分，只写角 |
| `100.05` | 壹佰元零伍分 | 角为零分不为零，元和分之间加"零" |
| `100.55` | 壹佰元伍角伍分 | 角分都有 |
| `0` | 零元整 | 零金额 |

"零"的插入规则是财务格式最绕的地方：角（十分位）为零但分（百分位）不为零时，元和分之间要加"零"来占位。这跟中文口头读金额的方式一致。

## 实用技巧

- 填银行汇款单直接把财务模式结果复制到金额栏。
- 大数字（亿级别）确认一下万和亿的分组是否正确 -- 工具处理的是中文特有的万（10^4）和亿（10^8）分组，跟西方的千/百万分组不一样。
- 超过万亿（10^12）的数字受 JavaScript 精度限制，可能不完全准确。
