# PCRE2 正则 — 使用教程

1. 在「正则表达式」框里写模式。
2. 勾选需要的标志位（忽略大小写、多行等）。
3. 在「测试文本」框里粘贴要匹配的文本。
4. 点「运行匹配」：下方列出每条匹配、捕获组和命名组。
5. 要替换？点「替换首个」或「替换全部」，在替换模板框里写替换式（支持 `$1`、 `${name}` 等反向引用），结果实时显示。

## 命名分组

用 `(?<name>...)` 给分组起名，结果里会以「名称: 值」展示，替换时可用 `${name}` 引用。

## 编译错误

模式写错时，工具显示错误信息和出错偏移量（第几个字符），方便你定位修正。

## 小提示

- 点「加载示例」可填入一个日期提取的正则，含命名分组和替换演示。
- 想匹配嵌套结构（如 JSON/括号），JS 正则做不到，用 PCRE2 的递归特性。
- 勾 `x` 可以在模式里加空格和注释，方便读复杂正则。
