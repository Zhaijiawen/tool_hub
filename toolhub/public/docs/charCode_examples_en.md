# Character Code Converter — Examples

## Example 1: Basic Latin Characters

| Character | Decimal | Hex | HTML Entity | URL Encoded |
|---|---|---|---|---|
| `A` | 65 | 41 | `&#65;` | `%41` |
| `a` | 97 | 61 | `&#97;` | `%61` |
| `0` | 48 | 30 | `&#48;` | `%30` |
| Space | 32 | 20 | `&#32;` | `%20` |

## Example 2: Special Characters

| Character | Decimal | Hex | HTML Entity |
|---|---|---|---|
| `<` | 60 | 3C | `&lt;` |
| `>` | 62 | 3E | `&gt;` |
| `&` | 38 | 26 | `&amp;` |
| `"` | 34 | 22 | `&quot;` |

## Example 3: Unicode Characters

| Character | Unicode | UTF-8 Bytes | Description |
|---|---|---|---|
| `€` | U+20AC | E2 82 AC | Euro sign |
| `©` | U+00A9 | C2 A9 | Copyright |
| `中` | U+4E2D | E4 B8 AD | Chinese character |
| `😀` | U+1F600 | F0 9F 98 80 | Grinning face emoji |

## Example 4: Hidden / Invisible Characters

| Character | Unicode | Description |
|---|---|---|
| (invisible) | U+200B | Zero Width Space |
| (invisible) | U+FEFF | BOM / Zero Width No-Break Space |
| (invisible) | U+00A0 | Non-Breaking Space |
