# URL 解析器 使用教程

## 解析一个 URL

1. 粘贴完整 URL 到输入框（自动解析）
2. 顶部会显示 **合法 URL** 或 **非法 URL** 标签
3. 查看「结构解析」Tab 了解所有字段

## 查看 Query 参数

1. 切换到「Query 参数」Tab
2. 参数以表格形式展示（键/值两列）
3. 勾选「URL 解码显示」可将 `%E4%B8%AD%E6%96%87` 显示为 `中文`
4. 点击每行右侧「复制」按钮单独复制某个参数值
5. 点击「复制全部参数」将所有参数以 `key=value` 格式复制

## 使用反向构建器

1. 切换到「反向构建」Tab
2. 解析 URL 后字段会自动填充
3. 修改任意字段，下方「构建结果」实时更新
4. 点击复制按钮复制构建好的 URL

## 常见问题

**Q：URL 显示非法，但我确定它是对的？**

A：URL 解析需要包含完整协议头，如 `https://` 或 `http://`。仅输入 `example.com` 是不够的。

**Q：参数值显示乱码？**

A：请勾选「URL 解码显示」选项。
