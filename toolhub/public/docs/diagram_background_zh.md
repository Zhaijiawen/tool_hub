# 图表渲染 · 技术背景

## 这是什么
图表渲染在浏览器本地把 **Mermaid 语法**转换成矢量 SVG 图，支持导出 SVG / PNG。整个过程在本机完成，源码不上传服务器，断网也能用。

## 技术原理
- 渲染引擎为 **Mermaid**（本项目使用 v12，随站内资源自托管，不依赖 CDN）。
- 纯 JavaScript 实现，**不使用 WebAssembly** —— 因为图表布局与绘制并非性能瓶颈，没必要为此引入 WASM（本项目原则：只有在性能/能力上有明显优势时才用 WASM）。
- 渲染在本地进程内完成；Mermaid 以 `securityLevel: 'strict'` 运行，会对标签内容做消毒处理。
- 图表类型通过**按需懒加载**分发：流程图、时序图、贺图（KaTeX）、ELK 布局引擎等各自独立加载，未用到的不会下载。

## 支持的图表类型
内置 12 类常用图：流程图、时序图、类图、状态图、实体关系图、用户旅程图、甘特图、饼图、Git 分支图、思维导图、时间线、四象限图。每类在「示例模板」里都有可直接上手的样例。

## 为什么在本地做
- **隐私**：图表源码多为未公开的接口设计、业务链路或组织架构，不应上传到第三方服务器。
- **离线**：无需联网，飞机上、内网都可画。
- **免费**：没有云端编辑器的导出限制与水印。

## 导出差异
| 格式 | 特点 | 适合场景 |
|---|---|---|
| SVG | 矢量、无限放大、可在 Figma / Illustrator 里再编辑 | 文档插图、印刷、再加工 |
| PNG | 位图，本工具按 2 倍像素密度输出 | 贴 PPT / 聊天 / Issue 备注 |
