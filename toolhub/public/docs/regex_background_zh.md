# 正则表达式测试器 — 技术背景

## 什么是正则表达式？

正则表达式（regex 或 regexp）是定义搜索模式的字符序列，是字符串匹配、验证、提取和转换的强大工具，几乎被所有编程语言支持。

## 核心语法

### 字面字符
大多数字符匹配自身：`abc` 匹配字符串 "abc"。

### 特殊字符（元字符）
| 符号 | 含义 |
|---|---|
| `.` | 任意单个字符（换行符除外） |
| `^` | 字符串开头（多行模式下为行首） |
| `$` | 字符串结尾（多行模式下为行尾） |
| `*` | 前面元素出现 0 次或多次 |
| `+` | 前面元素出现 1 次或多次 |
| `?` | 前面元素出现 0 或 1 次（也可使量词变为懒惰模式） |
| `\` | 转义下一个特殊字符 |
| `|` | 或运算——匹配左边或右边的表达式 |
| `()` | 分组与捕获 |
| `[]` | 字符类 |
| `{}` | 指定数量的量词 |

### 字符类
| 模式 | 匹配 |
|---|---|
| `[abc]` | a、b 或 c |
| `[^abc]` | 除 a、b、c 之外的任意字符 |
| `[a-z]` | 任意小写字母 |
| `[0-9]` | 任意数字 |
| `\d` | 任意数字，等同于 `[0-9]` |
| `\D` | 任意非数字 |
| `\w` | 单词字符 `[a-zA-Z0-9_]` |
| `\W` | 非单词字符 |
| `\s` | 空白字符 |
| `\S` | 非空白字符 |

### 量词
| 模式 | 含义 |
|---|---|
| `a{3}` | 恰好 3 个 a |
| `a{2,4}` | 2 到 4 个 a |
| `a{2,}` | 2 个或更多 a |

## 标志

| 标志 | 作用 |
|---|---|
| `g` | 全局——查找所有匹配，而非仅第一个 |
| `i` | 不区分大小写 |
| `m` | 多行——`^` 和 `$` 匹配行边界 |
| `s` | dotall——`.` 也匹配换行符 |

## 分组与反向引用

- `(pattern)` — 捕获组，可通过 `$1`、`$2` 等访问
- `(?:pattern)` — 非捕获组
- `(?=pattern)` — 正向先行断言
- `(?!pattern)` — 负向先行断言
