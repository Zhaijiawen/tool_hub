# 单位换算器 — 使用教程

## 使用步骤

### 第一步：选择类别
选择要换算的计量类别：
- 长度、质量、温度、面积、体积、速度、压强、能量等

### 第二步：输入数值
在输入框中输入要换算的数值。

### 第三步：选择输入单位
从"源单位"下拉框中选择当前值的单位。

### 第四步：选择目标单位
从"目标单位"下拉框中选择要换算成的单位。

### 第五步：读取结果
换算结果即时显示在结果框中。

## 使用技巧

- **温度**换算使用公式（而非简单乘法），因此单独处理
- 点击交换按钮可以互换源单位与目标单位
- 结果保留合理的小数位数
- 对于极大或极小的数值，结果可能以科学记数法显示
