# 图表渲染 · 使用教程

## 快速开始
1. 打开 **图表渲染** 工具。首次进入会从「示例模板」加载一个流程图示例并自动渲染。
2. 在左侧 **源码区** 编写或粘贴 Mermaid 语法，右侧实时预览（输入停止约 0.3 秒后自动渲染）。
3. 想换图类型时，从顶部 **「示例模板」** 下拉选择即可套用样例骨架，再改成自己的内容。

## 切换主题
顶部 **「主题」** 下拉提供 5 个选项：
- **跟随站点（自动）**（默认）：随整站明暗模式自动切换；
- 浅色 / 深色 / 森林绿 / 中性灰：固定使用某一配色。

## 导出
- **下载 SVG**：矢量文件，可用 Figma、Illustrator、Inkscape 二次编辑。
- **下载 PNG**：按 2 倍像素密度输出，适合直接贴到 PPT、Issue 或不便打开 SVG 的场景。
- **复制源码**：把 Mermaid 源码复制到剪贴板，方便粘回文档/README。

## 常见问题
- **右侧报错？** 红框会给出具体语法原因（例如缺 `end`、括号不匹配、类型名拼错），按提示修正即可。
- **导出 PNG 失败？** 多为浏览器把 SVG 转 canvas 时受字体/跨域限制所致，可改用「下载 SVG」再用本地工具转 PNG。
- **图太挤？** 流程图分支多时用 `subgraph` 分组；时序图可用 `box` 归并参与方。
- **第一次打开较慢？** 首次会懒加载对应图表的渲染引擎，之后由浏览器缓存，秒开。
