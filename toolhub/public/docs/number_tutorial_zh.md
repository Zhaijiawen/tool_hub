# 数字转换器 — 使用教程

## 使用步骤

### 第一步：选择输入格式
选择要转换的数字格式：
- **十进制** — 标准的十进制数
- **二进制** — 二进制数（只含 0 和 1）
- **八进制** — 八进制数（数字 0–7）
- **十六进制** — 十六进制数（数字 0–9 和 A–F）

### 第二步：输入数字
在输入框中输入数字，工具会实时校验输入，确保与所选格式匹配。

### 第三步：查看结果
所有转换结果即时显示在输出区域，以所有支持的进制展示同一个值。

## 使用技巧

- 十六进制输入不区分大小写（`FF` = `ff`）
- 十进制可输入负数，二进制结果以补码形式显示
- 利用此工具理解同一数值在不同进制下的表现形式
