# 数字转换器 - 使用教程

输入任意进制的数字，瞬间看到四种进制的转换结果。就这个。但有几个技巧值得了解。

## 怎么用

1. 选输入进制 -- 十进制、二进制、八进制或十六进制
2. 在输入框里输入数字。工具实时校验 -- 十六进制模式下打 `G` 可以，十进制模式下不行
3. 四种转换结果立刻显示。不用点按钮，不用等

## 进制选择很重要

工具只接受所选进制合法的数字。二进制模式下 `2` 会被拒绝。八进制下 `8` 和 `9` 进不去。十六进制下 A-F 可以，`G` 不行。实时校验帮你在一开始就抓出错误，免得浪费时间。

## 负数处理

十进制输入负数，工具会在二进制下显示补码表示。比如 `-1` 在 8 位二进制下变成 `11111111`。工具在各进制之间正确处理了负数。

## 十六进制不区分大小写

`FF`、`ff`、`Ff` 都表示 255。输出格式通常统一为大写，但输入怎么写都行。

## 什么时候真用得上

**读颜色值：** CSS 里的 `#FF6600`，红色=FF（255），绿色=66（102），蓝色=00（0）。工具让你一眼看懂这些十六进制值的十进制含义。

**解码 Unix 权限：** `chmod 755` -- 什么意思？八进制 7 是二进制 `111`（rwx），5 是 `101`（r-x），5 是 `101`（r-x）。所以 755 = `rwxr-xr-x`。工具帮你把八进制权限解码成看得懂的东西。

**处理二进制数据：** 看十六进制 dump 看到 `0x1A3F`，丢进工具，立刻知道十进制是 6719，二进制是 `1101000111111`。比心算快多了。

**理解位掩码：** `0xFF` 是个常见的位掩码 -- 意思是"低 8 位"。看到它是 `11111111`（二进制）和 255（十进制），帮助巩固对实际发生的操作的理解。

**读内存地址：** `0x7FFE5B4C2A30` 是 x64 上的 48 位虚拟地址。工具对超过 2^53 的值会有精度问题（浏览器数字限制），但在这个范围内的地址都能精确转换。

## 知道 JavaScript 的限制

JavaScript 的数字是 64 位浮点数，所以 2^53（约 9000 万亿）以内的整数是精确的。超出之后精度就没了。如果你在转换超过 16 个十六进制字符的大值，十进制输出可能只是近似值。
