# 存储与时间转换器 — 怎么用

## 基本操作

选择存储或时间转换模式。输入一个数值，选它当前的单位，工具同时显示所有其他单位的等效值。不用一个个点。

## 存储转换示例

| 输入 | 会看到什么 |
|------|-----------|
| `1 GB` | `1,000 MB` / `1,024 MiB` / `8,000,000,000 位` |
| `1 TiB` | `1.0995 TB` / `1,099,511,627,776 字节` |
| `100 Mbps` | 实际速度 `12.5 MB/s` |

工具同时显示十进制（SI）和二进制（IEC）单位，硬盘厂商的数字和操作系统显示的数字可以并排对比。

## 时间转换示例

| 输入 | 会看到什么 |
|------|-----------|
| `1 小时` | `60 分钟` / `3,600 秒` / `3,600,000 毫秒` |
| `86400 秒` | `1 天` / `24 小时` |
| `1 年` | `365 天` / `8,760 小时` / `31,536,000 秒` |

## 常见换算场景

- **算实际下载速度：** 输入运营商标的 Mbps，看 MB/s 结果，除以 8 就行
- **设 JWT 过期时间：**「7 天」→ `604,800` 秒——填到认证配置里的数
- **Session 超时：**「30 分钟」→ `1,800,000` 毫秒——填到 session 中间件配置里的数
- **缓存 TTL：**「1 小时」→ `3,600` 秒——CDN 缓存头的标准值
- **数据库容量估算：** 输入预估行大小，乘以行数，看看是 MB 级别还是 GB 级别
