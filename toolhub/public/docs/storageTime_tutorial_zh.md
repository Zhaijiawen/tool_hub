# 存储与时间转换器 — 使用教程

## 使用步骤

### 第一步：选择转换类型
选择要转换**存储**单位还是**时间**单位。

### 第二步：输入数值
在输入框中输入要转换的数值。

### 第三步：选择输入单位
从下拉菜单中选择输入值的单位（如 GB、MB、秒、分钟）。

### 第四步：查看所有转换结果
工具会同时显示所有其他单位的等效值，便于横向比较。

## 存储转换示例

| 输入 | 输出 |
|---|---|
| `1 GB` | `1,000 MB` / `1,024 MiB` / `8,000,000,000 位` |
| `1 TiB` | `1.0995 TB` / `1,099,511,627,776 字节` |
| `100 Mbps` | 实际速度 `12.5 MB/s` |

## 时间转换示例

| 输入 | 输出 |
|---|---|
| `1 小时` | `60 分钟` / `3,600 秒` / `3,600,000 毫秒` |
| `86400 秒` | `1 天` / `24 小时` |
| `1 年` | `365 天` / `8,760 小时` |

## 使用技巧
- 计算网络速度时，记得将 Mbps 除以 8 转换为 MB/s
- 配置超时、缓存 TTL 或 token 过期时间时使用此工具
