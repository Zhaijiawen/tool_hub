# 时间戳转换器 — 使用示例

## Unix 时间戳转人类可读日期

这是最常见的场景。你在数据库或 API 响应里看到一串数字，需要知道它是什么意思。

**输入：** `1712620800`（秒）
**模式：** Unix 时间戳转日期
**输出：**
```
UTC:      2024-04-09 00:00:00
本地:     2024-04-09 08:00:00 (UTC+8)
ISO 8601: 2024-04-09T00:00:00.000Z
```

同一个时间戳，不同时区显示不同时钟读数。本地时间显示的是北京时间（UTC+8）。如果你在不同时区，本地输出会不一样。

**输入：** `1700000000000`（毫秒）
**模式：** Unix 时间戳转日期（毫秒模式）
**输出：**
```
UTC:      2023-11-14 22:13:20
ISO 8601: 2023-11-14T22:13:20.000Z
```

这是 2023 年底某次 JavaScript `Date.now()` 调用的真实输出。原始数字基本不可读——转换器让它一目了然。

## 日期转 Unix 时间戳

调一个需要时间戳参数的 API 请求？用这个方向。

**输入：** `2024-12-25 00:00:00`（UTC）
**模式：** 日期转 Unix 时间戳
**输出：** `1735104000`

现在你知道了 UTC 午夜 2024 年圣诞节对应的 Unix 时间戳。如果 JavaScript 需要毫秒，乘 1000 即可：`1735104000000`。

## 格式转换——电子表格日期转 ISO

常见数据清洗场景：电子表格导出经常是 `MM/DD/YYYY`，但你的数据库要 `YYYY-MM-DD`。

**输入：** `12/25/2024`
**来源格式：** `MM/DD/YYYY`
**目标格式：** `YYYY-MM-DD`
**输出：** `2024-12-25`

批量走一遍转换器，整列就标准化了。

## 转换日志时间戳

日志文件爱用各种自定义格式。Apache 日志用 `[09/Apr/2024:14:30:45 +0000]`，应用日志可能是 `2024-04-09 14:30:45.123`。

**输入：** `09/Apr/2024:14:30:45 +0000`
**来源格式：** `DD/MMM/YYYY:HH:mm:ss Z`
**目标格式：** `YYYY-MM-DD HH:mm:ss`
**输出：** `2024-04-09 14:30:45`

`MMM` 标记处理缩写的月份名，`Z` 处理时区偏移量。一旦全部统一格式，排序和搜索就简单了。

## 获取当前时间戳参考值

需要知道现在的 Unix 时间戳？转换器的「现在」按钮填入当前日期并算出时间戳。写脚本需要硬编码一个「最近的」值，或者验证 API 返回的数据是不是新鲜的时，点一下就行。

如果当前输出显示 `1712000000`，而你的 API 返回的创建时间是 `1711900000`，那大概是不到一天前的数据——不用掏出计算器就能大致估算时间差。

## 排查：1970 年问题

**输入：** `1712620800`
**模式：** 毫秒（模式用错了！）
**输出：** `1970-01-20 19:43:40`

十亿级的时间戳放在毫秒模式下，你会得到 1970 年 1 月的日期——纪元后约 20 天。任何时候看到 1970 年附近的日期，检查你的单位。同样的问题发生在 JavaScript 里，把秒直接传给 `new Date()` 而不乘 1000。

**输入：** `1712620800000`
**模式：** 秒（模式用错了！）
**输出：** 56246 年

反过来，把毫秒级时间戳放进秒级模式，你会得到一个几万年以后的日期。两种错误一旦看到就一目了然，这让转换器成了一个快速的合理性检查工具。
