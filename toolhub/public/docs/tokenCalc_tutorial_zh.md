# AI Token 计算器 — 使用教程

本工具计算文本在大语言模型中的 token 数量，并估算 API 费用。所有计算都在你的浏览器本地完成，文本不会上传。

## 基本用法

1. 在**模型**下拉框选择目标模型（如 GPT-4o、Claude 3.5 Sonnet 等）。不同模型使用不同的分词器，token 数会随之变化。
2. 在文本框里粘贴或输入你的文本 / JSON / 代码。
3. 下方的统计区会**实时**显示：
   - **Token 数量**：模型实际会消耗的 token 数。
   - **字符数**：文本的总字符数（按 Unicode 计）。
   - **词数**：英文按单词计、中文按字计的综合计数。
   - **预估费用**：按所选模型单价估算（in 为输入价，out 为输出价参考）。

## 选择模型的注意事项

- OpenAI 选项按真实分词器精确计数（cl100k_base 或 o200k_base）。
- Anthropic（Claude）选项会标注"近似"——因为 Claude 分词器不公开，这里用 cl100k_base 近似，数量级准确但非精确值。

## 复制与清空

- 点 **复制** 把 Token / 字符 / 词数结果复制到剪贴板。
- 点 **示例** 填入一段示例文本，快速体验。
- 点 **清空** 重置输入框。

## 费用怎么看

费用栏的 `in` 是把当前文本当作 prompt（输入）的估算成本；`out` 是该模型输出单价的参考。如果你要估算"一次完整对话"的花费，把预估 token 数乘以对应单价即可。价格会随厂商调整，请以实际账单为准。

## 隐私

页面底部始终显示一行提示：文本完全本地计算，不上传任何服务器。这也是相比云端分词服务的核心优势。
