# JSONPath 查询 - 使用教程

把 JSONPath 理解成 JSON 的搜索工具。拿到一个 JSON 文档，写个路径表达式，返回所有匹配的节点。不用 grep，不用手动遍历。

## 快速开始

点一下示例按钮（"所有书名"、"价格低于 $10 的书"等）加载演示数据看效果。最好的学习方式是改示例表达式，观察结果变化。

## 用自己的数据

1. 把 JSON 贴到左侧面板
2. 压成一坨的话点格式化
3. 语法错误会被高亮 -- 先修好再查
4. 在右边输入 JSONPath 表达式

输入的同时自动执行查询，不用点任何按钮。

## 最常用的表达式

**定位到字段：**
```
$.user.name
```
直接的属性访问，返回该路径的值。

**获取数组所有元素：**
```
$.items[*]
```
`*` 通配符匹配每个元素。配合属性访问：`$.items[*].id` 取所有 ID。

**递归搜索 -- 找到任意深度的所有匹配键：**
```
$..id
```
不知道字段嵌套多深（也不关心）的时候超级好用。`$..price` 找到文档里所有的 price，不管是 `$.store.book[0].price` 还是 `$.store.bicycle.price`。

**条件过滤：**
```
$.products[?(@.price < 100 && @.inStock == true)]
```
这才是 JSONPath 有意思的地方。`@` 符号在过滤迭代中代表当前数组元素。这句话的意思是："给我所有价格低于 100 且有库存的产品。"

**数组切片：**
```
$.items[0:3]    // 前 3 个
$.items[-3:]    // 后 3 个
$.items[1:4]    // 索引 1、2、3
```
经典的 start:end 切片。start 包含，end 不包含，跟 JavaScript 的 `.slice()` 一样。

**多索引选择：**
```
$.items[0,2,4]
```
选特定索引，不是范围，就是这三个。

**正则过滤：**
```
$.users[?(@.email =~ /.*@gmail\.com/)]
```
`=~` 运算符做正则匹配。适合基于模式的字符串字段过滤。

## 读结果

结果面板显示匹配数量（绿色标签）。结果以格式化 JSON 展示。点复制拿走。如果没匹配到任何东西，结果为空 -- 检查路径是否指向了正确的结构。

## 真实场景模式

API 响应带信封：
```json
{"code": 0, "data": {"users": [{"id": 1, "name": "张三"}, {"id": 2, "name": "李四"}]}}
```
提取所有名字：`$.data.users[*].name`

嵌套分页响应：
```json
{"data": {"items": [...], "total": 100}}
```
查总数：`$.data.total`
拿条目：`$.data.items[*]`

## 注意事项

- JSONPath 区分大小写。`$.User` 不是 `$.user`。
- `..` 递归运算符在超大文档（10 万+ 节点）上可能慢。能精确就精确。
- `=~` 过滤器用的是 JavaScript 正则语法，不是 POSIX。忽略大小写标志可用：`=~ /pattern/i`。
- 部分实现不支持 `[-1]` 取最后一个元素。`jsonpath-plus` 是支持的。
