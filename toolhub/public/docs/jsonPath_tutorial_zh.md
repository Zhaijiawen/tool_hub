# JSONPath 查询 使用教程

## 快速开始

点击顶部「所有书名」等快速示例按钮，即可加载演示数据并自动查询结果。

## 自定义 JSON 数据

1. 将你的 JSON 数据粘贴到左侧输入框
2. 如果格式不整齐，点击「格式化」按钮
3. 如果有语法错误，红色提示会显示具体错误信息

## 编写 JSONPath 表达式

在右侧输入框输入 JSONPath 表达式，输入后自动执行查询。

### 常用表达式示例

**获取所有元素：**
```
$.items[*]
```

**获取特定字段：**
```
$.user.name
```

**递归查找所有 id 字段：**
```
$..id
```

**按条件过滤：**
```
$.products[?(@.price < 100 && @.inStock == true)]
```

**获取数组切片（前3个）：**
```
$.items[0:3]
```

## 查看结果

- 右侧结果区显示匹配数量（绿色标签）
- 结果以格式化 JSON 展示
- 点击「复制」将结果复制到剪贴板
