# 字符编码：屏幕上每个字背后的数字

你在屏幕上看到的每个字符，底层都是一个数字。字符编码就是这些数字到字形之间的映射关系。调试乱码、写正则、处理 URL 的时候，理解这套机制很有用。

## ASCII：7 位的原始世界

ASCII 用 7 位定义了 128 个字符，是几乎所有现代编码的共同祖先：

- 0-31：控制字符（换行、制表、空字符这些不可见的东西）
- 32-126：可打印字符 -- 字母、数字、标点
- 127：DEL

```
A = 65    a = 97    0 = 48    空格 = 32    ! = 33
```

为什么 JavaScript 里 `'a' > 'A'` 是 true？因为小写字母的码点比大写的大。

## Unicode：通用字符集

Unicode 覆盖了地球上几乎所有书写系统，150+ 种文字超过 14 万个字符，每个有唯一码点，比如 `U+0041` 就是 `A`。

### UTF-8：最终赢家

UTF-8 现在基本统治了网络、文件系统和 API。它是变长编码：ASCII 字符 1 字节，中文一般 3 字节，emoji 要 4 字节。最关键的是跟 ASCII 向后兼容。

```
A  = 0x41                    (1 字节 -- 跟 ASCII 一样)
€  = 0xE2 0x82 0xAC         (3 字节)
😀 = 0xF0 0x9F 0x98 0x80    (4 字节)
```

### UTF-16：JavaScript 内部用的

JavaScript 的字符串本质是 UTF-16 码元序列。大多数字符一个 16 位单元搞定，但基本多语言平面之外的字符（比如很多 emoji）需要两个单元 -- 这就是代理对（surrogate pair）。所以 `'😀'.length` 在 JavaScript 里返回 2，即使你眼睛看到的是一个字符。

### URL 编码（百分号编码）

URL 里不能直接放的字符用 `%XX` 表示，XX 是十六进制字节值：

- 空格 = `%20`
- `/` = `%2F`
- `@` = `%40`

### HTML 实体

HTML 里表示特殊字符的几种方式：

- 命名实体：`&amp;` 表示 `&`，`&lt;` 表示 `<`
- 十进制引用：`&#65;` = `A`
- 十六进制引用：`&#x41;` = `A`

这跟安全性直接相关 -- 用户输入如果没做实体编码就直接渲染到 HTML 里，那就是 XSS 漏洞。
