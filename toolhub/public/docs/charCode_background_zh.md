# 字符编码转换器 — 技术背景

## 字符编码基础

字符编码将字符（字母、数字、符号）映射为数字码点，计算机再将其以二进制形式表示。

## ASCII

**ASCII**（美国信息交换标准代码）是最初的 7 位字符编码，定义了 128 个字符：
- 0–31：控制字符（不可打印）
- 32–126：可打印字符（字母、数字、标点）
- 127：DEL

```
A = 65   a = 97   0 = 48   空格 = 32   ! = 33
```

## Unicode

Unicode 是通用字符标准，为所有书写系统中的每个字符分配唯一的**码点**（U+XXXX）。

- 覆盖 150+ 种文字的超过 **14 万**个字符
- 码点范围：U+0000 到 U+10FFFF

### UTF-8

最流行的 Unicode 编码：
- 可变宽度：每个字符 1 到 4 字节
- 兼容 ASCII：前 128 个码点完全一致
- `A` = `0x41`（1 字节）
- `€` = `0xE2 0x82 0xAC`（3 字节）
- `😀` = `0xF0 0x9F 0x98 0x80`（4 字节）

### UTF-16

JavaScript、Java 和 Windows 内部使用：
- 每个字符 2 或 4 字节
- JavaScript 的 `String.charCodeAt()` 返回 UTF-16 码元

### UTF-32

每个字符固定 4 字节——简单但内存效率低。

## HTML 实体

字符可以在 HTML 中表示为：
- **命名实体**：`&amp;`（= `&`）、`&lt;`（= `<`）
- **十进制引用**：`&#65;`（= `A`）
- **十六进制引用**：`&#x41;`（= `A`）

## URL 编码（百分号编码）

URL 中的特殊字符编码为 `%XX`，其中 XX 为十六进制字节值：
- 空格 = `%20`
- `/` = `%2F`
- `@` = `%40`
