# 随机密码生成器 使用教程

## 快速生成一个强密码

1. 保持默认配置（长度16，全字符集）
2. 将数量设为 `1`
3. 点击「生成」
4. 点击结果行复制密码

## 配置说明

### 密码长度

拖动滑块或直接输入数字（4~128）。推荐：
- 普通账号：12~16 位
- 重要账号（银行、邮箱）：20+ 位
- API Key / Secret：32+ 位

### 字符集

| 选项 | 包含字符 |
|------|---------|
| 大写字母 | A-Z（26种） |
| 小写字母 | a-z（26种） |
| 数字 | 0-9（10种） |
| 特殊符号 | `!@#$%^&*()_+-=[]{}|;:,.<>?`（默认28种） |

**自定义符号集**：勾选「特殊符号」后，可以修改符号集合，只使用你需要的符号（有些网站不支持所有特殊字符）。

### 排除易混淆字符

勾选后会去除 `0`（零）、`O`（大写欧）、`l`（小写L）、`1`（一）、`I`（大写i），适合需要抄写或记忆密码的场景。

### 批量生成

生成数量最多 20 个，适合批量为用户生成初始密码。

## 复制方式

- **点击单行**：复制该密码到剪贴板
- **全部复制**：将所有密码以换行分隔复制，方便粘贴到文本文件
