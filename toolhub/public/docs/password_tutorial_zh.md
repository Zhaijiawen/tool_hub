# 随机密码生成器 — 怎么用

## 快速生成

默认配置（16 位、全字符集、数量 1）直接点「生成」就是一个强密码。点一下结果行就复制好了。

## 配置选项

**长度 —** 拖滑块或直接输入（4 到 128）。大概的建议：
- 普通账号：12-16 位
- 邮箱、网银等重要账号：20+ 位
- API Key、Secret：32+ 位

**字符集 —**

| 选项 | 包含 |
|------|------|
| 大写字母 | A-Z（26 种）|
| 小写字母 | a-z（26 种）|
| 数字 | 0-9（10 种）|
| 符号 | `!@#$%^&*()_+-=[]{}|;:,.<>?`（默认 28 种）|

**自定义符号集 —** 勾选符号后可以编辑符号集合。有些网站只接受部分特殊字符（银行网站经常限制成「只允许 !@#$」），把符号集裁成目标系统接受的即可。

**排除易混淆字符 —** 去掉 `0`、`O`、`l`、`1`、`I`——这些在很多字体里看起来一样的字符。密码需要手打或者抄下来的时候特别有用。

**批量生成 —** 数量最多 20。点某一行复制那个密码。「全部复制」一次复制所有，每个一行，贴到密码管理器或文本文件。

## 复制方式

- 点击单行复制该密码
- 「全部复制」一次性复制所有密码，换行分隔
