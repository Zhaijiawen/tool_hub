# Color Picker & Converter — Usage Tutorial

## How to Use

### Picking a Color
Use the color picker wheel or gradient panel to visually select any color. The tool automatically shows the color's values in all supported formats (HEX, RGB, HSL, HSV, CMYK).

### Converting Between Formats
1. Enter a color value in any supported format (e.g., `#3498db`, `rgb(52, 152, 219)`, `hsl(204, 70%, 53%)`)
2. The tool instantly converts and displays it in all other formats
3. Click the copy icon next to any format to copy that value

### Supported Input Formats
- **HEX**: `#RGB`, `#RRGGBB`, `#RRGGBBAA`
- **RGB**: `rgb(r, g, b)` or `rgba(r, g, b, a)`
- **HSL**: `hsl(h, s%, l%)` or `hsla(h, s%, l%, a)`
- **HSV/HSB**: h, s, v as numbers

## Tips

- **Design consistency**: Copy HEX values for use in CSS, Tailwind, or design tools
- **Accessibility**: A well-chosen contrast ratio between text and background colors improves readability for users with visual impairments
- **Opacity control**: Adjust the alpha slider to add transparency to any color
