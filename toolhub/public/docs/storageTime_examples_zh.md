# 存储与时间转换器 — 使用示例

## 存储示例

### 1.5 TB 等于多少 MB？
`1.5 TB = 1,500,000 MB`（SI 十进制）
`1.5 TiB = 1,572,864 MiB`（IEC 二进制）

### 我的实际下载速度是多少？
网速：`100 Mbps`
→ `100 ÷ 8 = 12.5 MB/s`

下载 1 GB 文件所需时间：`1,000 ÷ 12.5 = 80 秒`

### 存储空间规划
数据库备份：`500 MB`
每日增长：`10 MB/天`
30 天后：`500 + (10 × 30) = 800 MB`

## 时间示例

### Session 超时配置
系统要求：30 分钟 session 超时
转为毫秒：`30 × 60 × 1000 = 1,800,000 ms`
转为秒：`1,800 s`

### Token 过期时间
JWT access token：`15 分钟 = 900 秒`
JWT refresh token：`7 天 = 604,800 秒`

### 缓存 TTL
浏览器缓存：`1 年 = 31,536,000 秒`
API 响应缓存：`5 分钟 = 300 秒`
