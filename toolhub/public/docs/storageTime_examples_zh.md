# 存储与时间转换器 — 使用示例

## 存储

**1.5 TB 等于多少 MB？**
- SI（十进制）: 1.5 TB = 1,500,000 MB
- IEC（二进制）: 1.5 TiB = 1,572,864 MiB

**实际下载速度 —**
宽带标称 100 Mbps。
100 / 8 = 12.5 MB/s 实际速度。
一个 1 GB 的文件按这个速度：1,000 / 12.5 = 80 秒。

**存储空间增长 —**
数据库备份现在 500 MB，每天增长 10 MB。
30 天后：500 + (10 x 30) = 800 MB。

**一张卡能装多少照片 —**
手机照片每张约 8 MB。256 GB 手机 = 256,000 MB / 8 = 约 32,000 张。扣掉系统和 App，大概 25,000 张。

## 时间

**Session 超时 —**
需求：30 分钟无操作自动超时。
毫秒（session 配置要的）：30 x 60 x 1,000 = 1,800,000 ms。
秒：1,800 s。

**JWT Token 过期 —**
Access token：15 分钟 = 900 秒。
Refresh token：7 天 = 604,800 秒。
就是填到认证库配置里的那两个数。

**缓存 TTL —**
静态资源浏览器缓存：1 年 = 31,536,000 秒。
API 响应缓存：5 分钟 = 300 秒。
CDN 边缘缓存：1 小时 = 3,600 秒。

**限流窗口 —**
「每 15 分钟 100 次请求」= 每 900 秒 100 次。滑动窗口的大小。

**后台任务间隔 —**
「每 6 小时执行一次」= 每 21,600 秒。大多数任务调度器接受秒作为间隔单位。
