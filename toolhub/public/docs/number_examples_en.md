# Number Converter — Examples

## Example 1: Decimal 255

| Base | Value |
|---|---|
| Decimal | `255` |
| Binary | `11111111` |
| Octal | `377` |
| Hexadecimal | `FF` |

## Example 2: Hexadecimal 1A3F

| Base | Value |
|---|---|
| Hexadecimal | `1A3F` |
| Decimal | `6719` |
| Binary | `1101000111111` |
| Octal | `15077` |

## Example 3: Binary 10101010

| Base | Value |
|---|---|
| Binary | `10101010` |
| Decimal | `170` |
| Octal | `252` |
| Hexadecimal | `AA` |

## Practical Uses

- `0xFF` in a color code = channel value 255 (max intensity)
- Unix permission `chmod 755` = `rwxr-xr-x` = binary `111 101 101`
- Memory address `0x7FFE5B4C2A30` is a 64-bit hex address
