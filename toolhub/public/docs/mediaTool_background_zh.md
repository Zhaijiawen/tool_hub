# 音视频处理 — 技术背景

这个工具在浏览器里用 **FFmpeg** 的 WASM 版本处理音视频，包含三个功能：**视频转码**、**提取音频**、**视频转 GIF**。首次使用会下载约 32MB 的 FFmpeg 核心（带进度条、可取消、之后走缓存秒开），整个过程在本地完成。

## 视频转码

- **MP4 (H.264)**：兼容性最好，几乎任何设备都能播。
- **WebM (VP8)**：体积通常更小，适合网页嵌入。
- 质量用 **CRF**（恒定速率因子）表示，范围 18-40，数字越大质量越低、文件越小。日常用 23-28 是平衡点。
- 可选缩放：原尺寸、1280px、960px、720px、480px。

## 提取音频

把视频（或音频）里的音轨抽出来，支持 **MP3 / M4A(AAC) / WAV / OGG / Opus**。比如从一段讲座录像里提取纯音频方便通勤听。

## 视频转 GIF

把一段视频变成动图。可调 **帧率**（5-30fps，越高越流畅越大）和 **宽度**（80-800px，越小越省体积）。GIF 不支持音频，所以只取画面。

## 隐私与限制

- 文件不离开浏览器，适合处理私人录像。
- FFmpeg WASM 不支持读取 `stderr` 的详细日志，出错时只能给笼统提示；某些极特殊的编码组合可能不被 WASM 构建支持。
- 处理时长取决于文件大小和你的设备性能，大视频请耐心等待。
