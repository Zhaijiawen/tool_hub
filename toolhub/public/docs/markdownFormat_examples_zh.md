# Markdown 格式化器 — 使用示例

## 场景一：表格对齐

手工写的表格分隔符往往不平整，阅读源码时要凑近了看：

```markdown
|姓名|年龄|城市|
|-|-|-|
|张三|25|北京|
|李四|30|上海|
```

格式化后，分隔行补全，列间加上空格：

```markdown
| 姓名 | 年龄 | 城市 |
| ---- | ---- | ---- |
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
```

不只三列——无论多少列，Prettier 都会根据内容宽度统一对齐。

## 场景二：多余空行清理

多人编辑的文档经常出现不规则的连续空行：

```markdown
# 项目说明



## 安装

克隆仓库后运行以下命令：



npm install



## 配置
```

格式化后，多余空行被压缩到一个，标题前也自动保留一个空行：

```markdown
# 项目说明

## 安装

克隆仓库后运行以下命令：

npm install

## 配置
```

## 场景三：代码块留白

围栏代码块紧贴上文或下文时，渲染没问题，但源码阅读体验很差。下面是一段典型的「挤在一起」的 Markdown：

````markdown
## API 说明

获取用户列表：
```bash
curl https://api.example.com/users
```
响应为 JSON 数组。
````

格式化后，代码块前后自动加上空行，源码呼吸感好很多：

````markdown
## API 说明

获取用户列表：

```bash
curl https://api.example.com/users
```

响应为 JSON 数组。
````
