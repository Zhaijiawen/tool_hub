# CIDR 网段计算 -- 使用指南

两种输入模式，结果一样。看你手头有什么信息就选哪种。

## CIDR 模式

输入 CIDR 表达式就行了，比如 `192.168.1.0/24`。计算器会自动算出网络地址、广播地址、可用范围、主机数量和地址类型。

不需要精准输入网络地址 -- `192.168.1.100/24` 也行。工具会自动推算出所属的网络地址。

**常用输入示例：**
- `10.0.0.0/8` -- 大型私有网络
- `172.16.0.0/12` -- 中型私有网络
- `192.168.0.0/16` -- 小型私有网络
- `192.168.1.1/32` -- 单主机路由
- `10.0.0.0/30` -- 点对点链路

## IP + 掩码模式

如果你手头是点分十进制的子网掩码而不是 CIDR 写法，用这个模式：

1. **IP 地址**：`192.168.1.0`
2. **子网掩码**：`255.255.255.0`（直接写 `24` 也行，两种都认）

结果跟 CIDR 模式完全一样，只是输入形式不同。

## 计算结果怎么看

| 字段 | 含义 |
|---|---|
| 网络地址 | 网段的起始地址，标识网络本身 |
| 广播地址 | 发到这个地址，子网内所有主机都收到 |
| 子网掩码 | 点分十进制写法 |
| 前缀长度 | `/24` 里的那个数字 |
| 可用 IP 数量 | 实际上能分配给设备的地址数 |
| IP 范围 | 可分配的第一个到最后一个地址 |
| IP 类型 | 私有（RFC 1918）、回环、本地链路还是公网 |

## 判断 IP 是否在网段内

算出网段信息后，用 IP 检查功能测试某个地址属不属于这个网段：

```
网段：192.168.1.0/24
输入：192.168.1.150  →  在网段内
输入：192.168.2.1    →  不在网段内
```

排查路由问题或者验证防火墙规则的时候特别有用。

## 常见网段速查

| 网段 | 用途 |
|---|---|
| `127.0.0.0/8` | 本地回环（localhost -- 包不出本机） |
| `10.0.0.0/8` | A 类私有 |
| `172.16.0.0/12` | B 类私有 |
| `192.168.0.0/16` | C 类私有 |
| `169.254.0.0/16` | 本地链路（DHCP 失败时自动分配的那个） |
| `0.0.0.0/0` | 默认路由（匹配所有流量） |
| `255.255.255.255/32` | 受限广播 |
