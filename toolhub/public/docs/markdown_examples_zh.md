# Markdown 转换器 — 使用示例

## 示例 1：完整文档结构

**Markdown 输入：**
```markdown
# 项目标题

项目的简短描述。

## 功能特性

- 功能 A
- 功能 B
- 功能 C

## 安装方法

```bash
npm install my-package
```

## 使用说明

详情请参阅[文档](https://docs.example.com)。

> **注意**：请先配置好你的环境。
```

**渲染输出：**

包含标题层级、无序列表、代码块、链接和引用块的结构化 HTML 文档。

---

## 示例 2：表格

**输入：**
```markdown
| 姓名  | 角色       | 部门   |
|-------|------------|--------|
| Alice | 工程师     | 后端   |
| Bob   | 设计师     | 前端   |
| Carol | 产品经理   | 产品   |
```

**输出：**
带有表头行和数据行的样式化 HTML 表格。

---

## 示例 3：任务列表（GFM）

**输入：**
```markdown
- [x] 设计数据库 Schema
- [x] 搭建 CI/CD 流水线
- [ ] 编写单元测试
- [ ] 部署到生产环境
```

**输出：**
带复选框的列表——已完成的条目显示为勾选状态。
