# SQLite 工具 — 技术背景

这个工具在浏览器里用 **wa-sqlite**（SQLite 编译成 WebAssembly）直接打开、查询、修改 SQLite 数据库。无需安装任何软件，数据库文件也不上传。

## 三种打开方式

- **上传导入**：从本地选一个 `.db` / `.sqlite` / `.sqlite3` 文件，导入到浏览器的 OPFS 存储。
- **已保存**：列出之前导入/创建、存在 OPFS 里的库，点开即用。
- **新建**：新建一个空库，可选存在 **OPFS**（持久化，关掉网页还在）或 **内存**（临时，关掉就没）。

## OPFS 是什么

OPFS（Origin Private File System）是浏览器提供的、归当前网站私有的文件系统。存在这里的数据库会持久保存，下次打开网页还在。部分浏览器或隐私模式可能不支持 OPFS，那时工具会提示你，只能用内存模式。

## 能做什么

- 左侧列出所有表（含视图），点表名直接浏览前 200 行。
- 右侧写 SQL，点「运行」执行。SELECT 结果以表格展示，可导出 CSV；INSERT/UPDATE/DELETE 显示影响行数。
- 顶栏可「导出」当前库为 `.sqlite3` 文件下载。

## 隐私

数据库完全在本地处理。导入的文件只进 OPFS，不上传服务器。

> 提示：SQLite 引擎本身也是 WASM，首次使用需下载，带进度条、可取消、之后缓存。
