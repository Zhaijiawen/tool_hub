# 条码识别 · 技术背景

## 这是什么
条码识别在浏览器本地解码图片或摄像头画面中的一维 / 二维条码，输出码制类型与内容文本。整个过程在本地完成，图片与摄像头画面不上传任何服务器。

## 支持格式
基于 **ZXing** 解码引擎，支持常见码制：
- 二维码：QR Code、Data Matrix、Aztec、PDF 417
- 一维码：EAN-13 / EAN-8、UPC-A / UPC-E、Code 128、Code 39、Code 93、ITF、Codabar 等

## 两种模式
- **上传图片**：选择或拖拽一张含条码的图片，点击识别。
- **摄像头扫描**：调用设备摄像头实时取景，扫到即解码，适合手机 / 笔记本前置或后置镜头。

## 为什么在本地做
- **隐私**：图片与摄像头画面仅在你的浏览器内处理，从不离开设备。
- **免费**：无需调用云端按次付费 API。
- **离线可用**：模型在浏览器内运行，断网也能用（首次加载依赖库缓存）。

## 使用提示
- 条码需清晰、光照均匀、无明显畸变。
- 一维码尽量正对、铺满画面；二维码保持完整四个定位角。
- 反光、模糊、过度压缩会降低识别率。

## 隐私说明
本工具仅调用本地解码库，不收集、不上传任何图像或识别结果。
