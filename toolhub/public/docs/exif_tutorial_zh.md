# 图片 EXIF 查看器 — 怎么用

## 把照片放进来

把图片文件拖到上传区域，或者点一下选文件。JPEG 和 HEIC（iPhone 拍照格式）是最常带 EXIF 的格式，TIFF 和 WebP 也能解析。

## 能看到什么

工具把 EXIF 数据分成了几个标签页，不用对着一堆原始字段发愣：

**「基本信息」标签 —** 相机品牌型号、拍摄时间、图片分辨率、色彩空间。快速看一眼用的。

**「拍摄参数」标签 —** 快门速度、光圈、ISO、焦距、闪光灯状态。还原拍摄现场用的。

**「GPS」标签 —** 如果照片有位置信息，这里显示十进制度数格式的经纬度。复制粘贴到高德或百度地图就能看到拍摄位置。

## 复制数据

每行右侧有复制按钮，只复制该字段的值。顶部还有「复制全部 EXIF」按钮，把所有字段按 `key: value` 格式一次性导出，适合贴到文档或发给人看。

## 为什么有的照片没 EXIF

这种情况其实挺多的：

1. 截图——截图不包含 EXIF
2. 微信/微博下载的图——这些平台上传时会清掉 EXIF
3. Photoshop/Lightroom 导出时勾了「移除元数据」
4. PNG 格式——PNG 不支持标准 EXIF（有些工具会把元数据写成 XMP）
5. 太老或者太基础的设备拍的，本身就不记录 EXIF
