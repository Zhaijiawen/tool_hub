# 数字大写转换 - 示例

## 整数转换

| 数字 | 大写 | 小写 |
|---|---|---|
| 0 | 零 | 零 |
| 1 | 壹 | 一 |
| 10 | 壹拾 | 一十 |
| 100 | 壹佰 | 一百 |
| 1000 | 壹仟 | 一千 |
| 10000 | 壹万 | 一万 |
| 100000 | 壹拾万 | 一十万 |
| 1000000 | 壹佰万 | 一百万 |
| 100000000 | 壹亿 | 一亿 |

注意小写模式下 10 是 `一十` -- 自然读法。但大写是 `壹拾` -- 正式写法。中文数字分组单位是 10^4（万）和 10^8（亿），不是西方的 10^3（千）和 10^6（百万）。这就是为什么 `100000` 变成 `壹拾万`（10 x 10,000）而不是基于"十万"的某种表达。

## 财务金额

| 数字 | 财务大写 | 说明 |
|---|---|---|
| 0 | 零元整 | 零金额 |
| 1 | 壹元整 | 整数加"整" |
| 10 | 壹拾元整 | 十元整 |
| 100.50 | 壹佰元伍角 | 有角无分 |
| 100.05 | 壹佰元零伍分 | 角为零分不为零，注意"零"的插入 |
| 100.55 | 壹佰元伍角伍分 | 角分都有 |
| 1234.56 | 壹仟贰佰叁拾肆元伍角陆分 | 完整金额 |
| 10000.01 | 壹万元零壹分 | 大额带分 |
| 100000000 | 壹亿元整 | 一亿元 |
| 123456789.99 | 壹亿贰仟叁佰肆拾伍万陆仟柒佰捌拾玖元玖角玖分 | 最大真实支票金额 |

最下面那个大数 -- 123,456,789.99 -- 分解如下：
- 1 亿（100,000,000）
- 2345 万（23,450,000）
- 6789（6,789）
- .99 = 9 角 9 分

中文在万和亿边界分组，所以读起来是 `壹亿贰仟叁佰肆拾伍万...` 而不是西方的分组方式。如果不熟悉这套系统，工具帮你正确处理了，不用自己操心。

## 负数

| 数字 | 大写 |
|---|---|
| -100 | 负壹佰 |
| -1234.56 | 负壹仟贰佰叁拾肆元伍角陆分（财务格式） |

负数前缀"负"加在金额前面。实际支票上很少写负数金额，但完整性支持。

## 实际对比：为什么大写重要

想象一张手写欠条：`欠款 1000 元`。用"一"写的话，加个笔画就变成了"二千"或"三千"。法律文书用"壹仟"就是防这个 -- 笔画改不成别的数字，改了也很明显。

同一张欠条用大写：`欠款壹仟元整` -- 试试把壹改成贰、叁或者任何别的数字。改不了，一改就留痕。这就是这套系统存在的全部意义，几百年来一直如此。
