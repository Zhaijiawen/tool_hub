# 数字转换器 — 使用示例

## 示例 1：十进制 255

| 进制 | 值 |
|---|---|
| 十进制 | `255` |
| 二进制 | `11111111` |
| 八进制 | `377` |
| 十六进制 | `FF` |

## 示例 2：十六进制 1A3F

| 进制 | 值 |
|---|---|
| 十六进制 | `1A3F` |
| 十进制 | `6719` |
| 二进制 | `1101000111111` |
| 八进制 | `15077` |

## 示例 3：二进制 10101010

| 进制 | 值 |
|---|---|
| 二进制 | `10101010` |
| 十进制 | `170` |
| 八进制 | `252` |
| 十六进制 | `AA` |

## 实际应用

- 颜色代码中的 `0xFF` = 通道值 255（最大亮度）
- Unix 权限 `chmod 755` = `rwxr-xr-x` = 二进制 `111 101 101`
- 内存地址 `0x7FFE5B4C2A30` 是 64 位十六进制地址
