# PNG 优化 — 使用教程

1. 上传一个 PNG 图片（拖拽或点击）。工具显示预览和原始大小。
2. 调参数：
   - **级别**：往右压得小但慢，默认 3。
   - **交错**：一般关。
   - **优化 Alpha**：一般开（有透明通道时更有用）。
3. 点「优化」。首次会下载 Oxipng 的 WASM（带进度、可取消、之后缓存）。
4. 完成后显示原始大小、优化后大小和节省百分比，点下载保存。

> 节省 ≤ 0% 时提示「无收益」——说明这图已经压得很好了。

## 小提示

- 网页要用的 PNG（图标、截图、logo）先过一遍优化，能省不少带宽。
- 级别拉到 6 压得最狠，但大图会慢；日常用 3-4 足够。
- 透明 PNG 一定开着「优化 Alpha」。
