# AI 提示词工具箱 — 使用示例

## 示例 1：代码审查提示词

```
你是一位精通 {{language}} 的资深软件工程师。

请审查以下代码，关注：
1. Bug 和潜在错误
2. 性能问题
3. 安全漏洞
4. 代码风格和可读性

代码：
```{{language}}
{{code}}
```

请针对发现的每个问题提供具体、可操作的反馈。
```

## 示例 2：博客文章大纲生成

```
你是一位专业的技术写作者。请为主题为"{{topic}}"的博客文章创建详细大纲。

要求：
- 目标受众：{{audience}}
- 写作风格：{{tone}}（如：信息性、轻松、权威）
- 篇幅：约 {{word_count}} 字
- 包含：引言、3-5 个带子标题的主要章节、结语和行动号召

以 Markdown 格式返回大纲。
```

## 示例 3：SQL 查询生成器

```
你是一位数据库专家。根据以下需求生成优化的 SQL 查询：

数据库类型：{{database_type}}
表结构：{{schema}}
需求：{{requirement}}

包含：
- 完整的 SQL 查询语句
- 查询功能的简要说明
- 可以提升性能的索引建议
```

## 示例 4：英文语法纠错

```
请纠正以下文本的语法错误并提升清晰度。保持原意不变，只做必要的修改。

文本：{{text}}

输出格式：
- 修正后的文本
- 修改内容列表
