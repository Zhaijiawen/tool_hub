# AI 提示词工具箱 — 模板示例

## 代码审查

```
你是一位精通 {{language}} 的资深软件工程师。

请审查以下代码，关注：
1. Bug 和潜在错误
2. 性能问题
3. 安全漏洞
4. 代码风格和可读性

代码：
```{{language}}
{{code}}
```

请针对发现的每个问题提供具体、可操作的反馈。
```

这个模板好在哪里：指定了角色、列出了审查重点、要求给出可操作的反馈——不是「这里写得不好」，而是「这里可以这样改」。

## 博客文章大纲

```
你是一位专业的技术写作者。请为主题为"{{topic}}"的博客文章创建详细大纲。

要求：
- 目标受众：{{audience}}
- 写作风格：{{tone}}（如：信息性、轻松、权威）
- 篇幅：约 {{word_count}} 字
- 包含：引言、3-5 个带子标题的主要章节、结语和行动号召

以 Markdown 格式返回大纲。
```

适合动手写之前先理清结构。tone 参数特别有用——「轻松」和「权威」从同一个主题产出的提纲完全不同。

## SQL 查询生成

```
你是一位数据库专家。根据以下需求生成优化的 SQL 查询：

数据库类型：{{database_type}}
表结构：{{schema}}
需求：{{requirement}}

包含：
- 完整的 SQL 查询语句
- 查询功能的简要说明
- 可以提升性能的索引建议
```

索引建议这部分让这个模板真正有价值——把一个查询生成器变成了一个迷你查询优化器。

## 语法纠错和表达优化

```
请纠正以下文本的语法错误并提升清晰度。保持原意不变，只做必要的修改。

文本：{{text}}

输出格式：
- 修正后的文本
- 修改内容列表
```

让模型列出改了什么很重要——你能从中学到自己哪里写得不对，还能验证模型有没有曲解你的原意。
