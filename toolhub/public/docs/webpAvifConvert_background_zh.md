# WebP / AVIF 转换 — 技术背景

这个工具用 **jsSquash** 的 WASM 编码器在浏览器里把图片转成 **WebP** 或 **AVIF**，全程本地、不上传。

## 为什么要转这两种格式

- **WebP**：比同等 JPEG/PNG 小 25-35%，支持有损/无损和透明，浏览器支持已全面覆盖。是日常替代 JPEG/PNG 的好选择。
- **AVIF**：基于 AV1 视频编码，压缩率比 WebP 还好（同等质量常再小 50%），但编码更慢、文件更大时需要更多内存。现代浏览器都支持。

## 参数

- **WebP**：质量 0-100（默认 75），可切**无损**模式。
- **AVIF**：质量 0-100（默认 50）、**速度** 0-10（默认 6，越大越快但稍大）、可切**无损**模式。

## 编码器的体积

- WebP 编码器走 SIMD 版（约 338KB）或普通版（约 275KB），工具按你的设备能力自动选。
- AVIF 编码器约 3.3MB，首次下载正好展示全局进度条，之后缓存。

## 解码

输入图片用浏览器原生解码（Canvas / `createImageBitmap`），所以 JPG/PNG/WebP/GIF/BMP 都能读，现代浏览器也能读 AVIF 输入。超大图片编码会慢、占内存多，工具会提示。

## 隐私

图片只在本地处理。
