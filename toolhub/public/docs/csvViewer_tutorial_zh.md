# CSV / TSV 预览解析 - 使用教程

## 快速开始

CSV / TSV 预览工具支持两种输入方式：

1. **直接粘贴文本**：将 CSV/TSV 内容粘贴到文本框，即时预览
2. **上传文件**：点击"上传文件"区域，选择 `.csv`、`.tsv` 或 `.txt` 文件（最大 5MB）

## 选择分隔符

工具默认使用**自动检测**模式，会根据内容中各分隔符的出现频率自动判断最可能的分隔符。

如果自动检测结果不正确，可以在下拉菜单中手动切换：

| 选项 | 适用场景 |
|------|---------|
| 自动检测 | 不确定分隔符时，让工具自动判断 |
| 逗号（,）| 标准 CSV，Excel 默认导出 |
| 制表符（Tab）| TSV 文件，数据库导出 |
| 分号（;）| 欧洲 Excel 导出 |
| 竖线（\|）| 自定义日志格式 |
| 空格 | nginx/Apache 日志 |

## 查看解析结果

解析成功后，数据会以**表格形式**展示：

- **第一行作为表头**：默认将首行数据当作列名
- **行列信息**：表格上方显示总行数和列数
- **数据预览**：最多显示 10,000 行，超出部分提示截断

## 复制数据

点击右上角的**"复制"**按钮，可将当前解析内容以 JSON 数组格式复制到剪贴板，便于在代码中使用：

```json
[
  { "姓名": "张三", "城市": "北京", "年龄": "28" },
  { "姓名": "李四", "城市": "上海", "年龄": "32" }
]
```

## 常见问题

### 中文显示乱码

原因：文件编码为 GBK，浏览器按 UTF-8 解析。

解决方式：用记事本/VS Code 打开文件，另存为 UTF-8 编码后重新上传。

### 解析后列数不对

原因：部分字段内含有未转义的分隔符。

解决方式：切换到"自动检测"模式，或手动尝试其他分隔符选项。

### 上传后显示空白

原因：文件为空，或只有表头没有数据行。

解决方式：检查文件内容是否正确。
