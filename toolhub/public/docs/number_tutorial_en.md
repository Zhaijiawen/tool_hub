# Number Converter — Usage Tutorial

## How to Use

### Step 1: Select Input Format
Choose the format of the number you want to convert:
- **Decimal** — standard base-10 number
- **Binary** — base-2 number (digits 0 and 1 only)
- **Octal** — base-8 number (digits 0–7 only)
- **Hexadecimal** — base-16 number (digits 0–9 and A–F)

### Step 2: Enter the Number
Type the number in the input field. The tool validates the input in real time to ensure it matches the selected format.

### Step 3: View Results
All converted values appear instantly in the output section, showing the number in all supported bases.

## Tips

- Hexadecimal input is case-insensitive (`FF` = `ff`)
- Negative numbers can be entered in decimal; the binary result shows two's complement representation
- Use this tool to understand how the same value looks in different number systems
