# 查找与替换 — 使用示例

## 示例 1：简单单词替换

**查找：** `color`
**替换：** `colour`
**输入：**
```
The color of the sky is blue. I love this color.
```
**输出：**
```
The colour of the sky is blue. I love this colour.
```

## 示例 2：去除 HTML 标签（正则模式）

**查找：** `<[^>]+>`
**替换：** *（留空）*
**输入：**
```html
<p>你好 <strong>世界</strong>，这是一个<em>测试</em>。</p>
```
**输出：**
```
你好 世界，这是一个测试。
```

## 示例 3：重新格式化日期（正则模式）

**查找：** `(\d{4})-(\d{2})-(\d{2})`
**替换：** `$3/$2/$1`
**输入：**
```
活动日期：2024-03-15
```
**输出：**
```
活动日期：15/03/2024
```

## 示例 4：删除空行（正则模式）

**查找：** `^\n`
**替换：** *（留空）*
**输入：**
```
第一行

第二行


第三行
```
**输出：**
```
第一行
第二行
第三行
