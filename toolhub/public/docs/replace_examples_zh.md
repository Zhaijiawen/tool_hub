# 查找与替换 — 使用示例

## 简单单词替换

**查找：** `color`
**替换：** `colour`
**输入：**
```
The color of the sky is blue. I love this color.
```
**输出：**
```
The colour of the sky is blue. I love this colour.
```

最基础的用法——找字面字符串，换成另一个字面字符串。没有正则，没有反向引用，纯替换。如果你在做美式到英式英语的本地化，这个再加几轮替换就完事了。

## 剥离 HTML 标签

**查找：** `<[^>]+>`
**替换：** *（留空）*
**输入：**
```html
<p>你好 <strong>世界</strong>，这是一个<em>测试</em>。</p>
```
**输出：**
```
你好 世界，这是一个测试。
```

模式 `<[^>]+>` 匹配一个开尖括号、然后一个或多个非闭尖括号的字符、再一个闭尖括号——任何 HTML 标签一把抓。替换留空就把它们全删了。这个模式处理不了跨行的带属性自闭合标签，但对付单行标记绰绰有余。

## 日期格式转换

**查找：** `(\d{4})-(\d{2})-(\d{2})`
**替换：** `$3/$2/$1`
**输入：**
```
活动日期：2024-03-15
```
**输出：**
```
活动日期：15/03/2024
```

三个捕获组分别拿了年、月、日，替换字符串重新排列它们的顺序。分隔符也可以一起换——把替换改成 `$2-$3-$1` 就变成了月-日-年格式，如果你的系统需要那样的话。关键是数据没丢，只是呈现方式变了。

## 删除空行

**查找：** `^\n`
**替换：** *（留空）*
**输入：**
```
第一行

第二行


第三行
```
**输出：**
```
第一行
第二行
第三行
```

`^` 锚定行首（需要多行模式，工具在适当时会启用）。`\n` 匹配换行符。合在一起匹配完全空白的行。执行一次，连续空行就被压缩了。要注意 `^\n` 匹配的是空行加一个换行符——它不会碰文件末尾没有换行符结尾的尾随空行，而这通常正是你想要的效果。

## 去除行尾空格

**查找：** `[ \t]+$`
**替换：** *（留空）*
**输入：**
```
function foo() {   
  return 42;      
}                
```
**输出：**
```
function foo() {
  return 42;
}
```

`[ \t]+` 匹配一个或多个空格或制表符，`$` 锚定到每行末尾。这条把 lint 工具天天抱怨的不可见垃圾清理干净，又不影响有意的缩进。如果你在跟 Windows 风格的换行符打交道，把 `\r` 也加到字符类里就好。
