# User Agent 解析器 — 使用教程

## 使用步骤

### 第一步：获取 User Agent
页面加载时工具会自动检测并显示你的浏览器当前 User Agent 字符串。

### 第二步：解析任意 UA 字符串
也可以手动在输入框中粘贴任意 User Agent 字符串进行分析。

### 第三步：查看解析信息
工具解析 UA 字符串并展示：
- **浏览器**：名称和版本
- **操作系统**：系统名称和版本
- **设备类型**：桌面端、移动端或平板
- **引擎**：渲染引擎和版本

## 获取 User Agent 字符串的方法

- **浏览器开发者工具**：打开 Console 标签，输入 `navigator.userAgent`
- **HTTP 请求头**：在服务器日志或 DevTools 网络标签 → 请求头中查看
- **在线工具**：本页面会自动检测你的 UA

## 常见使用场景

1. **调试移动端布局**：确认用户使用的 iOS 或 Android 版本
2. **验证爬虫流量**：检查请求是否来自 Googlebot 或伪造的 UA
3. **跨浏览器测试**：在错误追踪系统中记录 UA 以复现问题
4. **API 兼容性**：检查客户端 SDK 版本是否过旧

## 使用技巧
- 在升级浏览器前复制 UA 字符串，便于前后对比
- 服务端 UA 检测应使用可靠的库（如 `ua-parser-js`、`device-detector`）
