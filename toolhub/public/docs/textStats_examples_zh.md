# 文本统计 - 使用示例

## 示例 1：英文文章统计

**输入：**

```
The quick brown fox jumps over the lazy dog.
This is a sample sentence to demonstrate word counting.

Paragraph two starts here. It contains multiple sentences.
Each sentence ends with appropriate punctuation.
```

**统计结果参考：**

| 指标 | 值 |
|------|-----|
| 总字符数 | ~175 |
| 单词数 | ~33 |
| 行数 | 5 |
| 段落数 | 2 |
| 句子数 | 4 |
| 阅读时间 | 不足 1 分钟 |

## 示例 2：中文文章统计

**输入：**

```
人工智能正在深刻改变我们的生活方式。从智能手机的语音助手，到医疗影像的辅助诊断，AI技术已经渗透到各个领域。

然而，技术的快速发展也带来了新的挑战。数据隐私、算法偏见、就业替代等问题值得我们深思。

面向未来，如何在享受技术红利的同时，妥善处理这些社会问题，是每个时代参与者都需要思考的命题。
```

**统计结果参考：**

| 指标 | 值 |
|------|-----|
| 总字符数 | ~160 |
| 单词数（汉字数）| ~140 |
| 段落数 | 3 |
| 句子数 | 5 |
| 阅读时间 | 不足 1 分钟 |

## 示例 3：中英混排

**输入：**

```
今年的 JavaScript 生态依然活跃，React 18 正式引入并发特性，
Vue 3 的 Composition API 也越来越被社区接受。

选择前端框架时，需要综合考虑团队技术栈、学习成本和社区支持等因素。
最终的目标是构建高质量的 User Experience。
```

**说明：**

工具会分别统计中文字数和英文单词数，汇总后计算阅读时间。

## 示例 4：词频分析

**场景：** 检查一篇技术博客是否过度使用某些词

**输入后，高频词可能显示：**

| 排名 | 词 | 出现次数 |
|------|-----|---------|
| 1 | 功能 | 12 次 |
| 2 | 用户 | 9 次 |
| 3 | 系统 | 8 次 |
| 4 | 数据 | 7 次 |
| 5 | 优化 | 6 次 |

如果某个词出现次数远超其他词，可考虑用同义词替换以提升文章多样性。

## 典型应用对照

| 场景 | 关注指标 |
|------|---------|
| 社交媒体发文 | 总字符数（Twitter ≤ 280）|
| 微信公众号正文 | 去空格字符数（800~2000）|
| 论文摘要 | 单词数（一般 ≤ 250 词）|
| 简历自我介绍 | 字符数 + 词频（避免重复）|
| 翻译报价估算 | 单词数 / 字数 |
| SEO 文章检查 | 单词数（建议 ≥ 1000 词）|
