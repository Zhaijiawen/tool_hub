# 文本统计 — 使用示例

## 英文文章

**输入：**
```
The quick brown fox jumps over the lazy dog.
This is a sample sentence to demonstrate word counting.

Paragraph two starts here. It contains multiple sentences.
Each sentence ends with appropriate punctuation.
```

**统计结果参考：**

| 指标 | 值 |
|------|-----|
| 总字符数 | ~175 |
| 单词数 | ~33 |
| 行数 | 5 |
| 段落数 | 2 |
| 句子数 | 4 |
| 阅读时间 | < 1 分钟 |

## 中文文章

**输入：**
```
人工智能正在深刻改变我们的生活方式。从智能手机的语音助手，到医疗影像的辅助诊断，AI技术已经渗透到各个领域。

然而，技术的快速发展也带来了新的挑战。数据隐私、算法偏见、就业替代等问题值得我们深思。
```

**统计结果参考：**

| 指标 | 值 |
|------|-----|
| 总字符数 | ~115 |
| 汉字数 | ~100 |
| 段落数 | 2 |
| 句子数 | 4 |
| 阅读时间 | < 1 分钟 |

## 中英混排

**输入：**
```
React 18 正式引入并发特性，Vue 3 的 Composition API 也越来越被社区接受。
选择前端框架时，需要综合考虑团队技术栈、学习成本和社区支持等因素。
最终的目标是构建高质量的 User Experience。
```

工具分别统计中文字数和英文单词数，然后加权计算阅读时间。

## 词频分析示例

把一篇关于 React 的技术博客丢进去，高频词可能是：

| 排名 | 词 | 次数 |
|------|-----|------|
| 1 | 组件 | 12 |
| 2 | React | 9 |
| 3 | 状态 | 8 |
| 4 | 渲染 | 7 |
| 5 | Hook | 6 |

如果「组件」出现了 12 次而第二名才 9 次，可以考虑换个说法——根据上下文用「部件」「模块」「视图」。

## 典型应用对照

| 场景 | 关注指标 |
|------|---------|
| 社交媒体发文 | 总字符数（Twitter <= 280）|
| 微信公众号正文 | 去空格字符数（800-2000）|
| 论文摘要 | 单词数（一般 <= 250）|
| 简历自我介绍 | 字符数 + 词频（看有没有词重复太多）|
| 翻译报价估算 | 单词数 或 字数 |
| SEO 内容 | 单词数（建议 >= 1000）|
