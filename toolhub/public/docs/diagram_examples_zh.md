# 图表渲染 — 使用示例

## 给 README 画架构流程
你正在写 README 的「请求处理流程」小节。

**操作：** 模板选「流程图」，改成自己的链路，导出 SVG。
**结果：** 矢量图随文档缩放不糊，源码只是一段文本，可直接写在代码块里长期维护，比截图或第三方编辑器更好版本管理。

## 梳理登录时序
需要向同事说明"前端如何拿到 token"。

**操作：** 模板选「时序图」，列出 用户 / 前端 / 服务端 三个参与方，画出调用箭头。
**结果：** 一张图说清调用顺序与返回内容，比大段文字更省沟通成本；源码不上传，接口细节不外泄。

## 数据库表关系评审前画 ER 图
做建表评审，需要一张实体关系图。

**操作：** 模板选「实体关系图」，把 `USER ||--o{ ORDER` 这类关系写清楚，导出 SVG 放进评审文档。
**结果：** 表之间的基数关系（一对多、多对多）一目了然。

## 排项目里程碑
季度规划要一张排期表。

**操作：** 模板选「甘特图」，用 `dateFormat YYYY-MM-DD` 与 `after a1` 表达依赖，导出 PNG 贴进 PPT。
**结果：** 任务依赖与并行关系清晰可见；PNG 直接可用，SVG 留给需要高清印刷的场合。

## 组织架构总结
想用一张图概括某个主题的结构。

**操作：** 模板选「思维导图」，用缩进表达层级，`root((主题))` 作为中心节点。
**结果：** 层级折叠/展开直观，适合做学习笔记或汇报提纲。

## 内网 / 涉密文档
你在写不能外发的设计文档。

**说明：** 全部渲染在本地浏览器完成、源码不上传、离线可用，相比需要联网保存的在线图表工具没有外发风险。
