# 文档格式转换 — 使用教程

顶部可选「粘贴文本」或「上传文件」两种输入方式，然后选来源格式与目标格式，点「开始转换」。首次转换会下载 Pandoc 引擎（约 56MB，有进度条、可取消、之后自动缓存），文件不会上传到任何服务器。

## 粘贴文本转格式

1. 选「粘贴文本」，在文本框里贴入内容。
2. 来源格式选你贴的是什么（默认 Markdown）。
3. 目标格式选要转成什么。
4. 点「开始转换」。文本类结果直接显示在下方，可复制或下载；Word / EPUB / ODT / RTF 结果给下载按钮。

## 上传文件转格式

1. 选「上传文件」，拖入或点选文件。
2. 来源格式会按后缀自动识别（`.md` / `.docx` / `.tex` / `.rst` 等都认），识别不出时手动选。
3. 选目标格式，点「开始转换」。

## 常用转换路径

| 你想要的 | 来源 | 目标 |
|---|---|---|
| Markdown 转 Word | markdown | docx |
| Word 转 Markdown | docx | markdown |
| Markdown 转 EPUB（电子书）| markdown | epub |
| HTML 转 Markdown | html | markdown |
| LaTeX 转 HTML | latex | html |
| Markdown 转 ODT | markdown | odt |
| Markdown 转 RTF | markdown | rtf |
| 任意 → 纯文本 | 任意 | plain |

## 提取内嵌图片

勾选「提取内嵌图片」后，转换 docx / epub 这类含图片的文件时，Pandoc 会把图片解出来打成 `media.zip`，结果区会出现下载按钮。

两点需要知道：

- 源文档里**没有**图片时不会生成 `media.zip`，界面会明确提示「没有检测到内嵌图片」——这是正常结果，不是出错。
- 转换出的 Markdown 里，图片引用会指向 `media.zip` 内的相对路径，所以下载后请把压缩包解压到同目录再使用。

## 选项说明

- **生成独立文档**：对 HTML、LaTeX 这类输出有效，会带上 `<html>` / `<head>` 等完整结构，可以直接保存成文件打开。转 Markdown 时无效。
- **自动生成目录**：同上，仅对支持目录的输出格式有效。

## 关于首次加载

引擎约 56MB，比本站其他工具都大，这是 Pandoc 能力的代价——它支持的格式转换在浏览器里几乎没有替代品。下载有进度条、可以随时取消，成功后写入缓存，**同一浏览器再次打开不会重新下载**。

## 小提示

- 只想看看结构，用「Markdown → native」可以看到 Pandoc 内部的 AST，排查格式问题很有用。
- 转 Word 时如果没勾「生成独立文档」，内容仍然完整，只是少了一些文档级设置。
- 表格在 Markdown → Word 时保留得最好；从 PDF 扫描件转则没有意义（PDF 不是 Pandoc 的输入格式）。
