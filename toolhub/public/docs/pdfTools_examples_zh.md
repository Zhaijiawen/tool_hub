# PDF 工具 — 使用示例

## 把合同某一页转成图片发微信

**输入：** `contract.pdf`（20 页）
**操作：** 转图片，PNG，2x，范围 `3`
**输出：** `contract-3.png`（清晰的一页）

只渲染第 3 页，几秒搞定，不用整本导出。

## 合并三份扫描件

**输入：** `scan1.pdf` / `scan2.pdf` / `scan3.pdf`
**操作：** 合并，顺序 1→2→3
**输出：** 一个 30 页的合并 PDF

签完字分三拍扫的，拼回一份方便归档。

## 拆出一份报告的指定章节

**输入：** `report.pdf`（50 页）
**操作：** 拆分，按范围 `12-18`
**输出：** 一页一个的 7 个 PDF

只给同事看第 12-18 页的章节，不用发整本。

## 把演示文稿每页存成图

**输入：** `deck.pdf`（25 页）
**操作：** 转图片，JPEG，2x，全部页码
**输出：** 25 张图片，可批量下载

做缩略图墙或导入不支持 PDF 的编辑器时用得上。
