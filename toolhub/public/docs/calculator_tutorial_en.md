# Using the Calculator

It's a calculator -- you probably already know how to use one. But there are a few things worth pointing out that'll make you faster.

## The Basics

Type numbers and operators like you'd expect. You can use the on-screen buttons or just type on your keyboard -- either way works.

- **Addition**: `5 + 3 = 8`
- **Subtraction**: `10 - 4 = 6`
- **Multiplication**: `6 × 7 = 42`
- **Division**: `15 ÷ 4 = 3.75`

The `=` button or hitting Enter gives you the result. The expression stays visible so you can double-check before committing.

## Beyond the Four Operations

| Button | What it does |
|---|---|
| `%` | Percentage -- `50 %` turns into `0.5`, so `200 × 50%` = `100` |
| `√` | Square root -- `√16 = 4` |
| `x²` | Square -- `5² = 25` |
| `xⁿ` | Power -- `2 ^ 10 = 1024` |
| `1/x` | Reciprocal -- `1/4 = 0.25` |
| `log` | Base-10 logarithm |
| `ln` | Natural logarithm (base e) |
| `sin/cos/tan` | Trig functions -- input is in degrees |

The trig functions default to degrees. If you're coming from a programming background where everything is radians, just keep that in mind.

## Handy Shortcuts

- **Parentheses `()`** are your best friend when the order of operations isn't obvious. When in doubt, add them.
- **ANS** drops the previous result into your current expression. Super useful for chaining calculations without retyping.
- **C** clears the current input line. **AC** wipes everything and starts fresh.
- **History panel** on the side keeps track of your past results. Click any of them to reuse that value.
- **Keyboard input** works throughout -- numbers, operators, Enter for equals, Escape to clear. Faster than clicking buttons once you get the hang of it.
