# Calculator — Usage Tutorial

## Basic Operations

Use the calculator for standard arithmetic:
- **Addition** (`+`): `5 + 3 = 8`
- **Subtraction** (`-`): `10 - 4 = 6`
- **Multiplication** (`×`): `6 × 7 = 42`
- **Division** (`÷`): `15 ÷ 4 = 3.75`

## Advanced Functions

| Button | Function |
|---|---|
| `%` | Percentage: `50 % = 0.5` |
| `√` | Square root: `√16 = 4` |
| `x²` | Square: `5² = 25` |
| `xⁿ` | Power: `2 ^ 10 = 1024` |
| `1/x` | Reciprocal: `1/4 = 0.25` |
| `log` | Base-10 logarithm |
| `ln` | Natural logarithm |
| `sin/cos/tan` | Trigonometric functions |

## Tips

- Use parentheses `( )` to control the order of operations
- The **ANS** key inserts the previous result into the current expression
- Press **C** to clear the current input, **AC** to clear everything
- For long calculations, use the history panel to review previous results
- Keyboard input is supported — type numbers and operators directly
