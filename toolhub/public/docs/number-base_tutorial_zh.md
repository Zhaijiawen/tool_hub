# 进制转换器 - 使用教程

跟标准的数字转换器只做 2/8/10/16 进制不同，这个工具让你在 2 到 36 的任意进制之间互转。需要 5 进制转 13 进制？没问题。

## 怎么用

1. 输入框里输入数字
2. 设置"源进制" -- 你输入的数字是什么进制？
3. 设置"目标进制" -- 想要什么进制的结果？
4. 结果立刻显示。复制走人。

## 速查

| 输入 | 源 | 目标 | 结果 | 含义 |
|---|---|---|---|---|
| `255` | 10 | 16 | `FF` | 标准十转十六 |
| `FF` | 16 | 2 | `11111111` | 十六转二 |
| `42` | 10 | 8 | `52` | 十转八 |
| `z` | 36 | 10 | `35` | Base-36 字符的数字值 |
| `10` | 36 | 10 | `36` | Base-36 "10" = 1 x 36 + 0 = 36 |

## 10 以上进制怎么读

超过 10 的进制使用 A-Z 字母：
- A = 10, B = 11, ..., Z = 35
- 不区分大小写：`a` 和 `A` 都等于 10

所以在十六进制里，`FF` = F x 16 + F = 15 x 16 + 15 = 255。
在二十进制里，`1G` = 1 x 20 + 16 = 36。
在三十六进制里，`ZZ` = 35 x 36 + 35 = 1295。

## 什么时候用得到任意进制

**三进制：** 某些谜题和算法用到三值逻辑。平衡三进制（-1, 0, 1 三个值）曾被早期苏联计算机使用。

**五进制：** 计算不常用，但有助于理解位值系统的通用原理。有些手指数数系统用五进制。

**七进制或九进制：** 很少见。主要用于教学或特定算法。

**二十进制：** 出现在某些历史上的计数系统中（玛雅数字）。法语 60 以上的数字体系也隐含二十进制（quatre-vingts = 4 x 20）。

**三十六进制：** 编码数字为短字符串的利器。YouTube 视频 ID 看起来像 base-64 但其实用了更宽的字符集。

## Base 36 的实际用法

需要一个紧凑的、URL 安全的数字 ID？

```javascript
const n = 123456789
const id = n.toString(36) // "21i3v9"
const back = parseInt('21i3v9', 36) // 123456789
```

比十进制短得多，对大数字比十六进制更可读。注意别跟区分大小写的编码搞混 -- 标准实现中 base 36 不区分大小写。
