# 随机密码生成器 技术背景

## 密码安全的重要性

弱密码是账号被盗的主要原因之一。研究表明，使用随机生成的高强度密码可以有效抵御暴力破解和字典攻击。

## 密码强度评估标准

| 长度 | 字符集 | 理论破解时间（当前算力） |
|------|-------|----------------------|
| 8位，纯数字 | 10种字符 | 毫秒级 |
| 8位，字母+数字 | 62种字符 | 分钟级 |
| 12位，大小写+数字+符号 | 94种字符 | 数千年 |
| 16位，大小写+数字+符号 | 94种字符 | 数亿年 |

## 随机数安全性

本工具使用 `crypto.getRandomValues()`（Web Crypto API），这是浏览器提供的密码学安全伪随机数生成器（CSPRNG），生成的随机数不可预测，适合用于密码、令牌等安全场景。

普通的 `Math.random()` 不应用于密码生成，因为它基于可预测的伪随机算法。

## 密码强度评级规则

本工具综合考虑密码长度和字符集多样性进行评级：

- **弱**：长度 < 8 或只使用单一字符集
- **中**：长度 8~11 + 2种以上字符集
- **强**：长度 12~15 + 3种字符集
- **极强**：长度 16+ + 4种字符集
