# 颜色选择器与转换器 — 使用示例

## 示例 1：HEX 转 RGB

**输入：** `#3498db`
**输出：**
- RGB：`rgb(52, 152, 219)`
- HSL：`hsl(204, 70%, 53%)`
- HSV：`hsv(204, 76%, 86%)`
- CMYK：`cmyk(76%, 31%, 0%, 14%)`

## 示例 2：HSL 转 HEX

**输入：** `hsl(120, 100%, 25%)`
**输出：**
- HEX：`#007F00`
- RGB：`rgb(0, 127, 0)`

## 示例 3：半透明颜色

**输入：** `rgba(255, 99, 71, 0.6)`
**输出：**
- HEX（8位）：`#FF634799`
- 含 alpha 的 HSL：`hsla(9, 100%, 64%, 0.6)`

## 常用网页颜色

| 颜色名称 | HEX | RGB |
|---|---|---|
| 红色 | `#FF0000` | `rgb(255, 0, 0)` |
| 绿色 | `#008000` | `rgb(0, 128, 0)` |
| 蓝色 | `#0000FF` | `rgb(0, 0, 255)` |
| 白色 | `#FFFFFF` | `rgb(255, 255, 255)` |
| 黑色 | `#000000` | `rgb(0, 0, 0)` |
| 灰色 | `#808080` | `rgb(128, 128, 128)` |
