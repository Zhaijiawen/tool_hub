# 颜色转换示例

几个实用的格式互转场景。

## HEX 转所有格式

**输入：** `#3498db`（那个大家都在用的好看蓝色）

**各格式输出：**
- RGB：`rgb(52, 152, 219)`
- HSL：`hsl(204, 70%, 53%)`
- HSV：`hsv(204, 76%, 86%)`
- CMYK：`cmyk(76%, 31%, 0%, 14%)`

注意 CMYK 四个值加起来超过 100%，这在减色模型里是正常的。

## HSL 转 HEX 和 RGB

**输入：** `hsl(120, 100%, 25%)`（纯绿色，偏暗）

**输出：**
- HEX：`#007F00`
- RGB：`rgb(0, 127, 0)`

25% 亮度、100% 饱和度给出一种深绿色，比直接降低 RGB 的 G 通道得到的绿色更浓郁。

## 半透明颜色

**输入：** `rgba(255, 99, 71, 0.6)`（番茄红，60% 不透明度）

**输出：**
- HEX（8位）：`#FF634799` -- 最后两位 hex 是 alpha
- 含 alpha 的 HSL：`hsla(9, 100%, 64%, 0.6)`

8 位 hex 现代浏览器都支持，但实际代码里还是 RGBA 更常见。

## 常用网页颜色速查

| 颜色 | HEX | RGB |
|---|---|---|
| 红色 | `#FF0000` | `rgb(255, 0, 0)` |
| 绿色 | `#008000` | `rgb(0, 128, 0)` |
| 蓝色 | `#0000FF` | `rgb(0, 0, 255)` |
| 白色 | `#FFFFFF` | `rgb(255, 255, 255)` |
| 黑色 | `#000000` | `rgb(0, 0, 0)` |
| 灰色 | `#808080` | `rgb(128, 128, 128)` |

这几个值形成肌肉记忆不亏，你会敲很多次。

## 一个实用技巧：用 HSL 快速生成单色系调色板

要给设计系统做 5 个同一蓝色系的深浅变体？别用 RGB 瞎猜了：

1. 定好基础蓝：`hsl(210, 80%, 50%)`
2. 浅色变体：`hsl(210, 80%, 70%)`、`hsl(210, 80%, 85%)`
3. 深色变体：`hsl(210, 80%, 35%)`、`hsl(210, 80%, 20%)`

色相和饱和度不变，只调亮度。这样数学上保证颜色系列协调统一。用转换器拿到对应的 HEX 值，填到 CSS 变量或 Tailwind 配置里就行了。
