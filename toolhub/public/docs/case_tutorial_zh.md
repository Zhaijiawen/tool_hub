# 文本大小写转换 -- 怎么用

把文字丢进去，选个风格，结果就出来了。流程很简单，但几个细节值得提一下。

## 操作流程

把文字粘贴或输入到左边的输入框，支持多行文本，不会把换行搞乱。然后点对应的转换按钮：

- **全大写** -- 所有字母变大写。常量名、缩写、想强调的文字用这个。
- **全小写** -- 所有字母变小写。规范化用户输入、准备 URL 路径、统一大小写混乱的文本。
- **首字母大写** -- 每个单词首字母大写。标题、按钮标签、专有名词。
- **句首大写** -- 只有整个文本的第一个字母大写。把全大写的文字变回正常可读的句子。
- **交替大小写** -- 每个字母大小写交替。基本就是闹着玩的，偶尔用来混淆文字。

点**复制**拿结果，点**清空**重新来。

## 几个值得知道的点

- 多行文本处理是正确的 -- 每行结构保持不变，只改大小写。
- 数字、标点、特殊字符在所有模式下都原样保留，不会被吞掉。
- 首字母大写和句首大写会正确识别标点 -- 句号或换行后面该大写的会正确大写。
- 如果你在搞编程标识符的命名转换，这个工具给你的是纯大小写变换。它不会直接把 snake_case 转成 camelCase -- 那种需要专门的命名转换器。但它能帮你把基础工作做了：先全小写然后加下划线就是 snake_case，先首字母大写再去空格就是 PascalCase。
