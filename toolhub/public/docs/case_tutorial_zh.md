# 文本大小写转换 — 使用教程

## 快速上手

文本大小写转换工具支持一键将文本在多种大小写风格之间转换。

## 操作步骤

### 第一步：输入文本
将需要转换的文本粘贴或输入到输入框中，支持多行文本。

### 第二步：选择转换方式
点击对应的转换按钮：
- **全大写** — 将所有字母转换为大写
- **全小写** — 将所有字母转换为小写
- **首字母大写** — 每个单词首字母大写
- **句首大写** — 仅第一个字母大写
- **交替大小写** — 字母交替大写小写

### 第三步：复制结果
转换后的文本会显示在输出框中，点击**复制**按钮复制到剪贴板。

### 第四步：清空重置
点击**清空**按钮，同时清空输入和输出框。

## 使用技巧

- 支持多行文本，每行独立处理。
- 首字母大写和句首大写能正确处理标点和换行。
- 数字、空格和特殊字符保持不变。
