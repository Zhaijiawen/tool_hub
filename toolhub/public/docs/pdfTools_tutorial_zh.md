# PDF 工具 — 使用教程

顶部三个标签页对应三个功能，底部还有一个可选的「密码」框，对当前操作生效。

## PDF 转图片

1. 在「转图片」标签页上传 PDF。
2. 选格式（PNG / JPEG）和缩放倍数（1x/2x/3x）。
3. 选范围：全部页码，或自定义（如 `1-3,5`）。
4. 点「开始渲染」，完成后以网格展示每页图片，可单页下载或「下载全部」。

## 合并 PDF

1. 切到「合并」标签页，上传至少 2 个 PDF。
2. 用每条右侧的上下箭头调整顺序（顺序决定合并后的先后）。
3. 点「开始合并」，下载结果。

## 拆分 PDF

1. 切到「拆分」标签页，上传 PDF。
2. 选模式：
   - **逐页拆分**：每页一个文件。
   - **按范围拆分**：填范围（如 `1-3,5`）。
3. 点「开始拆分」，可单份或「下载全部」。

## 加密文件

在底部密码框填入密码，再执行上面的操作即可打开加密 PDF。

## 小提示

- 只要某一页当图片用？转图片时填自定义范围只渲染那几页，更快。
- 合并前先排好顺序，结果不可逆（除非重新合并）。
- 页数很多时，转图片会生成很多文件，建议按需选范围。
