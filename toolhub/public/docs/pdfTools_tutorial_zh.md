# PDF 工具 — 使用教程

顶部有六个标签页，前三个是「PDF 转图片 / 合并 PDF / 拆分 PDF」，后三个是「PDF 瘦身 / 提取文字 / 页面整理」。底部还有一个可选的「密码」框，对所有标签页生效。

## PDF 转图片

1. 在「PDF 转图片」标签页上传 PDF。
2. 选格式（PNG / JPEG）和缩放倍数（1x/2x/3x）。
3. 选范围：全部页码，或自定义（如 `1-3,5`）。
4. 点「开始转换」，完成后以网格展示每页图片，可单页下载或「下载全部」。

## 合并 PDF

1. 切到「合并 PDF」标签页，上传至少 2 个 PDF。
2. 用每条右侧的上下箭头调整顺序（顺序决定合并后的先后）。
3. 点「开始合并」，下载结果。

## 拆分 PDF

1. 切到「拆分 PDF」标签页，上传 PDF。
2. 选模式：
   - **每页一个文件**：逐页导出。
   - **按页码范围**：填范围（如 `1-3,5`），每个区间导出一个文件。
3. 点「开始拆分」，可单份或「全部下载」。

## PDF 瘦身

1. 切到「PDF 瘦身」标签页，上传 PDF。
2. 点「开始瘦身」。处理会清理无用对象并对内部数据流重新压缩。
3. 结果会显示体积变化，例如 `961 KB → 465 KB (-51.6%)`，然后下载。

**关于效果，需要如实说明：**

- 未经压缩的 PDF（扫描仪生成、老工具导出、拼图的 App 导出）收益最大，实测可缩小一半以上。
- 已经用别的方式压缩过的 PDF（Chrome「打印成 PDF」、Word / LaTeX 导出）通常只能缩小 1%–3%，有时甚至会略微变大——因为重新封装本身也要占几个字节。
- 工具不会粉饰结果：如果没能变小，标签会显示为黄色提示色并说明「该文件未能进一步压缩」，而不是假装成功。

## 提取文字

1. 切到「提取文字」标签页，上传 PDF。
2. 选范围：全部页面或指定页码（如 `1-3,5`）。
3. 点「开始提取」，按页展示结果，可复制单页、「复制全部」或「下载 .txt」。

注意：这里读取的是 PDF 内嵌的**文本层**，**不是 OCR**。由扫描件或截图生成的 PDF 没有文本层，提取结果会是空白，界面会给出明确提示——这种情况下请改用 OCR 工具。

## 页面整理

1. 切到「页面整理」标签页，上传 PDF。
2. 选处理方式：
   - **删除所选页**：删掉填写范围里的页面。
   - **保留所选页**：只留下填写范围里的页面，其余删除。
3. 填页码范围（如 `1-3,5`），点「开始整理」，下载结果。

不能把页面全部删掉，PDF 至少要保留一页，否则会提示错误。

## 加密文件

在底部密码框填入密码，再执行上面的操作即可打开加密 PDF。密码只在本地使用，不上传。

## 页码范围写法

所有支持范围的标签页都使用同一套语法，页码从 1 开始、两端都包含：

| 写法 | 含义 |
|---|---|
| `3` | 只有第 3 页 |
| `1-3` | 第 1 到 3 页 |
| `1-3,5` | 第 1 到 3 页，加上第 5 页 |
| `8-` | 第 8 页到最后一页 |
| `1-3,5,8-` | 可混用，逗号分隔 |

## 小提示

- 只要某一页当图片用？转图片时填自定义范围只渲染那几页，更快。
- 合并前先排好顺序，结果不可逆（除非重新合并）。
- 页数很多时，转图片会生成很多文件，建议按需选范围。
- 想从长文档里摘出一个章节，用「页面整理」的保留模式比拆分更直接。
- 瘦身前先想清楚：如果 PDF 本来就是软件导出的，收益会很小。
