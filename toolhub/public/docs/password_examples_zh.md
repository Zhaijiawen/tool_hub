# 随机密码生成器 — 示例

## 强密码（16 位，全字符集）

```
Kx9#mP2@wL5$vN8!
Rq7&jT4*nB6^cY1%
Hs3@fW8!uE2#pM9$
```

大多数账号就用这个级别的。大小写、数字、符号齐全，长度合理。

## 纯字母数字（无符号）

```
Kx9mP2wL5vN8cY1R
Rq7jT4nB6cY1pM9f
Hs3fW8uE2pM9nB6c
```

有些老系统不支持特殊符号，或者支持的符号集太窄，不如直接跳过符号把长度加长。20 位纯字母数字的密码比 12 位带符号的强得多。

## 超长（32 位，API Key 用）

```
Kx9#mP2@wL5$vN8!Rq7&jT4*nB6^cY1%
```

API Key、Secret、加密密钥用这个级别。32 位以上全字符集是标配。

## PIN 码（仅数字，6 位）

```
847291
039145
562078
```

需要纯数字 PIN 的时候用，不想用生日或者规律数字就让它随机生成。6 位数字有一百万种组合——有限速保护的 PIN 场景够用，但绝对不要当在线账号密码。

## 批量（5 个，16 位强密码）

```
Kx9#mP2@wL5$vN8!
Rq7&jT4*nB6^cY1%
Hs3@fW8!uE2#pM9$
Zt5*kD1@xG4&bJ7^
Mn2$hA6#yC3!wP8@
```

一次性开多个账号或者给新团队成员生成初始密码时用批量模式。一人发一个密码，首次登录强制修改。
