# Storage & Time Converter — Examples

## Storage Examples

### How much is 1.5 TB in MB?
`1.5 TB = 1,500,000 MB` (SI decimal)
`1.5 TiB = 1,572,864 MiB` (IEC binary)

### What is my actual download speed?
Internet connection: `100 Mbps`
→ `100 ÷ 8 = 12.5 MB/s`

A 1 GB file at 12.5 MB/s will take: `1,000 ÷ 12.5 = 80 seconds`

### File storage planning
Database backup: `500 MB`
Daily growth: `10 MB/day`
After 30 days: `500 + (10 × 30) = 800 MB`

## Time Examples

### Session timeout configuration
System requirement: 30-minute session timeout
In milliseconds: `30 × 60 × 1000 = 1,800,000 ms`
In seconds: `1,800 s`

### Token expiry
JWT access token: `15 minutes = 900 seconds`
JWT refresh token: `7 days = 604,800 seconds`

### Cache TTL
Browser cache: `1 year = 31,536,000 seconds`
API response cache: `5 minutes = 300 seconds`
