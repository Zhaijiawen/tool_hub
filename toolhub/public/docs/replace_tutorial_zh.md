# 查找与替换 — 使用教程

## 使用步骤

### 第一步：粘贴文本
将要处理的文本输入或粘贴到输入框中。

### 第二步：输入搜索词
在**查找**栏中输入要查找的文本或模式。

### 第三步：输入替换内容
在**替换**栏中输入替换文本，留空表示删除所有匹配项。

### 第四步：配置选项
- **正则模式**：开启以启用正则表达式匹配
- **区分大小写**：控制是否区分大小写（默认不区分）

### 第五步：执行替换
- 点击**全部替换**来替换所有匹配
- 结果会自动显示在输出框中

## 使用正则表达式

开启正则模式后，查找栏支持正则模式，替换栏支持反向引用：
- `$1` — 第一个捕获组
- `$2` — 第二个捕获组
- `$&` — 整个匹配内容

### 示例：交换姓名顺序
- **查找**：`(\w+)\s+(\w+)`
- **替换**：`$2 $1`
- **输入**：`John Doe`
- **输出**：`Doe John`

## 使用技巧
- 在正则中使用 `.*` 匹配任意字符序列
- 用 `\` 转义特殊字符（例如 `\.` 匹配字面点号）
- 复制前预览结果，确保准确无误
