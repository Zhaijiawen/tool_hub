# 查找与替换 — 使用教程

替换工具概念上简单到不行——输入找什么、输入换成什么、点按钮——但正则模式打开的那些用法，第一眼不一定看得出来。

先把文本丢进输入区。什么都行：配置文件、一坨 HTML、日志输出，随便什么你要整理的。

在**查找**栏输入你要找的东西。正则模式关着的时候就是字面字符串——`color` 只找 `color`，不多不少。正则模式一开，这个栏变成模式输入，你可以用完整的正则语法。

在**替换**栏输入你想让每个匹配变成什么。留空就等价于删除匹配——这是剥离 HTML 标签、去除注释、清理数据噪声最快的方式。

两个开关控制行为：
- **正则模式**：默认关闭。需要模式匹配而不是字面搜索时开启。查找栏立刻开始解析元字符，记得用 `\` 转义字面的点和括号。
- **区分大小写**：默认关闭——`hello` 能匹配 `Hello` 和 `HELLO`。当大小写有实际意义时打开，比如你在代码里重命名一个具体的标识符。

点**全部替换**，输出区原地更新。每个命中的查找模式都被替换，结果可以直接复制。

## 反向引用怎么用

正则模式开着且你的模式里有捕获组 `()` 时，替换字符串可以引用它们：
- `$1` — 第一个捕获组
- `$2` — 第二个捕获组
- `$&` — 整个匹配内容

这就是不丢数据重组信息的方法。假如你有一列「张三 李四」格式的姓名，需要变成「李四, 张三」——模式 `(\w+)\s+(\w+)`，替换 `$2, $1`，一遍搞定。

日期场景：`(\d{4})-(\d{2})-(\d{2})` 分别捕获年、月、日。替换为 `$3/$2/$1` 就能把顺序翻成年/月/日。不用写脚本。

## 容易踩的坑

- 如果你先输入查找内容再打开正则模式，复查一遍。`.` 和 `()` 这些字符刚才还是字面文本，现在已经变成元字符了。
- 正则模式 + 空查找栏不会匹配任何东西——如果你想包装或转换整行，需要的是 `.*`。
- 正则模式下 `\n` 匹配换行符，但要注意 JavaScript 的 `.` 不加 `s` 标志不会匹配 `\n`（而 `\n` 本身作为字符在字符类和分支选择里始终有效）。
- 用反向引用替换时，确保你的模式里捕获组确实在捕获——`(?:...)` 非捕获组不会产生 `$1`。
