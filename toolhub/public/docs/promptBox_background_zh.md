# AI 提示词工具箱 — 技术背景

## 什么是提示词？

在生成式 AI 和大型语言模型（LLM）的语境中，**提示词（Prompt）** 是输入给模型以引导其响应的文本。提示词的质量、结构和清晰度直接决定了输出的有效性。

## 提示词工程的重要性

GPT-4、Claude、Gemini 等 LLM 对指令的表达方式非常敏感。精心设计的提示词可以：
- 显著提升响应准确性
- 控制输出的格式和风格
- 减少"幻觉"（模型编造错误信息）
- 将响应定制为特定受众或场景

## 核心提示技巧

### 1. 角色指定
告诉模型扮演特定的角色或人设：
```
你是一位经验丰富的软件架构师。请审查以下代码并提出改进建议。
```

### 2. 少样本提示（Few-Shot）
提供示例来演示期望的输出模式：
```
将英文翻译成法文：
英文：Hello → 法文：Bonjour
英文：Thank you → 法文：Merci
英文：Good morning → 法文：？
```

### 3. 思维链（Chain-of-Thought）
要求模型在回答前逐步推理：
```
请一步步求解：一列火车以 60 英里/时的速度行驶 2.5 小时，走了多远？
```

### 4. 输出格式指定
明确指定预期的输出格式：
```
以 JSON 数组的形式列出 2024 年前 5 大编程语言，每项包含 "name" 和 "ranking" 字段。
```

### 5. 上下文注入
在指令前提供相关背景信息：
```
背景：[在此粘贴相关文档或数据]

基于以上背景，回答以下问题：...
```

## 提示词模板

可复用的提示词结构（模板）有助于在相似任务中保持一致性：
- 代码审查模板
- 博客文章写作模板
- 数据提取模板
- 客服回复模板
