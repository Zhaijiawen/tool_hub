# AI 提示词工具箱 — 好提示词长什么样

提示词就是你喂给大语言模型的那段文本。可以是一句话，也可以是一整页带示例的详细指令。好提示词和差提示词之间的区别，往往就是「拿到想要的结果」和「拿到看着像那么回事但用不了的废话」之间的区别。

## 为什么提示词质量这么重要

GPT-4、Claude、Gemini 这些模型对措辞的敏感程度远超人类读者。措辞上的小变化能把输出推向完全不同的方向。一条好的提示词同时做几件事：限定主题范围、确定语气、指定输出格式、给模型足够的上下文来填充正确的细节。

## 有效的提示技巧

**角色指定 —** 告诉模型它是谁。「你是一位经验丰富的 DBA……」能定下术语深度、回答风格。不指定角色，模型就默认当一个通用助手。

**少样本提示 —** 给几个例子展示你要的输出模式。比如做特定风格的翻译，先给两三个例句，再让它翻下一个。模型会自动跟上这个模式。

**思维链 —** 涉及推理的任务，要求模型一步步来。「解这道数学题，展示每一步计算过程」比「答案是多少」靠谱得多。

**指定输出格式 —** 明确说明你要的格式。「返回 JSON 数组，每项包含 name 和 description 字段」或「用要点列表，每条最多三句话」。不说清楚格式，模型就按自己的默认方式来。

**上下文注入 —** 在提问之前先贴相关背景信息。「这是 PR 描述和改动代码，请基于以上上下文进行审查」比「帮我审查这个 PR」效果好太多。

## 提示词模板

模板给重复性任务提供可复用的结构。代码审查模板、博客大纲模板、数据提取模板——填变量就用。省时间、输出质量也稳定。
