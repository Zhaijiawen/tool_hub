# Python 运行器 — 使用教程

1. 页面打开时编辑器里已经有一份「统计」示例。也可以点顶部的示例按钮（统计 / JSON / 正则 / 日期 / 算法）换一份。
2. 在编辑器里写或改 Python 代码。只用到标准库。
3. 点「运行」。首次运行会下载 Pyodide（带进度条），之后走缓存。
4. 结果区显示：
   - **返回值**：最后一个表达式的值（如果有）。
   - **stdout**：`print()` 的输出。
   - **stderr**：报错或警告。
5. 没有输出时会提示「无输出」。点「复制」可复制结果。

## 小提示

- 想看某个变量？直接用 `print()`，它会出现在 stdout。
- 想看最后一个表达式的值？直接写表达式（不赋值），它会作为返回值显示。
- 报错会显示在 stderr，红字，附异常类型。

## 不支持的事

- 不能 `import numpy` / `pandas` 等第三方库。
- 不能访问网络（`requests` 不可用）。
- 不能读写你电脑上的文件（只能用字符串/变量）。
