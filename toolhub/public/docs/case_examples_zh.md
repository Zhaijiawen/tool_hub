# 文本大小写转换 — 使用示例

## 示例 1：转换 API 响应字段名

**输入：**
```
user_first_name
user_last_name
email_address
```

**首字母大写输出：**
```
User_First_Name
User_Last_Name
Email_Address
```

## 示例 2：规范化用户输入

**输入：**
```
hELLO wORLD this IS a TEST
```

**句首大写输出：**
```
Hello world this is a test
```

## 示例 3：生成常量名称

**输入：**
```
maximum retry count
database connection timeout
```

**全大写输出：**
```
MAXIMUM RETRY COUNT
DATABASE CONNECTION TIMEOUT
```
