# 数字转换器 — 技术背景

## 数制

数制是表示数字的书写系统。计算机领域最常用的数制包括：

### 十进制（Base 10）
人类日常使用的标准数制，使用数字 0–9。
- 示例：`255`

### 二进制（Base 2）
计算机内部使用，只有 0 和 1 两个数字。
- 示例：`11111111`（= 十进制 255）
- 每个二进制位称为 **bit**；8 位 = 1 **字节**

### 八进制（Base 8）
使用数字 0–7，有时用于 Unix 文件权限。
- 示例：`377`（= 十进制 255）

### 十六进制（Base 16）
使用数字 0–9 和字母 A–F，广泛用于计算机领域（内存地址、颜色、字符编码）。
- 示例：`FF`（= 十进制 255）

## 转换原理

从任意进制转换为十进制：将每位数字乘以其位权（基数^位置）后求和：

```
二进制 1011 → 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = 11
十六进制 FF → 15×16¹ + 15×16⁰ = 240 + 15 = 255
```

## 有符号与无符号整数

- **无符号**：只有非负值（0 到 2^n − 1）
- **有符号（补码）**：包含负值（−2^(n-1) 到 2^(n-1) − 1）

对于 8 位有符号整数：−128 到 127。

## 浮点数

计算机使用 **IEEE 754** 标准表示实数：
- **32 位浮点数**（单精度）：约 7 位有效数字
- **64 位双精度**：约 15 位有效数字

浮点运算可能产生舍入误差，例如大多数语言中 `0.1 + 0.2 ≠ 0.3`。
