# Text Case Conversion — Examples

## Example 1: Convert API Response Keys

**Input:**
```
user_first_name
user_last_name
email_address
```

**Title Case Output:**
```
User_First_Name
User_Last_Name
Email_Address
```

## Example 2: Normalize User Input

**Input:**
```
hELLO wORLD this IS a TEST
```

**Sentence Case Output:**
```
Hello world this is a test
```

## Example 3: Create Constants from Names
