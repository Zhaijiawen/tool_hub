# IP 查询工具 - 技术背景

## 什么是 IP 地址

IP（Internet Protocol）地址是网络中每台设备的唯一标识符，用于设备间的通信寻址。目前主要使用 IPv4 和 IPv6 两个版本。

## IPv4 vs IPv6

### IPv4
- 32 位数字，点分十进制表示：`192.168.1.1`
- 共约 43 亿个地址，已基本耗尽
- 私有地址段：`10.x.x.x`、`172.16-31.x.x`、`192.168.x.x`

### IPv6
- 128 位数字，冒号十六进制表示：`2001:0db8:85a3::8a2e:0370:7334`
- 地址数量约 3.4×10³⁸，可以为每粒沙子分配 IP
- 已在全球逐步推广普及

## IP 地理位置查询原理

IP 地理位置数据库通过以下方式建立：
1. **WHOIS 注册信息**：IP 段向区域互联网注册机构（RIR）申请注册时提供的地理信息
2. **BGP 路由分析**：分析互联网路由宣告，推断 IP 所属网络的地理位置
3. **主动探测**：通过 traceroute 等工具探测路径上的路由器位置
4. **用户反馈与校准**：通过用户反馈和 GPS 数据不断修正精度

## IP 信息包含的字段

| 字段 | 说明 |
|------|------|
| IP | IP 地址本身 |
| 国家/地区 | 所属国家及区域代码 |
| 城市 | 所在城市（可能不准确） |
| 经纬度 | 大概的地理坐标 |
| ISP/ASN | 互联网服务提供商和自治系统编号 |
| 时区 | 该区域使用的时区 |
| 货币 | 该国使用的货币 |
| 语言 | 官方语言 |

## 常用 IP 查询 API

### ipapi.co
- 免费版：每天 1000 次请求
- 支持 IPv4 和 IPv6
- 返回 JSON 格式
- 端点：`https://ipapi.co/{ip}/json/`

### ip-api.com
- 免费版：每分钟 45 次请求
- 支持中文返回（`lang=zh-CN`）
- 仅支持 HTTP（非 HTTPS）
- 端点：`http://ip-api.com/json/{ip}?lang=zh-CN`

### ipinfo.io
- 免费版：每月 5 万次请求
- 提供 ASN 详细信息
- 支持 HTTPS

## 精度局限性

IP 地理位置查询**不是精准定位**，存在以下局限：
- 城市级精度通常在 50-100 公里以内
- ISP 机房地址≠用户实际地址
- VPN/代理用户显示的是出口节点位置
- 企业 VPN 用户显示的是总部或数据中心位置
- Starlink 等卫星网络用户位置显示可能非常不准

## 公网 IP vs 私有 IP

- **私有 IP**（如 `192.168.1.1`）只在局域网内使用，无法在公网上被访问，查询不到地理位置
- **公网 IP** 是由 ISP 分配的可在互联网上路由的地址，可以查询到地理位置
- 大多数家庭用户使用 NAT（网络地址转换），多台设备共享一个公网 IP
