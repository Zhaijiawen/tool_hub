# IP 查询工具 - 技术背景

IP 地址是设备在网络上的唯一标识，相当于你寄信时的回邮地址。没有 IP 地址，互联网没法把数据路由到正确的机器上。

## IPv4 vs IPv6

**IPv4** 就是大家都熟悉的样子：`192.168.1.1`。32 位，四个十进制数字用点隔开。总共约 43 亿个地址，90 年代就开始不够用了。所以你家的路由器用 NAT 技术让多台设备共享一个公网 IP。私有地址段 `10.x.x.x`、`172.16-31.x.x`、`192.168.x.x` 只用于局域网，永远不会出现在公网上。

**IPv6** 是长期的解决方案：128 位，冒号隔开的十六进制表示，比如 `2001:0db8:85a3::8a2e:0370:7334`。地址空间大到离谱 -- 3.4 x 10^38 个。给地球上每个原子分配一个都还有剩余。推广速度不快但一直稳步增长，Google 大约 45% 的流量已经走 IPv6 了。

## IP 地理位置查询的原理

别想成 GPS 定位，更接近"合理猜测"。数据库通过以下几种方式建立：

1. **WHOIS 记录** -- ISP 向区域互联网注册机构注册 IP 段时提供物理地址。
2. **BGP 路由数据** -- 分析哪个网络从哪个位置宣告了哪个 IP 段。
3. **延迟三角测量** -- 测量到已知位置节点的 ping 延迟来估算距离。
4. **用户反馈数据** -- 部分服务用手机 App 的 GPS 数据来校准数据库。

## 查询结果包含什么

| 字段 | 含义 |
|---|---|
| IP | 地址本身 |
| 国家/地区 | 国家级通常准确 |
| 城市 | 大概位置，常有 50-100 公里误差 |
| 经纬度 | 粗略坐标，别当导航用 |
| ISP/ASN | 谁拥有这个 IP 段 |
| 时区 | 基于注册位置 |
| 货币 | 该国货币，做本地化时有用 |
| 语言 | 官方语言 |

## 公网 IP vs 私有 IP

私有 IP（`192.168.x.x`、`10.x.x.x`、`172.16-31.x.x`）只在局域网内有效，公网上不可路由，查不到地理位置。公网 IP 是 ISP 分配的、外部服务能看到的地址。如果你在路由器后面，工具显示的 IP 是你路由器的公网 IP，不是你笔记本的局域网 IP。

## 精度问题

IP 定位精度有限。固定宽带城市的精度一般在 50-100 公里内。移动网络更差。VPN 和代理直接让定位失去意义 -- 你看到的是出口节点的位置，不是用户的。企业 VPN 用户经常显示为总部或数据中心的位置。Starlink 等卫星网络用户可能显示完全错误的位置，因为地面站可能在另一个国家。
