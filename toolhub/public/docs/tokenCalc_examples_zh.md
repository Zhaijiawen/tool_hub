# AI Token 计算器 — 使用示例

## 估算一次 API 调用的成本

你准备给 GPT-4o 发一段 2000 字的产品需求文档，想知道会不会超预算。

**输入：** 一段约 2000 中文字的需求描述
**操作：** 模型选 GPT-4o（o200k_base）
**输出：** Token 数量约 2600，按输入价 $2.5 / 1M 计，约 $0.0065（不到 1 美分）

同样是 2000 字，如果你选 GPT-4 Turbo（cl100k_base），token 数会略有不同——这就是"同文本、不同模型 token 数不同"的直观体现。切一下下拉框就能对比。

## 控制 prompt 不超上下文窗口

GPT-4o 的上下文窗口是 128K token。你有一段很长的技术文档要塞进 prompt。

**操作：** 把整段文档粘进去，看 Token 数量。如果超过 ~100K，就先做摘要或分段，避免截断或报错。工具的字符/词数同时显示，方便你判断该删哪部分。

## 对比不同模型的花费

同一段客服话术，分别选 GPT-4o-mini 和 o1 看费用差。

**结果：** GPT-4o-mini 输入价 $0.15 / 1M，o1 输入价 $15 / 1M——相差 100 倍。对海量、简单的任务，用 mini 模型能省下大量成本。工具让你在写代码前就看清这个差距。

## 估算 Claude 的用量（近似）

**操作：** 模型选 Claude 3.5 Sonnet，界面出现"近似"提示。
**说明：** token 数是基于 cl100k_base 的近似值，数量级可靠，可用于粗略预算，但不要当作精确账单。

## 批量任务预算

你要处理 1 万条用户评论，每条约 300 字，全部发给 GPT-4o-mini 做分类。

**估算：** 单条约 400 token × 1 万 = 400 万 token → 约 $0.6（输入）。提前知道总量，就能决定要不要限流或换更便宜的模型。
