# 计算器 — 使用教程

## 基本运算

使用计算器进行标准算术运算：
- **加法** (`+`)：`5 + 3 = 8`
- **减法** (`-`)：`10 - 4 = 6`
- **乘法** (`×`)：`6 × 7 = 42`
- **除法** (`÷`)：`15 ÷ 4 = 3.75`

## 高级功能

| 按钮 | 功能 |
|---|---|
| `%` | 百分比：`50 % = 0.5` |
| `√` | 平方根：`√16 = 4` |
| `x²` | 平方：`5² = 25` |
| `xⁿ` | 幂次：`2 ^ 10 = 1024` |
| `1/x` | 倒数：`1/4 = 0.25` |
| `log` | 以 10 为底的对数 |
| `ln` | 自然对数 |
| `sin/cos/tan` | 三角函数 |

## 使用技巧

- 使用括号 `( )` 控制运算顺序
- **ANS** 键将上一次结果插入当前表达式
- 按 **C** 清除当前输入，**AC** 清除全部内容
- 对于长计算，使用历史记录面板查看之前的结果
- 支持键盘输入——直接输入数字和运算符
