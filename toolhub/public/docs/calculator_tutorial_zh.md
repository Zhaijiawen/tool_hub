# 计算器使用指南

界面上的按钮一目了然，说几个能让你用得更顺手的点。

## 基本操作

输入数字和运算符就行。你可以点屏幕上的按钮，也可以直接用键盘敲，两种方式都支持。

- **加法**：`5 + 3 = 8`
- **减法**：`10 - 4 = 6`
- **乘法**：`6 × 7 = 42`
- **除法**：`15 ÷ 4 = 3.75`

按 `=` 或回车键出结果。表达式会留在屏幕上，方便你确认输入没问题再提交。

## 科学计算功能

| 按钮 | 功能 |
|---|---|
| `%` | 百分比 -- `50 %` 变成 `0.5`，所以 `200 × 50%` = `100` |
| `√` | 平方根 -- `√16 = 4` |
| `x²` | 平方 -- `5² = 25` |
| `xⁿ` | 幂运算 -- `2 ^ 10 = 1024` |
| `1/x` | 倒数 -- `1/4 = 0.25` |
| `log` | 以 10 为底的对数 |
| `ln` | 自然对数（以 e 为底） |
| `sin/cos/tan` | 三角函数 -- 注意输入是角度不是弧度 |

三角函数默认按角度算。写代码写习惯了用弧度的话要注意一下。

## 几个省时间的技巧

- **括号 `()`** 是最可靠的工具。优先级搞不清楚的时候直接加括号，稳。
- **ANS** 把上一次的结果插到当前表达式里。连续计算的时候不用重新打数字。
- **C** 清当前行，**AC** 全部清空重新来。
- **历史记录面板** 在侧边，点了之前的结果就能复用。不小心清掉了也不用慌。
- **键盘操作** 全支持 -- 数字、运算符、回车出结果、Esc 清空。用熟了比鼠标点快得多。
