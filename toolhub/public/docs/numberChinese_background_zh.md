# 数字大写转换 技术背景

## 为什么需要数字大写？

在中国的财务、法律、票据场景中，金额必须用汉字大写书写，以防止篡改。国家标准 GB/T 15834 规定了中文数字写法。

## 三种模式说明

### 1. 大写模式
使用正式汉字：壹贰叁肆伍陆柒捌玖拾佰仟万亿

示例：`1234` → `壹仟贰佰叁拾肆`

### 2. 小写模式
使用日常汉字：一二三四五六七八九十百千万亿

示例：`1234` → `一千二百三十四`

### 3. 财务金额模式
遵循银行/财务规范，包含货币单位：

示例：`1234.56` → `壹仟贰佰叁拾肆元伍角陆分`

规则：
- 整数末尾无小数时加"整"
- 角为零而分不为零时，整数后加"零"
- 金额为零时写"零元整"
