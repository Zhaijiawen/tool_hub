# AI 提示词工具箱 — 怎么用

## 操作流程

**选或创建模板 —** 按分类浏览内置模板（代码、写作、分析等），或者从空白开始。模板里有 `{{topic}}`、`{{language}}` 这样的占位符，后面填你自己的内容。

**填变量 —** 模板里的每个 `{{占位符}}` 都换成具体内容。`{{language}}` 换成「Python」，`{{topic}}` 换成「微服务架构」，按实际情况来。

**在编辑器里调整 —** 提示词文本可以直接改。调整措辞、加约束条件、删掉不需要的部分。下面的技巧可以帮助提升清晰度。

**复制拿去用 —** 点复制拿到最终提示词，贴到 ChatGPT、Claude、Gemini 或你用的任何 AI 工具里。

## 写好提示词的要点

| 原则 | 什么意思 |
|------|---------|
| 具体明确 | 「写一篇博客」毫无用处。「写一篇 800 字关于 Docker 网络的文章，面向只用过 docker-compose 的开发者」才是具体的。|
| 定义角色 | 「你是一位资深前端工程师，正在审查 React 代码」给模型设定了专业背景。|
| 指定格式 | 「返回 JSON 数组」、「用 Markdown 写，带 ## 标题」、「用要点列表」。|
| 限定长度 | 「三段话」、「不超过 500 字」、「包含至少 5 个章节的详细分析」。|
| 给示例 | 几个输入输出对能大幅提升结构化任务的输出质量。|
| 迭代优化 | 第一次输出很少完美。根据结果调整提示词再来一次。|

## 模板分类

内置模板覆盖了常见场景：

- **代码类** — 生成、审查、调试、重构、解释代码
- **写作类** — 邮件、报告、博客、文档
- **分析类** — 摘要、对比、评估、信息提取
- **翻译类** — 跨语言或跨风格转换
- **头脑风暴** — 创意、替代方案、开放问题的解法
