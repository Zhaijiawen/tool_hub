# AI 提示词工具箱 — 使用教程

## 使用步骤

### 第一步：选择或创建提示词模板
按分类浏览内置提示词模板，或从空白提示词开始。

### 第二步：填写变量
模板可能包含 `{{topic}}`、`{{language}}`、`{{code}}` 等占位符，用你的具体内容填写每个变量。

### 第三步：完善提示词
直接在编辑器中修改提示词文本。参考下方格式技巧提升表达清晰度。

### 第四步：复制并使用
点击**复制**将完整提示词复制到剪贴板，然后粘贴到你使用的 AI 工具中（ChatGPT、Claude、Gemini 等）。

## 提示词编写最佳实践

| 原则 | 说明 |
|---|---|
| **具体明确** | 模糊的提示词会产生模糊的答案。包含背景、约束和目标。 |
| **定义角色** | "你是一位资深后端工程师..."有助于确定专业水平。 |
| **指定格式** | "以编号列表回答"、"以 JSON 格式输出"、"用 Markdown 撰写"。 |
| **限定长度** | "用 3 句话"、"不超过 500 字"、"提供详细的分析"。 |
| **提供示例** | 向模型展示你期望的输出样式。 |
| **迭代优化** | 根据模型回应不断调整提示词。 |

## 常见提示词分类

- **代码类**：生成、审查、调试、重构、解释代码
- **写作类**：起草邮件、报告、博客文章、文档
- **分析类**：摘要、对比、评估、信息提取
- **翻译类**：语言或风格转换
- **头脑风暴类**：生成想法、替代方案、解决方案
