# CSV/TSV 预览工具 -- 使用指南

粘贴或上传 CSV/TSV 文件，即时渲染成可读的表格。

## 两种输入方式

1. **直接粘贴**：把 CSV/TSV 内容复制粘贴到文本框，表格即时渲染。
2. **上传文件**：点击上传区域，选择 `.csv`、`.tsv` 或 `.txt` 文件。最大 5MB -- 大约 5 万行典型数据。

## 选对分隔符

工具默认用**自动检测**模式，扫描内容后选使各行列数最一致的分隔符。数据干净的时候自动检测很好用。

自动检测猜错了就手动切：

| 选项 | 什么时候用 |
|---|---|
| 自动检测 | 默认，让工具自己判断 |
| 逗号（`,`） | Excel、Google Sheets 导出的标准 CSV |
| Tab | TSV 文件、数据库 dump |
| 分号（`;`） | 欧洲 Excel 导出 |
| 竖线（`\|`） | 自定义日志格式 |
| 空格 | nginx/apache 日志 |

## 解析结果怎么看

解析成功后数据以可排序、可滚动的表格展示：

- **首行当表头**：第一行默认当成列名。
- **行列统计**：表格上方显示总行数和列数，一眼看清数据规模。
- **最多显示 10000 行**：展示上限 1 万行，超出的数据虽然解析了但视觉上截断，会有提示。

## 复制为 JSON

右上角的**复制**按钮把解析结果以 JSON 数组格式复制到剪贴板：

```json
[
  { "姓名": "张三", "城市": "北京", "年龄": "28" },
  { "姓名": "李四", "城市": "上海", "年龄": "32" }
]
```

直接粘到 JavaScript、Python（`json.loads` 之后）或任何支持 JSON 的代码里用。

## 常见问题

### 中文乱码

文件编码多半是 GBK 但被按 UTF-8 读了。用 VS Code 或记事本打开，重新另存为 UTF-8 编码再上传。

### 列数不对

某些字段里有没转义的分隔符。切到自动检测模式试试，或者手动换一个分隔符。竖线分隔的文件有时候会被误判为逗号分隔。

### 上传后空白

文件可能是空的，或者只有表头行没有数据。直接打开文件确认内容。
