# CSV / TSV 预览解析 - 技术背景

## 什么是 CSV 和 TSV

**CSV（Comma-Separated Values，逗号分隔值）** 是最常见的表格型纯文本格式，广泛用于数据导出、表格交换和数据库迁移。

**TSV（Tab-Separated Values，制表符分隔值）** 与 CSV 类似，区别在于使用制表符（`\t`）而非逗号作为分隔符，常见于日志系统和 TSV 数据库导出。

## 分隔符类型

| 分隔符 | 字符 | 典型场景 |
|--------|------|---------|
| 逗号 | `,` | Excel 导出、Google Sheets、通用 CSV |
| 制表符 | `\t` | 数据库 dump、MySQL 导出 |
| 分号 | `;` | 欧洲地区 Excel（本地化逗号作为小数点）|
| 竖线 | `\|` | 日志文件、自定义数据格式 |
| 空格 | ` ` | nginx 日志、系统日志 |

## CSV 的常见问题

### 1. 字段内含分隔符

当字段值本身包含逗号时，需用双引号包裹：

```
姓名,城市,备注
张三,"北京,上海","经常出差，跨城办公"
```

### 2. 字段内含换行符

双引号内的字段可以包含换行：

```
id,description
1,"第一行
第二行"
```

### 3. 双引号转义

在已有引号的字段中，用 `""` 表示一个字面引号：

```
name,quote
李四,"他说""你好"""
```

### 4. 编码问题

CSV 文件的编码可能是 UTF-8、GBK（Windows 中文系统常见）、UTF-8 with BOM 等，编码不匹配会导致中文乱码。

## RFC 4180 标准

CSV 的事实标准由 [RFC 4180](https://tools.ietf.org/html/rfc4180) 定义，核心规则：

1. 每条记录独占一行，以 CRLF 结尾
2. 最后一条记录可以没有结尾换行
3. 第一行可选作为表头
4. 字段用逗号分隔
5. 含逗号、双引号或换行的字段必须用双引号包裹
6. 字段内的双引号用 `""` 转义
