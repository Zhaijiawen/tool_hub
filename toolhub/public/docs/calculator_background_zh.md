# 计算器 — 技术背景

## 浮点运算

计算机使用 **IEEE 754** 浮点标准以二进制表示数字。尽管这允许表示很大范围的值，但会引入细微的精度问题：

```javascript
0.1 + 0.2 === 0.3   // false
0.1 + 0.2           // 0.30000000000000004
```

这是因为 `0.1` 和 `0.2` 无法在二进制浮点数中精确表示。对于关键的金融或科学计算，应使用任意精度库。

## 运算优先级（PEMDAS/BODMAS）

标准算术遵循以下优先级：
1. **括号**
2. **指数**（幂和根）
3. **乘法**和**除法**（从左到右）
4. **加法**和**减法**（从左到右）

示例：`2 + 3 × 4 = 14`（不是 20）

## 整数除法 vs. 浮点除法

在许多编程语言中，两个整数相除执行**整数除法**（向零截断）：
```python
7 // 2 = 3   # Python 整数除法
7 / 2 = 3.5  # Python 浮点除法
```

在 JavaScript 中，`/` 始终返回浮点数：`7 / 2 = 3.5`。

## 科学记数法

极大或极小的数使用科学记数法：
- `1.5e6 = 1,500,000`
- `2.5e-3 = 0.0025`
