# 计算器没你想的那么简单

按几个按钮就出结果，看起来挺简单的事。但如果你写过 JavaScript，应该知道背后有些坑。

## 浮点数那个老问题

在浏览器控制台敲 `0.1 + 0.2`，出来的不是 `0.3` 而是 `0.30000000000000004`。这不是 bug，这是 IEEE 754 浮点标准在二进制里表示十进制小数时的精度问题。`0.1` 和 `0.2` 在二进制里是无限循环小数，就像十进制里的 1/3 永远写不完一样。

```javascript
0.1 + 0.2 === 0.3   // false，多少年了还是 false
0.1 + 0.2           // 0.30000000000000004
```

日常算算没什么影响。但如果你在做金额计算或者需要精确到小数点后很多位的场景，就要用 decimal.js 这类库了。我们的计算器跑在浏览器 JavaScript 里，同样受 IEEE 754 约束，心里有数就行。

## 先乘除后加减，别搞反了

运算优先级学校里都学过：括号 > 指数 > 乘除 > 加减，同级从左到右。`2 + 3 × 4` 不是 20 而是 14，因为乘法先算。想让它等于 20？加括号：`(2 + 3) × 4`。计算器严格按这个顺序来，不确定的时候加括号总是对的。

## 除法在这里永远是浮点

Python 里 `7 // 2` 给你整数 3，JavaScript 没有这种操作。`/` 永远返回浮点数，`7 / 2 = 3.5`。想要整数结果自己取整就行，不过大多数时候直接看小数结果更直观。

## 科学记数法

`1.5e6` 就是 1500000，`2.5e-3` 就是 0.0025。算超大或超小的数时很方便，计算器直接支持这种写法。

## 几个常用常数

| 常数 | 近似值 |
|---|---|
| π（圆周率） | 3.14159265358979 |
| e（自然常数） | 2.71828182845905 |
| √2 | 1.41421356237310 |
| φ（黄金比例） | 1.61803398874989 |

算圆面积、复利这些场景，内置 π 和 e 省得你手敲一长串数字。
