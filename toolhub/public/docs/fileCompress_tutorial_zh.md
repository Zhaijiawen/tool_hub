# 文件压缩 — 使用教程

把文件拖到页面上，或点击选择文件，就能开始压缩或解压。

## 压缩一个文件

1. 上传文件后，在「模式」里选 **压缩**。
2. 在「格式」里选 **Gzip** / **Brotli** / **Zstd**。
   - 选 Gzip 不需要调质量，它直接走浏览器原生流式压缩。
   - 选 Brotli 或 Zstd 会出现质量滑块：Brotli 1-11（默认 6），Zstd 1-19（默认 3）。数字越大压得越小越慢。
3. 点「压缩」按钮。Gzip 会显示实时进度条，并且处理中可随时取消。
4. 完成后显示原始大小、结果大小和压缩率，点下载保存。

> 压缩率 ≥ 100% 表示没压小（比如已经压缩过的文件再压没有意义），工具会提示你。

## 解压一个文件

1. 上传文件后，在「模式」里选 **解压**。
2. 如果是 `.gz` 或 `.zst`，工具会自动识别格式；如果是 `.br` 或其他，手动选 **Brotli**。
3. 点「解压」按钮，下载结果。

## 关于大小限制

- Brotli / Zstd 需要把整个文件读进内存。超过 **2GB** 会被直接拦下；超过 **500MB** 会先弹警告。
- Gzip 是流式的，没有大小上限，适合大文件。

## 小提示

- 想快速压一个几 GB 的日志或备份？用 **Gzip**。
- 想长期存档、追求最小体积？用 **Brotli**（质量调高）。
- 想要压缩率和速度都均衡？用 **Zstd**。
