# 颜色模型：HEX、RGB、HSL 为什么有这么多格式

做 Web 开发整天在颜色格式之间跳来跳去。每种格式都有它的适用场景，了解背后的逻辑就不用每次都查转换表了。

## RGB：屏幕实际用的颜色模型

RGB 是加法颜色模型 -- 红绿蓝三种光以不同强度混合，得到你看到的任何颜色。每个通道 0 到 255，总共 1670 万种可能。CSS 里写 `rgb(255, 0, 0)` 就是纯红。

带透明度就是 `rgba(255, 0, 0, 0.5)`，50% 透明的红色。alpha 通道 0 是完全透明，1 是完全不透明。

## HEX：把 RGB 写成十六进制

HEX 说白了就是 RGB 的十六进制写法。`#FF0000` 就是 R=255, G=0, B=0，跟 `rgb(255, 0, 0)` 完全一样。格式最紧凑，所以 CSS 和设计工具默认都用它。

还有缩写形式：`#F00` 等于 `#FF0000`，每位翻倍。带透明度是 8 位 hex：`#FF000080` 是 50% 透明的红色。

## HSL：给人看的，不是给机器看的

RGB 和 HEX 对计算机很友好，对人完全不是。"比这个蓝稍微亮一点"用 HSL 直接调亮度就行，用 RGB 就得拿计算器算了。

- **色相（Hue）**：色轮上的位置，0-360 度。0=红，120=绿，240=蓝。
- **饱和度（Saturation）**：颜色纯度。0% 是灰色，100% 是纯色。
- **亮度（Lightness）**：明暗程度。0% 是黑，50% 是纯色本身，100% 是白。

`hsl(210, 100%, 56%)` 是好看的天蓝色。改第三个数字就能得到同色系亮一点或暗一点的变体，程序化生成调色板的时候特别好用。

## HSV/HSB：跟 HSL 像但不一样

HSV（也叫 HSB）用 Value/Brightness 替代了 Lightness。`hsv(0, 100%, 100%)` 是纯红。Photoshop 的颜色选择器就用这个模型。跟 HSL 转换的时候要注意 -- 两个模型的计算逻辑不同，不是简单的加减。

## CMYK：印刷用的

减色模型，印刷行业用。四个通道：青（Cyan）、品红（Magenta）、黄（Yellow）、黑（Key/Black）。如果你做的东西要印出来才需要关心。只做屏幕显示的可以忽略。

## 快速换算参考

```
#3498db = rgb(52, 152, 219) = hsl(204, 70%, 53%)
```

HEX 和 RGB 之间就是进制转换，简单。HSL/HSV 的转换需要算，这就是工具帮你做的事。
