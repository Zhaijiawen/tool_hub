# 颜色转换 — 技术背景

## 颜色模型

数字系统中的颜色可以用多种模型表示，每种模型针对不同的使用场景。在 Web 开发和设计工作中，最常用的三种模型是 HEX、RGB 和 HSL。

## HEX（十六进制）

HEX 是 Web 开发中使用最广泛的颜色格式，用 6 位（或带透明度的 8 位）十六进制字符串表示颜色。

- 格式：`#RRGGBB` 或 `#RRGGBBAA`
- 示例：`#FF5733` 表示红色=255、绿色=87、蓝色=51
- 简写：`#RGB`（如 `#F53` 展开为 `#FF5533`）

每对十六进制数字代表一个颜色通道（0–255），用 16 进制数 `00` 至 `FF` 编码。

## RGB（红、绿、蓝）

RGB 是加法颜色模型，通过以不同强度混合红、绿、蓝三种光来创建颜色。

- 格式：`rgb(R, G, B)`，每个值范围 0–255
- 带透明度格式：`rgba(R, G, B, A)`，A 值范围 0–1
- 示例：`rgb(255, 87, 51)`

| 通道 | 范围 | 描述 |
|---|---|---|
| R（红） | 0–255 | 红色光强度 |
| G（绿） | 0–255 | 绿色光强度 |
| B（蓝） | 0–255 | 蓝色光强度 |
| A（透明度） | 0–1 | 不透明度（0=透明，1=不透明） |

## HSL（色相、饱和度、亮度）

HSL 是更符合人类直觉的颜色模型，用感知角度描述颜色。

- 格式：`hsl(H, S%, L%)`
- 示例：`hsl(14, 100%, 60%)`

| 分量 | 范围 | 描述 |
|---|---|---|
| H（色相） | 0–360° | 色轮位置（0=红，120=绿，240=蓝） |
| S（饱和度） | 0–100% | 颜色纯度（0%=灰色，100%=纯色） |
| L（亮度） | 0–100% | 明暗程度（0%=黑，50%=正常，100%=白） |

## 转换原理

HEX 与 RGB 之间的转换本质上是十进制与十六进制之间的互转。RGB 与 HSL 之间的转换需要先将 RGB 值归一化为 0–1 范围，再通过类三角函数计算确定色相角、饱和度和亮度。

## 应用场景

- **Web 开发** — CSS 使用 HEX 和 RGB；HSL 非常适合程序化颜色操作
- **设计工具** — Figma、Sketch 和 Photoshop 均支持多种颜色模型
- **无障碍设计** — WCAG 对比度计算需要 RGB 值
- **颜色主题** — 通过仅改变 HSL 的 L 值，可轻松创建一致的颜色系列
