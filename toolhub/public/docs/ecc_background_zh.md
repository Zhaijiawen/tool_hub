# 椭圆曲线密码学（ECC）背景

椭圆曲线密码学是近几十年公钥密码领域最重要的创新之一。核心洞察由 Neal Koblitz 和 Victor Miller 在 1985 年独立发现：有限域上椭圆曲线的数学性质能提供和 RSA 相同的密码学特性（逆转特定操作的困难性），但密钥小得多。256 位 ECC 密钥的安全性大约等同于 3,072 位 RSA 密钥。在我们到处在手机、智能卡和物联网传感器上做加密的时代，这个大小差别至关重要。

## 直观理解曲线

椭圆曲线和椭圆没有关系 -- 名字来源于历史上与椭圆积分的联系。对密码学而言，椭圆曲线是满足 y^2 = x^3 + ax + b 的点集，定义在某个有限域上，外加一个作为单位元的"无穷远点"。

神奇之处在于你可以在这些点上定义加法。过曲线上两点画一条直线，它与曲线交于第三点。把这个点关于 x 轴反射，就定义了 P + Q。如果在某点处画切线（给自己做加法），就得到标量乘法：P、2P、3P，以此类推。

标量乘法是一个单向函数。给定点 P 和标量 k，计算 kP 很快（用倍加算法，类似于快速幂）。给定 P 和 kP，求出 k -- 椭圆曲线离散对数问题（ECDLP）-- 在经典计算机上没有已知的高效解法。这就是 ECC 整个安全性基础。

## 曲线的选择比你想象的重要

不是所有曲线都一样安全，糟糕的曲线已经造成了真实的安全事故。最臭名昭著的例子是 Dual_EC_DRBG，一个 NIST 标准化的随机数生成器，里面包含了通过精心选择的曲线参数构造的后门。教训：使用参数生成过程透明、可验证的曲线。

今天的安全选择：

- **Curve25519**（Bernstein，2005）：为 Diffie-Hellman 密钥交换设计。参数选择绝对透明（p = 2^255 - 19，小于 2^255 且模 4 余 3 的最大素数）。快、恒定时间、几乎不可能实现出错。WireGuard、Signal、TLS 1.3 在用。
- **Ed25519**：Curve25519 的 Edwards 曲线版本，为数字签名优化。64 字节签名、确定性（没有随机 nonce 让你搞砸）、验证快。
- **NIST P-256**（secp256r1）：传统选择，由 NIST 标准化，到处都用。Dual_EC_DRBG 之后有些人不信任 NIST 曲线，但 P-256 经过独立分析，被认为是安全的。曲线参数可验证（从 SHA-1 种子哈希派生），不像 Dual_EC 那种神秘常数。

对新项目，大多数密码学家推荐 Curve25519/Ed25519。它的设计明确防止了困扰 ECDSA 的实现错误（nonce 重用、有偏 nonce、时序泄露）。

## ECDH 和 ECDSA：两个主要协议

ECC 提供两种主要操作：

**ECDH（椭圆曲线 Diffie-Hellman）**用于密钥交换。Alice 有私钥 a 和公钥 aG。Bob 有 b 和 bG。Alice 计算 a(bG)，Bob 计算 b(aG)，两人都得到 abG -- 共享密钥。看到 aG 和 bG 的窃听者无法在不解决 ECDLP 的情况下计算 abG。

**ECDSA（椭圆曲线数字签名算法）**用于签名。生成随机 nonce k，计算 kG（取 x 坐标为 r），计算 s = k^-1 * (hash + r * 私钥) mod n。签名是 (r, s)。验证检查一个涉及公钥、r 和 s 的等式是否成立。

ECDSA 有个致命的坑：如果在两次签名中重用同一个 nonce k，攻击者可以用简单代数从两次签名中恢复你的私钥。这件事真实发生过（PlayStation 3 的签名密钥就是这样被提取的）。Ed25519 通过让 nonce 变成确定性的 -- 从私钥和消息哈希派生 -- 从根本上杜绝了 nonce 重用。

## 量子考虑

ECC 不是后量子的。Shor 算法在足够大的量子计算机上能在多项式时间内解决 ECDLP，彻底破解 ECC。当可用的量子计算机出现时（最好估计：密码学相关规模的量子计算机还需要 10-20 年），ECC 密钥将和今天的 56 位 DES 密钥一样不安全。

向后量子密码的迁移已经在进行中（NIST 正在标准化基于格的算法），但与此同时，ECC 仍然是对性能敏感的公钥操作的实际最佳选择。
