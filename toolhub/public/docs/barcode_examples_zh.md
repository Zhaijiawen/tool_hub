# 条码识别 — 使用示例

## 商品包装上的 EAN / UPC
你手里一件进口商品，想查它的 EAN-13 码对应信息。

**操作：** 拍一张包装条码照片上传，点「识别」。
**结果：** 输出码制 `EAN_13` 与 13 位数字的编码文本，可直接用于查价、入库或比价。

## 收货单上的 Code 128
仓库到货，需要在系统里录入运单号（Code 128 一维码）。

**操作：** 用摄像头对准运单条码实时扫描。
**结果：** 自动解码出一串字母数字运单号，扫到即追加，无需手动敲键盘，减少录入错误。

## 活动海报里的二维码
线下活动海报印了一个二维码，想快速看它指向的链接。

**操作：** 上传海报截图，点「识别」。
**结果：** 输出码制 `QR_CODE` 与链接文本，复制后即可在浏览器打开核验，避免用手机扫码跳转。

## 身份证件 / 票据上的 PDF 417
某些票据或证件使用 PDF 417 码存储信息。

**操作：** 上传清晰票据照片识别。
**结果：** 解出 PDF 417 内的文本字段，便于核对，全程本地完成不泄露证件影像。

## 隐私敏感物料
你处理的是带条码的内部资产标签，不能外发。

**说明：** 图片与摄像头画面仅在本地浏览器解码，不经过任何外部服务器，比云端扫码服务更安心。
