# 文本反转 — 使用教程

## 使用步骤

### 第一步：输入文本
将需要反转的文本输入或粘贴到输入框中。

### 第二步：选择反转模式
- **反转文本** — 颠倒整个文本中的所有字符
- **反转单词** — 颠倒单词顺序（每行独立处理）
- **反转行** — 颠倒文本块中的行顺序

### 第三步：复制结果
反转后的文本显示在输出框中，点击**复制**按钮复制到剪贴板。

### 第四步：清空
点击**清空**按钮，同时重置输入和输出框。

## 示例

**反转文本：**
- 输入：`Hello`  →  输出：`olleH`

**反转单词：**
- 输入：`one two three`  →  输出：`three two one`

**反转行：**
- 输入：第1行 / 第2行 / 第3行  →  输出：第3行 / 第2行 / 第1行
