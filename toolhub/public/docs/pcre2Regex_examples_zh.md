# PCRE2 正则 — 使用示例

## 提取并重组日期（命名分组 + 替换）

**模式：** `(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})`
**文本：** `订单日期：2024-03-15，发货 2024-03-18`
**替换：** `$day/$month/$year`
**结果：** `订单日期：15/03/2024，发货 15/03/2024`

命名分组让替换模板可读性极高。

## 匹配嵌套括号（PCRE2 独有）

**模式：** `\((?:[^()]|(?R))*\)`
**文本：** `a(b(c)d)e`
**匹配：** `(b(c)d)`

JS 正则无法递归匹配，PCRE2 的 `(?R)` 轻松处理嵌套。

## 提取邮箱

**模式：** `[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}`
**文本：** `联系 alice@example.com 或 bob@test.org`
**匹配：** `alice@example.com`、`bob@test.org`

## 忽略大小写 + 多行

**模式：** `^error` ，勾 `i` 和 `m`
**文本：**
```
Error: disk full
warning: low mem
ERROR: timeout
```
**匹配：** 第 1 行和第 3 行的 `Error` / `ERROR`（`m` 让 `^` 匹配每行开头，`i` 忽略大小写）。
