# Argon2 技术背景

Argon2 是 2024 年及以后你应该使用的密码哈希算法。它赢得了 2015 年的密码哈希竞赛，击败了二十多个候选方案，后来在 RFC 9106 中标准化。设计团队 -- Alex Biryukov、Daniel Dinu 和 Dmitry Khovratovich -- 专门设计它来让拥有专用硬件的攻击者头疼。这就是 Argon2 的核心思路：内存密集型。

## "内存密集型"到底是什么意思

Argon2 之前的密码哈希大多设计成 CPU 密集型 -- 提高迭代次数，暴力破解的成本线性增长。问题是 GPU 和 ASIC 在并行计算上优势太大。一个有几千个核心的 GPU 可以比你的服务器 CPU 快几千倍地尝试密码。这根本不是公平的对决。

内存密集型改变了游戏规则。Argon2 强制算法分配并反复访问一大块内存 -- 几十甚至几百 MB。GPU 的显存虽然快，但每个核心分到的不多。如果 ASIC 要大规模破解 Argon2 哈希，就需要惊人的 RAM 容量，这让破解设备的成本上升好几个数量级。这比单纯让哈希变慢要优雅得多。

## 三种变体及选用建议

Argon2 有三种口味，初次接触时名字有点绕：

**Argon2d** 是最快的。内存访问模式依赖于数据 -- 访问路径跟密码本身有关。这让 GPU/ASIC 攻击最难受，但也意味着能观察到内存访问模式的攻击者（侧信道攻击）可能获取密码信息。只在侧信道不是威胁时用 -- 比如你完全控制的独立服务器。

**Argon2i** 是抗侧信道版。内存访问与数据无关 -- 不管什么密码，访问模式都一样。这意味着不会有信息通过时序或缓存行为泄露，但代价是更容易被并行硬件优化。当你担心侧信道时用这个，比如共享主机环境。

**Argon2id** 是混合版，也是你应该默认使用的。前半段用 Argon2i 式的数据无关访问（防止最敏感阶段的侧信道泄露），后半段切换到 Argon2d 式的数据相关访问（对 GPU 攻击关上大门）。RFC 9106 和 NIST 都推荐它作为默认选择。

## 底层：Blake2b 加内存矩阵

Argon2 基于 Blake2b，这是一个在 64 位平台上比 SHA-256 快得多的高性能加密哈希。算法先用从密码、盐值和其他参数派生的伪随机数据填充一大块内存。然后在内存中反复迭代，从不同位置读取和写入，创建依赖链 -- 没有完整的内存数组就无法计算任何块。

三个可调节的参数：

- **内存成本（m）** -- 使用多少 KiB 内存。从 64 MB（开发环境）到 256 MB 以上（生产环境）。越多内存意味着越能抵抗硬件攻击。
- **时间成本（t）** -- 对内存做多少次遍历。每次遍历加倍计算时间。1-3 很常见；超过 10 基本没什么意义。
- **并行度（p）** -- 同时处理多少个独立通道。通常 1-4。高并行度在典型服务器硬件上帮助不大，反而会因分散每个通道的可用内存而降低安全性。

遍历完成后，最后一个内存块再用 Blake2b 哈希一次，生成输出哈希 -- 通常是 32 字节，但可配置。

## Argon2id 参数选择的坑

很多人在这上面踩过坑：你得在内存和时间成本与生产服务器实际能承受的范围之间找平衡。如果设成 1 GB 内存导致登录请求在两核服务器上耗时 3 秒，用户体验会很差，迟早有人会把它调低到不安全的值来平息抱怨。

更好的做法：在实际生产硬件上做基准测试。选择能让单次哈希在 0.5-1 秒内完成的参数。这对用户来说感知不到延迟，但攻击者尝试数十亿个猜测则需要几百年和电力公司的预算。然后设置监控，当平均哈希时间发生变化时报警（可能意味着有人改了配置，或者硬件意外升级了）。

## 从 bcrypt 或 PBKDF2 迁移

如果你现在用的是 bcrypt 或 PBKDF2-SHA256，迁移到 Argon2id 是明显的安全升级。bcrypt 限制密码输入 72 字节，固定 4 KB 内存占用 -- 在 1999 年没问题，现在就不太够了。PBKDF2 只是一层层迭代 SHA 哈希，完全没有内存组件。

迁移策略：用户登录时，如果他们的哈希还是旧格式，先用旧算法验证，然后透明地用 Argon2id 重新哈希并存储新哈希。一段时间后，活跃用户的密码库就都升级了。还可以加个"最后登录"字段，对 N 个月没登录的用户直接重置密码强制升级。

## 量子抗性

Argon2 并非专门为后量子时代设计，但它的内存密集型特性给它带来了意外的优势。量子计算机不能神奇地绕过内存 -- Grover 算法加速的是无序数据搜索，但它不能让 RAM 变便宜。所以拥有量子计算机的攻击者可能把哈希输出的有效安全性减半（从前像攻击的 256 位降到 128 位），但每次猜测仍然需要同样巨大的内存。这意味着 Argon2 面对量子攻击比纯 CPU 密集型方案表现更好。
