# 颜色选择器与转换器 — 使用教程

## 使用步骤

### 选取颜色
使用色盘或渐变面板可视化地选择任意颜色。工具会自动以所有支持的格式（HEX、RGB、HSL、HSV、CMYK）显示颜色值。

### 在格式间转换
1. 在任意支持的格式中输入颜色值（例如 `#3498db`、`rgb(52, 152, 219)`、`hsl(204, 70%, 53%)`）
2. 工具会即时转换并以所有其他格式展示
3. 点击任意格式旁边的复制图标即可复制该值

### 支持的输入格式
- **HEX**：`#RGB`、`#RRGGBB`、`#RRGGBBAA`
- **RGB**：`rgb(r, g, b)` 或 `rgba(r, g, b, a)`
- **HSL**：`hsl(h, s%, l%)` 或 `hsla(h, s%, l%, a)`
- **HSV/HSB**：h、s、v 数值

## 使用技巧

- **设计一致性**：复制 HEX 值用于 CSS、Tailwind 或设计工具
- **无障碍性**：文字与背景颜色对比度合理可改善视觉障碍用户的阅读体验
- **透明度控制**：调整 Alpha 滑块为任意颜色添加透明度
