# 颜色选择器与转换器 -- 使用指南

可视化选色或者直接输入任意格式的颜色值，工具同步显示所有格式。

## 选取颜色

用色盘或渐变面板拖拽选色，所有格式的值实时更新：HEX、RGB、HSL、HSV、CMYK。也可以用各通道的滑块微调。

## 格式互转

手头已经有个颜色值？在任意格式里输入，工具即时转换成其他所有格式：

- **HEX**：`#3498db`，支持 `#RGB` 简写和 8 位 `#RRGGBBAA` 带透明度
- **RGB**：`rgb(52, 152, 219)` 或 `rgba(52, 152, 219, 0.5)`
- **HSL**：`hsl(204, 70%, 53%)` 或 `hsla(204, 70%, 53%, 0.5)`
- **HSV**：色相、饱和度、明度三个数字

点任意格式旁边的复制图标，单独复制那个值。

## 每种格式什么时候用

- **HEX**：CSS、Tailwind 配置、设计交付文档。大多数工具默认接受 hex。
- **RGB/RGBA**：需要 alpha 透明度且要广泛兼容的时候。JS Canvas 操作也常用。
- **HSL**：生成颜色系列。做同一色系的 5 个深浅变体？固定 H 和 S，L 从 90% 到 10% 滑过去就行，比调 RGB 值直观多了。
- **HSV**：跟用 Photoshop 的设计师协作时他们看的多半是这个。
- **CMYK**：印刷才需要。工具展示的是近似转换值，实际印刷颜色还跟纸张、油墨和印刷机校准有关。

## 透明度控制

Alpha 滑块给任意颜色加透明度。这个跟颜色格式无关 -- 你可以有带 alpha 的 HEX（8 位 hex）、RGBA、HSLA，工具三种都显示。

## 无障碍提示

如果是在选文字颜色和背景色，肉眼判断一下对比度。WCAG 合规要求特定对比度比值（普通文字 4.5:1，大字 3:1）。这个工具不直接算对比度，但有了 RGB 值就可以丢到专门的对比度检查器里验一下。
