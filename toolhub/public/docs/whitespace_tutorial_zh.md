# 空白字符处理 — 使用教程

## 使用步骤

### 第一步：输入文本
将需要处理的文本粘贴到输入框中，支持多行文本。

### 第二步：选择操作

**去除首尾空白（Trim）**
去除文本开头和结尾的所有空白字符，不影响内部空白。
- 输入：`  hello world  `
- 输出：`hello world`

**压缩空白（Compress）**
将文本中所有连续的空白字符（空格、制表符等）替换为单个空格，同时去除首尾空白。
- 输入：`hello    world   foo`
- 输出：`hello world foo`

### 第三步：复制结果
处理结果显示在输出框中，点击**复制**按钮复制到剪贴板。

## 常见使用场景

1. **表单输入清理** — 在验证或存储前 trim 用户提交的数据
2. **日志清理** — 压缩日志消息中不规则的空格，便于解析
3. **CSV 预处理** — 规范化分隔符周围的空白字符
4. **代码片段清理** — 去除粘贴代码中的多余空格
