# Diff 文本对比 -- 使用指南

旧文本放左边，新文本放右边，工具标出所有改动。

## 基本操作

界面分左右两个文本区：

- **左侧**：原始文本（旧版本）
- **右侧**：修改后的文本（新版本）

两边都粘贴或手敲进去，都支持多行。点**对比**按钮（或者开启自动对比，每敲一个字就实时更新），差异立刻高亮显示。

## 结果怎么看

- **绿色背景**：新增内容 -- 右边有左边没有
- **红色背景**：删除内容 -- 左边有右边没有
- **无背景**：没变的内容

顶部统计栏：`+N 行新增 / -N 行删除`。快速扫一眼就知道改动的规模。

## 对比模式

- **行级对比**：按行比较。代码、配置文件、日志这些结构化文本用这个。
- **字符级对比**：精确到每个字符。短文本、单个句子、需要看清单词内部改了什么的时候用。

顶部切换按钮切换模式。行级显示"整行都改了"但你想看看是不是就改了个拼写错误？切成字符级就清楚了。

## 几个好用的功能

- **互换**：左右内容对调。想看反向视角 -- "他们加了什么" vs "他们删了什么" -- 的时候用。
- **复制左侧 / 复制右侧**：把任意一侧的内容复制到剪贴板。
- **清空**：全部清除重新开始。

## 实用技巧

### 先统一格式再对比

两段文本缩进、换行符或行尾空格不一致的时候，diff 结果会充满格式噪音。先用格式化工具统一，或者切到字符级模式，它能识别出实际内容一致只是空白不同。

### 选对对比模式

| 场景 | 推荐模式 |
|---|---|
| 代码文件 | 行级 |
| 长文档 | 行级 |
| 短句/单词修改 | 字符级 |
| JSON/YAML 配置 | 行级 |
| 排查某个字符串的具体变化 | 字符级 |

### 统计数据怎么看

`+N / -N` 的数字帮你快速判断改动性质：
- 大量 `-` 少量 `+`：代码精简或删功能
- 大量 `+` 少量 `-`：新功能或新增内容
- 增删数量相近：重写或重构 -- 内容量差不多，结构变了

## 常见问题

**一模一样的内容被标记为改了**：通常是不可见字符搞的鬼 -- Windows 的 `\r\n` 和 Unix 的 `\n` 换行符不一样，或者有 Unicode 零宽空格。清理文本或者从确定干净的来源重新粘贴。

**超长文本对比慢**：上万行之后 diff 计算确实要等一会。特别长的对比建议只截取预期有差异的段落。
