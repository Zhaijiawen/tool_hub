# Diff 文本对比 - 使用教程

## 快速开始

Diff 文本对比工具可以帮助你快速找出两段文本的差异，无论是代码对比、文档修订还是配置比较都能轻松应对。

## 基本使用流程

### 步骤 1：输入文本

工具界面分为左右两栏：
- **左侧**：输入原始文本（旧版本）
- **右侧**：输入修改后的文本（新版本）

你可以直接粘贴文本，也可以手动输入。两栏均支持多行文本。

### 步骤 2：选择对比模式

点击顶部的模式切换按钮：
- **行级对比**：按行比较，适合代码和配置文件
- **字符级对比**：精确到每个字符，适合短文本

### 步骤 3：执行对比

点击 **"对比"** 按钮，或修改文本后自动触发实时对比。

### 步骤 4：查看结果

对比结果以高亮方式展示：
- 🟢 **绿色背景**：新增内容（右侧有，左侧无）
- 🔴 **红色背景**：删除内容（左侧有，右侧无）
- ⬜ **无背景**：未变化的内容

顶部统计栏显示：`+N 行新增 / -N 行删除`

## 功能详解

### 互换左右内容

点击 **"互换"** 按钮，左右内容互换，快速进行反向对比。这在审查修改者提交的内容时非常有用。

### 复制功能

- **复制左侧**：将左侧内容复制到剪贴板
- **复制右侧**：将右侧内容复制到剪贴板
- **复制差异**：仅复制有差异的部分（如支持）

### 清空功能

点击 **"清空"** 按钮清除所有输入和结果，开始新的对比任务。

## 使用场景示例

### 场景一：对比代码改动

**原始代码（左侧）：**
```javascript
function greet(name) {
  console.log('Hello ' + name);
}
```

**修改后代码（右侧）：**
```javascript
function greet(name, title = '') {
  const greeting = title ? `Hello ${title} ${name}` : `Hello ${name}`;
  console.log(greeting);
}
```

对比结果将高亮显示：新增的参数、新增的行、删除的旧行。

### 场景二：文档修订对比

**原始文本（左侧）：**
```
本产品适用于企业用户，提供基础功能套件。
价格为每月 99 元。
```

**修订文本（右侧）：**
```
本产品适用于企业和个人用户，提供完整功能套件。
价格为每月 79 元起。
```

字符级对比将精确标注每个改动的词汇。

### 场景三：配置文件差异

比较两个环境（dev/prod）的配置文件，快速定位差异配置项。

## 实用技巧

### 技巧 1：先清理格式再对比

如果两段文本格式不一致（缩进、换行符不同），建议先通过格式化工具统一格式，再进行对比，可以减少无意义的格式差异干扰。

### 技巧 2：利用互换功能

当你收到别人的修改版本，想知道他们改了什么时：
1. 左侧放你的原版
2. 右侧放他们的修改版
3. 结果即为他们的所有改动

### 技巧 3：行级 vs 字符级的选择

| 场景 | 推荐模式 |
|------|---------|
| 代码文件 | 行级对比 |
| 长篇文档 | 行级对比 |
| 短句/单词修改 | 字符级对比 |
| JSON/YAML 配置 | 行级对比 |

### 技巧 4：统计数字的意义

顶部的 `+N / -N` 统计帮助你快速了解改动规模：
- 大量删除少量增加 → 可能是代码精简
- 大量增加少量删除 → 可能是新功能添加
- 增删数量相近 → 可能是内容替换或重构

## 常见问题

**Q：为什么相同的内容被标记为修改？**

A：可能是不可见字符（如 Windows 换行符 `\r\n` vs Unix `\n`，或 Unicode 不可见空格）导致的。可以尝试先用文本处理工具清理。

**Q：文本很长时对比速度慢？**

A：超大文本的 diff 计算需要时间，建议只截取有差异的片段进行对比。

**Q：对比结果支持导出吗？**

A：可以复制对比结果到其他工具中使用。
