# 音视频处理 — 使用教程

顶部三个标签页对应三个功能。

## 视频转码

1. 在「视频转码」标签页上传一个视频（MP4 / MOV / WebM / MKV / AVI 等）。
2. 选输出格式：**MP4 (H.264)** 或 **WebM (VP8)**。
3. 选质量（CRF）：往左质量高体积大，往右体积小质量低。
4. 需要缩小就选缩放档位。
5. 点「开始转码」，完成后可直接预览、下载。

## 提取音频

1. 切到「提取音频」标签页，上传视频或音频文件。
2. 选输出格式：MP3 / M4A / WAV / OGG / Opus。
3. 点「提取音频」，下载结果。

## 视频转 GIF

1. 切到「视频转 GIF」标签页，上传视频。
2. 调帧率（5-30fps）和宽度（80-800px）。帧率低、宽度小，GIF 更轻。
3. 点「生成 GIF」，下载。

## 小提示

- 给网页用的视频，转 **WebM** 通常更省带宽。
- 只要声音、不要画面，用「提取音频」选 **MP3**。
- GIF 适合短循环动图；长视频别转 GIF，会非常大。
