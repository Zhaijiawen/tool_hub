# 字符编码速查示例

常见字符的各种编码格式，方便对照。

## 基本拉丁字符

| 字符 | 十进制 | 十六进制 | HTML 实体 | URL 编码 |
|---|---|---|---|---|
| `A` | 65 | 41 | `&#65;` | `%41` |
| `a` | 97 | 61 | `&#97;` | `%61` |
| `0` | 48 | 30 | `&#48;` | `%30` |
| 空格 | 32 | 20 | `&#32;` | `%20` |

规律记住：大写 A-Z 是 65-90，小写 a-z 是 97-122，数字 0-9 是 48-57。经常用到，背下来不亏。

## HTML 敏感字符

这几个字符要安全渲染到 HTML 里必须做实体编码：

| 字符 | 十进制 | 十六进制 | 命名实体 |
|---|---|---|---|
| `<` | 60 | 3C | `&lt;` |
| `>` | 62 | 3E | `&gt;` |
| `&` | 38 | 26 | `&amp;` |
| `"` | 34 | 22 | `&quot;` |
| `'` | 39 | 27 | `&apos;` |

写模板引擎或者任何输出 HTML 的工具时，这几个是必须处理的，漏一个就有 XSS 风险。

## Unicode 非 ASCII 字符

| 字符 | Unicode | UTF-8 字节 | 备注 |
|---|---|---|---|
| `€` | U+20AC | E2 82 AC | 欧元符号 -- UTF-8 占 3 字节 |
| `©` | U+00A9 | C2 A9 | 版权符号 |
| `中` | U+4E2D | E4 B8 AD | 汉字 -- 也是 3 字节 |
| `😀` | U+1F600 | F0 9F 98 80 | Emoji -- 4 字节，JS 里是代理对 |

Emoji 这个例子很好地说明了"字符"和"码元"是两回事。`'😀'.length` 在 JavaScript 里是 2，因为它占两个 UTF-16 码元。

## 那些让你 debug 到崩溃的不可见字符

| 字符 | Unicode | 坑在哪 |
|---|---|---|
| 零宽空格 | U+200B | 看不见但是真实存在的字符，字符串比较对不上 |
| BOM | U+FEFF | 字节序标记，Windows 保存 UTF-8 文件经常带上 |
| 不间断空格 | U+00A0 | 看起来像空格但 `trim()` 去不掉 |

两个字符串看起来一模一样但怎么比都不相等，十有八九就是这些不可见字符搞的鬼。把文本丢进转换器，看看有没有你不认识的码点。
