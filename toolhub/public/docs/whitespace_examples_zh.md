# 空白字符处理 — 使用示例

## 清理用户输入

这是你最常用 trim 的场景。某人在表单里输入姓名，带上了多余的空格。

**输入：**
```
   张三
```
**Trim 输出：**
```
张三
```

前面的空格（以及如果有的话，尾随换行符）都没了。「张」和「三」之间的空格保留。如果用户输入的是 `   张   三   `，中间有额外空格，trim 会给你 `张   三`——它不碰中间部分。要处理中间的，你需要 compress。

## 规范化 CSV 行

从不同工具导出的 CSV 文件，分隔符周围的间隔经常不一致。这会搞崩期望干净数据的解析器。

**输入：**
```
姓名,   年龄,   城市
张三,   25,    北京
```
**压缩输出：**
```
姓名, 年龄, 城市
张三, 25, 北京
```

Compress 把每簇空白替换为单个空格。逗号现在每个后面恰好一个空格，值都干净了。如果接下来要解析这个 CSV，字段值能够预期地匹配了。

Compress 之后 CSV 干净到可以解析，但对于引号包裹字段、内嵌逗号和换行这类高级情况，你可能还是想要一个专门的 CSV 工具。空白字符工具解决间距问题；CSV 解析器解决格式问题。

## 修复粘贴文本的不规则间隙

从 PDF、网页或即时聊天复制来的内容经常带着随机的多余空格，源内容的布局把词打散了。

**输入：**
```
快速    的   棕色    狐狸    跳过
懒惰    的    狗
```
**压缩输出：**
```
快速 的 棕色 狐狸 跳过
懒惰 的 狗
```

词之间的换行在压缩输出中被保留为单空格。如果你想全部合并成一行，需要额外的一步把换行转成空格。工具保留行的结构，同时在每行内部规范化水平空白。

## 去除配置值里的尾随换行

配置文件和环境变量里的常见 bug：尾随换行悄悄混进值里。

**输入：**
```
DATABASE_URL=postgres://localhost/db
```
（`db` 后面有一个尾随换行）

**Trim 输出：**
```
DATABASE_URL=postgres://localhost/db
```

尾随换行没了。如果你的应用从文件读取环境变量并且包含了那个换行，连接字符串就无效了——`postgres://localhost/db\n` 不是一个合法的 URL。在配置加载器里对每行做 trim 可以防止这个问题。

## 清理混用的制表符和空格

代码编辑器有「Tab 还是空格」的设置，不同人的选择永远不统一。当你从不同缩进风格的来源粘贴代码，得到的是一团混乱。

**输入：**
```
function foo() {
	   return 	42;
}
```
（`return` 和 `42` 之间混了制表符和空格）

**压缩输出：**
```
function foo() { return 42; }
```

Compress 把所有空白序列——包括制表符——转成单个空格。对于代码缩进来说这是破坏性的（要保留缩进你应该用格式化工具），但对于提取逻辑内容到可读的单行，比如写提交信息或构建搜索索引，这正合适。
