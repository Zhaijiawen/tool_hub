# PNG 优化 — 使用示例

## 优化一个网页截图

**输入：** `screenshot.png`（1.4 MB）
**操作：** 级别 3，优化 Alpha 开
**输出：** `screenshot.optimized.png`（约 980 KB，省 30%）

截图常带冗余元数据，无损优化能稳定省一截。

## 优化一个带透明的 logo

**输入：** `logo.png`（420 KB，透明背景）
**操作：** 级别 4，优化 Alpha 开
**输出：** `logo.optimized.png`（约 180 KB，省 57%）

透明通道是冗余重灾区，开优化 Alpha 收益明显。

## 已经压过的图再压（无收益）

**输入：** `already.opt.png`（之前用 Oxipng 压过）
**操作：** 级别 6
**结果：** 显示「无收益」

别白等——它确实压不动了，工具如实告诉你。

## 压一个相机截的 UI 图

**输入：** `ui.png`（2.2 MB）
**操作：** 级别 3
**输出：** 约 1.5 MB，省 32%

大尺寸 UI 图冗余多，优化效果比小图更明显。
