# Number to Chinese — Tutorial

## Quick Start

1. Enter a number in the input field (or click a quick example)
2. Select a conversion mode
3. View and copy the result

## Mode Guide

| Mode | Use Case |
|------|----------|
| Uppercase (壹贰叁) | Formal documents, contract amounts |
| Lowercase (一二三) | Casual writing, informal contexts |
| Financial | Checks, bank transfers, invoices |

## Supported Input Formats

- **Integers**: `100`, `12345`, `100000000`
- **Decimals**: `100.50`, `1234.99` (Financial mode only uses 2 decimal places)
- **Negatives**: `-100`, `-1234.56`

## Financial Mode Format Rules

| Input | Result |
|-------|--------|
| 100 | 壹佰元整 |
| 100.50 | 壹佰元伍角 |
| 100.05 | 壹佰元零伍分 |
| 100.55 | 壹佰元伍角伍分 |
| 0 | 零元整 |
