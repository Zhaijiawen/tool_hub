# 使用教程：把图片转成 SVG

## 一、准备一张合适的图片

在打开工具之前，先判断图片是否适合矢量化。本工具使用的是单色追踪算法，最理想的输入是：

- 白底上的黑色 Logo、图标或文字
- 手绘线稿、签名扫描件
- 拓印图案、剪影图

**不太适合**的输入：彩色照片、带渐变的设计图、背景杂乱的拍摄件。这类图片会被强制压成黑白轮廓，结果通常难以使用。

如果只有拍摄件，建议先做两步预处理（用本站的图像工具即可）：
1. 裁剪掉无关背景，只保留主体
2. 适当提高对比度，让线条与背景分明

## 二、上传图片

1. 点击工具页面中间的虚线区域，或点击「选择图片」按钮
2. 选择本地图片文件（PNG / JPG / WebP 等常见格式）
3. 上传成功后会显示原图预览，下方同时显示文件名、体积与像素尺寸

图片不会上传到任何服务器，转换全程在你的浏览器本地完成。

## 三、调节参数

### 黑白阈值（0–255）

这是影响结果最关键的参数。系统按亮度判断每个像素：亮度**低于**阈值 → 变黑并成为 SVG 图形；高于阈值 → 归入白色背景。

调节方向：

| 现象 | 判断 | 处理方式 |
| --- | --- | --- |
| 输出线条太细、笔画断裂 | 阈值过高或过低导致浅色部分丢失 | 观察预览，向能补全线条的方向微调 |
| 输出一片黑块、糊成一团 | 阈值过高，纳入了太多区域 | 调低阈值 |
| 图形整体缺失、几乎空白 | 阈值过低 | 调高阈值 |

默认阈值 128 是大多数白底黑稿的合适起点。

### 反色开关

深色会被当作图形（前景）。因此：

- **白底黑字/黑线** → 保持关闭（默认）
- **黑底白字/白线** → 必须开启

一个简单的判断方法：如果输出结果的形状看起来像原图的"底片"（该有的地方是空的，该空的地方是实的），把反色打开即可。

### 处理宽度

可选「原图尺寸」或限制为 1600 / 1000 / 600 px。

追踪耗时随像素面积增长，若原图很大（例如超过 3000px 宽）建议选择 1000 或 1600，速度差异非常明显。对 Logo 这类小图，保留原图尺寸即可。

## 四、执行转换

点击「转为 SVG」按钮，按钮会变为「追踪中…」。完成后页面下方会并列展示：

- 左侧：原图
- 右侧：SVG 矢量结果（棋盘格背景用于体现透明区域）

下方还会显示输出 SVG 的体积、处理耗时与输出尺寸。

## 五、导出结果

- **下载 SVG**：保存为 `.svg` 文件，文件名沿用上传图片的主名
- **复制 SVG 源码**：把 SVG 文本复制到剪贴板，可直接粘贴进 HTML 或设计工具

输出的 SVG 为纯黑填充（`fill="#000000"`），需要改色时用文本编辑器打开，替换该颜色值即可。

## 六、常见问题

**转换失败或结果异常**
通常是阈值不合适或图片过大。尝试调整阈值，或把处理宽度降到 1000 px 再试。

**输出有很多杂散小块**
扫描件上的噪点、污渍会被当作图形。先用图像处理工具清理背景，或提高阈值让浅色噪点被归入背景。

**SVG 文件比原图还大**
复杂照片被强制二值化后会产生海量零碎路径。这类图片不适合本工具，建议改用矢量重绘。

**想要保持多种颜色**
本工具只能输出单色矢量图。多色矢量化需要不同的算法（如颜色分层追踪），本站暂未提供。
