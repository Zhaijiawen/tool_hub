# PCRE2 正则 — 技术背景

这个工具在浏览器里用 **PCRE2** 的 WASM 版本运行正则表达式，支持匹配、替换、分组提取。与 JavaScript 自带的正则不同，PCRE2 实现了 Perl 兼容的正则语义，能力更强。

## 和 JS 正则的区别

JS 的正则（基于 ECMAScript 标准）缺少一些高级特性。PCRE2 额外支持：

- **递归匹配 / 子程序调用**：`(?R)`、`(?1)` 等，能匹配嵌套结构（如配对括号）。
- **命名子程序、条件表达式**：`(?(1)yes|no)`。
- **更丰富的断言**：后向断言在 PCRE2 里没有 JS 那种长度限制。
- **更完整的字符类**：`\R`（任意换行）、`\K`（重置匹配起点）等。

## 标志位

可勾选：`i` 忽略大小写、`m` 多行、`s` 点匹配换行、`x` 宽松注释、`u` UTF、`UCP` Unicode 属性、`U` 非贪婪、`A` 锚定、`D` 行末仅 `$`、`n` 禁用编号捕获。

## 结果展示

- 匹配总数、捕获组数、命名组数、是否含反向引用。
- 每条匹配显示位置、内容、编号分组 `$(n)`、命名分组。
- 编译错误会显示错误信息和出错偏移量，方便定位。
