# Calculator — Examples

## Example 1: Basic Arithmetic

```
125 + 37 = 162
1000 - 456 = 544
24 × 15 = 360
100 ÷ 8 = 12.5
```

## Example 2: Percentage Calculations

```
# 20% of 500
500 × 20% = 100

# Price after 15% discount
1200 × (1 - 15%) = 1200 × 0.85 = 1020

# What percentage is 75 of 300?
75 ÷ 300 × 100 = 25%
```

## Example 3: Scientific Calculations

```
# Area of a circle with radius 5
π × 5² = 3.14159 × 25 ≈ 78.54

# Compound interest (principal 10000, 5% annual, 3 years)
10000 × 1.05³ = 10000 × 1.157625 ≈ 11576.25

# Pythagorean theorem: hypotenuse of 3-4-5 triangle
√(3² + 4²) = √(9 + 16) = √25 = 5
```

## Example 4: Unit Conversions Using Calculator

```
# Celsius to Fahrenheit
(37 × 9 ÷ 5) + 32 = 98.6°F

# Miles to kilometers
100 × 1.60934 = 160.934 km

# Megabytes to bytes
250 × 1000 × 1000 = 250,000,000 bytes
