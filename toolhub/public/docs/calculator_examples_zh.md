# 计算器使用示例

日常实际会用到的计算场景，比干巴巴的公式有参考价值。

## 普通加减乘除

没什么特别的，就是平时拿计算器算的那些：

```
125 + 37 = 162
1000 - 456 = 544
24 × 15 = 360
100 ÷ 8 = 12.5
```

## 百分比计算技巧

百分比这玩意经常有人算错，几个常见场景的处理方式：

```
# 500 的 20% 是多少？500 乘以 20%：
500 × 20% = 100

# 1200 块的东西打 85 折后多少钱？
1200 × (1 - 15%) = 1200 × 0.85 = 1020
（技巧：用 (1 - 折扣%) 比先算折扣再减快）

# 75 是 300 的百分之几？
75 ÷ 300 × 100 = 25%
```

`%` 按钮把数字转成小数 -- `15%` 变成 `0.15`。然后你想算什么百分比直接乘就行。

## 科学和数学计算

```
# 半径 5 的圆面积：
π × 5² = 3.14159 × 25 ≈ 78.54

# 复利计算：本金 10000，年利率 5%，3 年：
10000 × 1.05³ = 10000 × 1.157625 ≈ 11576.25
（每年乘 1.05，3 年就是 1.05 的三次方）

# 勾股定理 -- 3-4-5 直角三角形的斜边：
√(3² + 4²) = √(9 + 16) = √25 = 5
```

## 顺手做单位换算

懒得开专门的换算工具时直接用计算器：

```
# 摄氏度转华氏度（体温 37°C）：
(37 × 9 ÷ 5) + 32 = 98.6°F

# 英里转千米（100 英里）：
100 × 1.60934 = 160.934 千米

# 兆字节转字节（250 MB）：
250 × 1000 × 1000 = 250,000,000 字节
```

当然不如专用换算器方便，但临时要个数字的时候够用。
