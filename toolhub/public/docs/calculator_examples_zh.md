# 计算器 — 使用示例

## 示例 1：基本算术

```
125 + 37 = 162
1000 - 456 = 544
24 × 15 = 360
100 ÷ 8 = 12.5
```

## 示例 2：百分比计算

```
# 500 的 20%
500 × 20% = 100

# 打 85 折后的价格
1200 × (1 - 15%) = 1200 × 0.85 = 1020

# 75 是 300 的百分之几？
75 ÷ 300 × 100 = 25%
```

## 示例 3：科学计算

```
# 半径为 5 的圆面积
π × 5² = 3.14159 × 25 ≈ 78.54

# 复利（本金 10000，年利率 5%，3 年）
10000 × 1.05³ = 10000 × 1.157625 ≈ 11576.25

# 勾股定理：3-4-5 三角形的斜边
√(3² + 4²) = √(9 + 16) = √25 = 5
```

## 示例 4：利用计算器做单位换算

```
# 摄氏转华氏
(37 × 9 ÷ 5) + 32 = 98.6°F

# 英里转千米
100 × 1.60934 = 160.934 千米

# 兆字节转字节
250 × 1000 × 1000 = 250,000,000 字节
