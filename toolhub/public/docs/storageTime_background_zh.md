# 存储与时间转换器 — 技术背景

## 存储单位

数字存储以位（bit）和字节（byte）的倍数来衡量，存在两套前缀体系：

### SI（十进制）前缀 — 以 1000 为倍数
| 单位 | 符号 | 值 |
|---|---|---|
| 千字节 | KB | 1,000 字节 |
| 兆字节 | MB | 1,000,000 字节 |
| 吉字节 | GB | 1,000,000,000 字节 |
| 太字节 | TB | 1,000,000,000,000 字节 |

存储设备制造商（硬盘/SSD 容量标注）使用此标准。

### IEC（二进制）前缀 — 以 1024 为倍数
| 单位 | 符号 | 值 |
|---|---|---|
| 千位字节 | KiB | 1,024 字节 |
| 兆位字节 | MiB | 1,048,576 字节 |
| 吉位字节 | GiB | 1,073,741,824 字节 |
| 太位字节 | TiB | 1,099,511,627,776 字节 |

操作系统传统上使用二进制单位，这就是为什么标称"1 TB"的硬盘在 Windows 中显示为约 931 GB。

## 时间单位

| 单位 | 秒数 |
|---|---|
| 纳秒 (ns) | 0.000000001 |
| 微秒 (µs) | 0.000001 |
| 毫秒 (ms) | 0.001 |
| 秒 (s) | 1 |
| 分钟 (min) | 60 |
| 小时 (h) | 3,600 |
| 天 (d) | 86,400 |
| 周 (w) | 604,800 |
| 月 (mo) | ~2,629,800（平均值） |
| 年 (y) | 31,557,600（儒略年） |

## 为什么转换很重要

- **网络吞吐量**：通常以 bps（位/秒）而非字节计量
  - 100 Mbps ÷ 8 = 实际下载速度 12.5 MB/s
- **数据库索引**：存储开销取决于数据类型大小
- **超时配置**：混用毫秒与秒是常见的 bug 来源
