# 压缩包工具 — 技术背景

这个工具用 **libarchive** 的 WASM 版本在浏览器里直接解压和创建压缩包。支持三种容器格式：**ZIP**、**TAR** 和 **7Z**。整个过程在本地完成，文件不上传。

## 能做什么

- **解压**：打开一个压缩包，列出里面的条目，可以单个提取，也可以一次性全部提取。加密的包可以填密码解锁。
- **创建**：把多个文件打包成一个压缩包，可选容器格式和压缩算法。

## 压缩算法

创建压缩包时可选多种压缩算法（取决于容器格式是否支持）：

- **deflate**：ZIP / 7Z 默认，通用且兼容性好。
- **store**：不压缩，仅打包（适合已经压缩过的文件，比如图片合集）。
- **gzip / bzip2 / xz / zstd / lz4**：不同速度与压缩率的组合，xz 压得最小但最慢，lz4 最快但压得少。

## 为什么解压有大小限制

libarchive 在 WASM 线性内存里展开归档内容：压缩包本身、解压后的内容、以及单条目缓冲会同时驻留。压缩比很高的包（比如大量重复文本）解压后可能膨胀数倍。所以工具按包体积保守设了阈值：

- **安全上限 2GB**：超过直接拦下。
- **提醒阈值 1GB**：超过提示解压后可能占用大量内存。

## 隐私

压缩包和里面的文件都在你的浏览器里处理，不会上传到任何服务器。这一点在处理敏感文档时尤其重要。
