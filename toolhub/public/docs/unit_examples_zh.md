# 单位换算器 — 使用示例

## 长度

| 输入 | 单位 | 结果 |
|---|---|---|
| 100 | 千米 | 62.137 英里 |
| 1 | 英里 | 1.60934 千米 |
| 6 | 英尺 | 1.8288 米 |
| 100 | 厘米 | 39.3701 英寸 |

## 质量

| 输入 | 单位 | 结果 |
|---|---|---|
| 70 | 千克 | 154.324 磅 |
| 1 | 磅 | 453.592 克 |
| 500 | 克 | 0.5 千克 |

## 温度

| 输入 | 单位 | 结果 |
|---|---|---|
| 100 | °C | 212 °F |
| 32 | °F | 0 °C |
| 0 | °C | 273.15 K |
| 98.6 | °F | 37 °C（人体体温） |

## 速度

| 输入 | 单位 | 结果 |
|---|---|---|
| 60 | 英里/时 | 96.561 千米/时 |
| 100 | 千米/时 | 62.137 英里/时 |
| 1 | 节 | 1.852 千米/时 |
