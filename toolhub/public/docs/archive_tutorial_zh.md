# 压缩包工具 — 使用教程

工具分两个模式：**解压** 和 **创建**，用顶部的单选切换。

## 解压一个包

1. 切到「解压」模式，上传一个 `.zip` / `.tar` / `.7z` 文件。
2. 如果包设了密码，在密码框里填上——留空会先试一次，失败再提示你输密码。
3. 点「打开压缩包」，工具列出所有条目（文件名、大小、修改时间）。
4. 点某一条目右侧的「提取」只取那一个，或点顶部「全部提取」一次性下载所有文件。

> 浏览器可能拦截批量下载，全部提取时各文件之间会留一点间隔。

## 创建一个包

1. 切到「创建」模式，上传一个或多个文件（可多次添加，用 ✕ 删除）。
2. 选容器格式：**ZIP** / **TAR** / **7Z**。切换格式会自动套用默认压缩算法和扩展名。
3. 选压缩算法：deflate / store / gzip / bzip2 / xz / zstd / lz4。
4. 填输出文件名（也可留默认）。
5. 点「创建压缩包」，完成后下载。

## 大小限制

- 解压的包超过 **2GB** 会被拦下；超过 **1GB** 会先警告。

## 小提示

- 只是把一堆图片打包分发，用 **store**（图片本身已压缩，再压没意义，还快）。
- 要最小体积且对方用 7-Zip，用 **7Z + xz**。
- 要通用兼容（Windows 资源管理器也能开），用 **ZIP + deflate**。
