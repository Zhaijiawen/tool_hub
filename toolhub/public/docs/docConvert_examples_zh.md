# 文档格式转换 — 使用示例

## 把 Markdown 笔记转成 Word 交出去

**输入：** 粘贴文本，一份会议记录
**操作：** 来源 markdown → 目标 docx
**输出：** `out.docx`，可直接用 Word / WPS 打开

同事只认 Word 的场景。全程本地，稿件不用先传到哪里。

## 把别人的 Word 文档拉回 Markdown 维护

**输入：** 上传 `spec.docx`
**操作：** 上传文件，来源自动识别为 docx → 目标 markdown
**输出：** 屏幕显示 Markdown 文本，可复制进仓库

想要把历史文档迁移到 Git 管理时很省事。

## 做一本 EPUB 电子书

**输入：** 粘贴文本，若干章节的 Markdown
**操作：** markdown → epub，勾选「自动生成目录」
**输出：** `out.epub`，可导入 Kindle / 多看 / Apple  Books

目录会依据标题层级自动生成。

## 从 docx 里把图片抠出来

**输入：** 上传 `report.docx`（内含 3 张图）
**操作：** docx → markdown，勾选「提取内嵌图片」
**输出：** Markdown 文本 + `media.zip`（3 张原图）

转换结果里图片引用指向压缩包内路径，把 `media.zip` 解压到同目录即可看到完整图文。

如果源文档本来没有图片，界面会提示「没有检测到内嵌图片」且不生成压缩包——这是正常提示。

## 网页内容存成纯文本

**输入：** 粘贴一段 HTML 源码
**操作：** html → plain
**输出：** 去掉所有标签的纯文本

适合把复制来的网页内容清洗成可读文本。

## LaTeX 论文转成网页预览

**输入：** 上传 `paper.tex`
**操作：** latex → html，勾选「生成独立文档」
**输出：** 完整 HTML 文件，可直接双击打开

给不装 LaTeX 的同事看稿子时用。
