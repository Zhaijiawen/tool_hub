# Text Reversal — Examples

## Palindrome Check

**Input:** `racecar`
**Reversed:** `racecar`
→ It's a palindrome!

**Input:** `hello`
**Reversed:** `olleh`
→ Not a palindrome.

## Reverse a Sentence

**Input:**
```
JavaScript is awesome
```
**Reverse Words Output:**
```
awesome is JavaScript
```
