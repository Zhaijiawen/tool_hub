# SSL 证书解析 — 使用教程

## 模式一：粘贴 PEM 证书

### 获取证书

**方式一：浏览器**
1. 点击地址栏锁形图标 → 「连接安全」→ 「证书详情」
2. 在证书弹窗中找到「导出」或「复制 PEM」

**方式二：命令行（openssl）**
```bash
openssl s_client -connect example.com:443 -showcerts 2>/dev/null \
  | openssl x509 -outform PEM
```

**方式三：下载 .pem / .crt 文件**
直接打开文本文件，内容以 `-----BEGIN CERTIFICATE-----` 开头。

### 粘贴与解析

1. 将 PEM 内容粘贴到文本框
2. 工具自动识别并开始解析（或点击「解析证书」手动触发）
3. 查看解析结果

---

## 模式二：域名查询

1. 切换到「域名查询」标签
2. 输入域名（如 `github.com`，无需填写 `https://`）
3. 点击「查询」
4. 工具通过 crt.sh CT 日志获取该域名的最新证书并自动解析

> **注意**：此功能需要网络连接，并且会通过 crt.sh 获取公开证书记录。

---

## 读取解析结果

| 字段 | 说明 |
|------|------|
| Subject | 证书主体，重点关注 CN |
| Issuer | 颁发机构，如 Let's Encrypt、DigiCert |
| 序列号 | 唯一标识，用于吊销检查 |
| 有效期 | 红色=已过期，橙色=30天内到期，绿色=正常 |
| SAN | 证书覆盖的所有域名，检查是否包含目标域名 |
| SHA-256 指纹 | 用于证书锁定，与浏览器展示的指纹比对 |

---

## 检查证书是否即将过期

顶部状态横幅会显示：
- 🔴 **证书已过期**
- 🟡 **证书即将过期（剩余 N 天）**（≤30 天时警告）
- 🟢 **证书有效（剩余 N 天）**
