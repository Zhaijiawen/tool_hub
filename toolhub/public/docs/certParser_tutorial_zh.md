# SSL 证书解析 — 使用教程

工具提供两种模式：直接粘贴 PEM 证书，或者输入域名自动拉取。

## 模式一：粘贴 PEM 证书

你得先拿到证书内容。三种获取方式：

**浏览器获取 —** 点击地址栏的小锁图标，找到「连接安全」或「证书详情」，里面有导出或复制 PEM 的选项。各浏览器菜单位置略有不同，但都在锁图标下面。

**命令行 openssl —**

```bash
openssl s_client -connect example.com:443 -showcerts 2>/dev/null \
  | openssl x509 -outform PEM
```

连上服务器直接吐出 PEM，想保存的话管道到文件就行。

**从 .pem 或 .crt 文件 —** 用文本编辑器打开，看到 `-----BEGIN CERTIFICATE-----` 就对了。

拿到内容后粘贴到文本框，工具会自动识别并解析。如果没触发自动解析，点一下「解析证书」按钮。

## 模式二：域名查询

切换到「域名查询」标签，输入域名（比如 `github.com`，不用加 `https://`），点「查询」。工具会通过 crt.sh 的 CT 日志接口获取该域名最新签发的证书。

这个操作需要联网，因为要调 crt.sh 的 API。只会获取公开的证书记录，不涉及任何隐私数据。

## 怎么看结果

| 字段 | 重点看什么 |
|------|-----------|
| Subject | CN 值是最主要的身份标识 |
| Issuer | 签发机构，比如 Let's Encrypt、DigiCert、Google Trust Services |
| 序列号 | 唯一编号，查吊销时用 |
| 有效期 | 绿色正常，橙色 30 天内到期，红色已过期 |
| SAN | 确认你的目标域名是否在列表里 |
| SHA-256 指纹 | 做证书锁定时和浏览器展示的指纹对比 |

顶部有状态横幅：已过期显示红色，30 天内到期显示橙色（带剩余天数），正常显示绿色。
