# Text Case Conversion — Usage Tutorial

## Getting Started

The Text Case Conversion tool allows you to quickly convert text between different capitalization styles with a single click.

## Step-by-Step Guide

### Step 1: Enter Your Text
Paste or type the text you want to convert into the input area. The tool supports multi-line text.

### Step 2: Choose a Conversion Style
Click one of the conversion buttons:
- **UPPERCASE** — converts all letters to uppercase
- **lowercase** — converts all letters to lowercase
- **Title Case** — capitalizes the first letter of each word
- **Sentence Case** — capitalizes only the first letter of the text
- **aLtErNaTiNg** — alternates uppercase and lowercase for each character

### Step 3: Copy the Result
The converted text appears in the output area. Click **Copy** to copy it to your clipboard.

### Step 4: Clear and Start Over
Click **Clear** to reset both input and output areas.

## Tips

- Multi-line text is fully supported; each line is processed independently where applicable.
- Title Case and Sentence Case handle punctuation and line breaks correctly.
- The tool preserves numbers, spaces, and special characters unchanged.
