# Text Case Converter -- How to Use

Drop text in, pick a style, grab the result. That's pretty much it, but let's walk through the details.

## Quick Workflow

Paste or type your text into the input area. Multi-line text is fine -- the tool handles it properly. Then click one of the conversion buttons and the output appears instantly.

Here's what each button does:

- **UPPERCASE** -- EVERYTHING BECOMES CAPITALS. Useful for constants, acronyms, or when you need text to be LOUD.
- **lowercase** -- everything goes to lowercase. Good for normalizing user input, preparing URL slugs, or cleaning up inconsistently capitalized text.
- **Title Case** -- Capitalizes The First Letter Of Each Word. Handy for headings, button labels, and proper names.
- **Sentence case** -- Just the first letter of the whole text gets capitalized, the rest stays lowercase. Good for turning all-caps text back into readable sentences.
- **aLtErNaTiNg** -- Flips case back and forth per character. Mostly for fun, but occasionally useful for obfuscating text.

Hit the **Copy** button to grab the result, or **Clear** to reset both fields.

## A Few Things to Know

- Multi-line input is processed correctly -- each line keeps its structure, only the case changes.
- Numbers, punctuation, and special characters pass through unchanged in all modes.
- Title Case and Sentence case handle punctuation intelligently -- a period or newline correctly triggers the next capital letter.
- If you're working with programming identifiers, the tool gives you the raw case conversion. It won't convert between naming conventions (snake_case to camelCase) -- you'll want a dedicated converter for that. What it does do is give you the building blocks: lowercase everything then you can add underscores for snake_case, or Title Case everything then remove spaces for PascalCase.
