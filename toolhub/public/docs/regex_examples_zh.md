# 正则表达式测试器 — 使用示例

## 示例 1：验证邮箱地址

**模式：** `^[\w.-]+@[\w.-]+\.[a-z]{2,}$`
**标志：** `i`

| 输入 | 匹配？ |
|---|---|
| `user@example.com` | ✅ |
| `user.name+tag@domain.co` | ✅ |
| `user@domain` | ❌ |
| `@domain.com` | ❌ |

## 示例 2：提取所有数字

**模式：** `\d+`
**标志：** `g`
**输入：** `订单42包含3件商品，共计150.00元`
**匹配结果：** `42`, `3`, `150`, `00`

## 示例 3：匹配 ISO 日期

**模式：** `\b\d{4}-\d{2}-\d{2}\b`
**标志：** `g`
**输入：**
```
会议时间 2024-03-15，截止日期 2024-04-01。
```
**匹配结果：** `2024-03-15`, `2024-04-01`

## 示例 4：使用捕获组

**模式：** `(\w+)\s(\w+)`
**输入：** `John Doe`
**第 1 组：** `John`
**第 2 组：** `Doe`
