# 图片文字识别 (OCR) — 使用教程

1. 上传图片。工具显示预览和大小。
2. 在「语言」里选择要识别的语言（可多选）。中英混排就同时选 `chi_sim` 和 `eng`。首次选某语言会下载对应语言包。
3. 选「页面分割模式（PSM）」：大多数情况用默认的「自动」（3）即可；只识别一行文字就选单行模式。
4. 点「识别」。进度条先走下载、再初始化、最后识别。
5. 结果出现在文本框里，可直接修改；点「复制」或「下载」保存为 `.txt`。

> 结果区显示字符数、置信度和耗时。置信度低说明识别可能不准，建议核对原文。

## 小提示

- 截图前把图片放正、调高对比度，识别率明显更好。
- 只识别英文文档就只选 `eng`，别加用不到的语言，能快很多。
- 识别不出来？检查一下是不是手写体或分辨率太低。
