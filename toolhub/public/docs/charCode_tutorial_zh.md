# 字符编码转换器 — 使用教程

## 使用步骤

### 第一步：输入字符或字符串
在输入框中输入或粘贴一个字符或字符串，支持单字符和多字符字符串。

### 第二步：查看编码表示
工具即时显示字符的多种编码格式：
- **十进制**（Unicode 码点）
- **十六进制**
- **二进制**
- **HTML 实体**（十进制和十六进制）
- **URL 编码**
- **八进制**

### 反向查询
输入码点（如 `65`、`0x41` 或 `U+0041`），查找对应的字符。

## 支持的输入格式

| 格式 | 示例 | 字符 |
|---|---|---|
| 十进制码点 | `65` | `A` |
| 十六进制码点 | `0x41` 或 `41` | `A` |
| Unicode 表示法 | `U+0041` | `A` |
| HTML 实体 | `&#65;` 或 `&#x41;` | `A` |
| 字符 | `A` | → 各种编码 |

## 使用技巧

- 使用此工具识别不可见或特殊字符（零宽空格、BOM 等）
- 粘贴有编码问题的文本，逐字符检查码点
- 便于调试涉及 Unicode 字符的正则表达式
