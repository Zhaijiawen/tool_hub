# Unit Converter — Usage Tutorial

## How to Use

### Step 1: Select a Category
Choose the measurement category you want to convert:
- Length, Mass, Temperature, Area, Volume, Speed, Pressure, Energy, etc.

### Step 2: Enter the Value
Type the number you want to convert in the input field.

### Step 3: Select Input Unit
Choose the unit of your value from the "From" dropdown.

### Step 4: Select Target Unit
Choose the unit you want to convert to in the "To" dropdown.

### Step 5: Read the Result
The converted value appears instantly in the result field.

## Tips

- **Temperature** conversions use formulas (not simple multiplication), so they are handled separately
- You can swap the From/To units by clicking the swap button
- Results are rounded to a practical number of decimal places
- For very large or small values, the result may be shown in scientific notation
