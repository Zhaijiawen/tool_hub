# 文件哈希校验 - 使用教程

所有计算都在浏览器本地完成，文件不会被上传到任何服务器，数据不会离开你的设备。

## 怎么用

### 选文件

两种方式：把文件拖进上传区域，或者点击区域浏览选择。所有文件类型都支持。建议控制在 500MB 以内，更大的也能跑，就是等久一点。

### 等哈希计算跑完

丢文件进去后，工具自动开始计算四种哈希：

- **MD5** 走 spark-md5 库（SubtleCrypto 不支持 MD5）
- **SHA-1、SHA-256、SHA-512** 走浏览器的 Web Crypto API

有进度条显示。几个 GB 的大文件可能要等 10-30 秒，去倒杯水。

### 看结果

跑完之后大概长这样：

```
文件名：ubuntu-22.04-desktop-amd64.iso
文件大小：3.71 GB

MD5:    a435f6f393dda581172490eda9f683c1
SHA-1:  c396e956b6a69b3b17b05b78e37f6a5e8e4c37...
SHA-256: b5f2fec6e2d86da19ab7ea4b8df8afb4c7d2f0b8f...
SHA-512: 3c8b5b0e8a54d3b0e6b4e7b31f9d0e3a4c9e7c1f...
```

### 校验比对（可选）

如果你有软件官方给的哈希值，粘贴到校验框里。工具会根据哈希长度自动识别算法（32 字符 = MD5，40 = SHA-1，64 = SHA-256，128 = SHA-512），跟计算结果对比，显示绿色对勾或红色叉号。绿色说明文件没问题；红色说明可能损坏或者被篡改了。

## 实际工作流

**验证下载的安装包：** 下好文件，在厂商下载页找到 SHA-256 哈希值（通常在下载链接旁边），把文件拖进工具，粘贴官方哈希，确认绿色对勾。

**检查备份完整性：** 给备份文件算个哈希，把值记下来。半年后要恢复的时候再算一次，比对一下。哈希一致说明备份没坏。

**检测文件变动：** 部署前后对配置文件算哈希，不一样就说明改动了。土办法但实用。

## 速查：哈希长度

| 算法 | 输出 | 十六进制字符数 |
|------|------|--------------|
| MD5 | 128 位 | 32 |
| SHA-1 | 160 位 | 40 |
| SHA-256 | 256 位 | 64 |
| SHA-512 | 512 位 | 128 |

这就是工具自动识别哈希算法类型的依据 -- 数十六进制字符个数。

## 注意事项

全部计算在客户端完成，文件不会上传。超过 500MB 的文件耐心等待，分片读取省内存但吃 CPU。哈希比对不区分大小写 -- 大写、小写、混着写都当一样的。日常文件完整性校验用 SHA-256，MD5 和 SHA-1 只适合非安全场景的校验和，别拿来做安全校验。
