# 文件哈希校验 - 使用教程

## 快速开始

文件哈希校验工具在浏览器中本地计算文件的哈希值，文件不会被上传到任何服务器，保证数据隐私。

## 基本使用流程

### 步骤 1：选择文件

有两种方式选择文件：
- **拖放**：将文件直接拖入页面中的上传区域
- **点击选择**：点击上传区域，在文件对话框中选择文件

支持任意类型的文件，建议文件大小不超过 500MB。

### 步骤 2：等待计算完成

选择文件后，工具会自动开始计算所有哈希值：
- **MD5**：通过 spark-md5 库计算
- **SHA-1**：通过 Web Crypto API 计算
- **SHA-256**：通过 Web Crypto API 计算
- **SHA-512**：通过 Web Crypto API 计算

进度条会显示当前计算进度。大文件可能需要等待几秒到几十秒。

### 步骤 3：查看哈希值

计算完成后，页面显示各算法的哈希值，例如：

```
文件名：ubuntu-22.04-desktop-amd64.iso
文件大小：3.71 GB

MD5:    a435f6f393dda581172490eda9f683c1
SHA-1:  c396e956b6a69b3b17b05b78e37f6a5e8e4c37...
SHA-256: b5f2fec6e2d86da19ab7ea4b8df8afb4c7d2f0b8f...
SHA-512: 3c8b5b0e8a54d3b0e6b4e7b31f9d0e3a4c9e7c1f...
```

### 步骤 4：校验哈希值（可选）

如果你有官方提供的预期哈希值，可以在"校验比对"区域输入：

1. 在输入框中粘贴官方的哈希值
2. 系统自动识别算法类型（根据哈希长度）
3. 与计算结果对比，显示：
   - ✅ **绿色**：哈希匹配，文件完整
   - ❌ **红色**：哈希不匹配，文件可能损坏或被篡改

## 实际使用场景

### 验证软件下载

1. 从官方网站下载软件安装包
2. 在下载页面找到文件的 SHA-256 哈希值（通常在下载链接旁）
3. 将下载的文件拖入本工具
4. 将官方哈希值粘贴到校验框中
5. 确认是否匹配 ✅

### 验证数据备份完整性

将备份文件拖入工具，记录 SHA-256 值。下次需要验证备份时，再次计算并对比，确认备份未损坏。

### 检查文件是否被修改

对文件计算哈希值并记录。如果后续对比哈希值不同，说明文件内容已被更改。

## 哈希长度参考

| 算法 | 输出长度 | 十六进制字符数 |
|------|---------|------------|
| MD5 | 128 位 | 32 个字符 |
| SHA-1 | 160 位 | 40 个字符 |
| SHA-256 | 256 位 | 64 个字符 |
| SHA-512 | 512 位 | 128 个字符 |

## 注意事项

1. **隐私安全**：所有计算在你的浏览器本地完成，文件内容不会离开你的设备
2. **大文件处理**：500MB 以上文件计算时间较长，请耐心等待
3. **算法选择**：
   - 日常文件完整性验证：SHA-256 足够
   - 安全场景（密码等）：不应使用 MD5 和 SHA-1
4. **大小写无关**：哈希值对比时不区分大小写
