# 二维码技术背景

## 概述

二维码（Quick Response Code）是二维矩阵条形码，可以存储各种类型的数据，包括文本、URL、联系信息和二进制数据。它们由Denso Wave于1994年开发，由于其高数据容量、纠错能力和易于扫描的特点，在现代数字应用中变得无处不在。

## 二维码结构和组件

### 基本结构

**定位图案**
- 三个相同的定位图案位于角落（左上、右上、左下）
- 7x7模块，具有3x3内部和外部定位图案
- 用于方向检测和位置参考

**对齐图案**
- 在较大二维码（版本2+）中使用的小型定位图案
- 帮助在不同尺寸打印时保持代码可读性
- 根据版本基于数学公式定位

**时序图案**
- 沿水平和垂直轴的交替黑白模块
- 用于模块尺寸校准和坐标系建立
- 对准确数据提取至关重要

**数据和纠错码字**
- 实际编码数据和Reed-Solomon纠错码
- 组织成块，具有交错以提高错误恢复能力
- 受多种纠错级别保护

### 二维码版本

**版本系统**
- 40个版本（1-40），模块数量递增
- 版本1：21x21模块，版本40：177x177模块
- 每个版本每边增加4个模块

**容量计算**
- 数据容量因版本、纠错级别和编码模式而异
- 版本40，L级别：最多2,953字节
- 版本40，H级别：最多1,273字节

## 编码模式数据类型

### 数字模式
- 仅编码数字0-9
- 数字数据最高效的编码
- 每3个数字10位（每个数字3.33位）

### 字母数字模式
- 编码数字0-9、大写A-Z和9个特殊字符
- 每2个字符11位（每个字符5.5位）
- 常用于URL和基本文本

### 字节模式
- 编码任何8位数据（ISO-8859-1、UTF-8等）
- 每个字符8位
- 最灵活但效率最低

### 汉字模式
- 编码日文汉字字符（Shift JIS）
- 每个字符13位
- 针对日文文本优化

### 结构化附加
- 将数据分割到多个二维码中
- 最多16个二维码序列
- 每个代码包含序列信息

## 纠错系统

### Reed-Solomon纠错

**数学基础**
- 基于有限域算术（伽罗瓦域GF(2^8)）
- 使用多项式除法和求值
- 可以纠正最多一半的纠错码字

**纠错级别**
- **L级别（低）**：7%恢复容量
- **M级别（中）**：15%恢复容量
- **Q级别（四分之一）**：25%恢复容量
- **H级别（高）**：30%恢复容量

**实现过程**
1. 数据编码为码字
2. Reed-Solomon多项式生成
3. 纠错码字计算
4. 数据和纠错交错

### 纠错权衡

**容量与可靠性**
- 更高的纠错减少数据容量
- H级别提供最大可靠性但最小容量
- L级别提供最大容量但最小可靠性

**用例考虑**
- **L级别**：清洁环境，大打印尺寸
- **M级别**：通用目的，平衡方法
- **Q级别**：挑战环境，较小尺寸
- **H级别**：损坏或部分遮挡的代码

## 数据编码过程

### 步骤1：模式选择
- 分析输入数据以确定最佳编码模式
- 考虑数据类型、长度和效率
- 可能对混合内容使用多种模式

### 步骤2：字符计数指示符
- 数据长度的二进制表示
- 位长度因版本和模式而异
- 对正确解码至关重要

### 步骤3：数据编码
- 根据选定模式将数据转换为二进制
- 处理混合内容的模式切换
- 确保正确的位对齐

### 步骤4：所需填充
- 添加填充位以填充剩余容量
- 使用交替的0和1以获得最佳扫描效果
- 确保总位数匹配码字要求

## 掩码和优化

### 掩码模式

**目的和功能**
- 与预定义模式的XOR操作
- 减少有问题的模式（全白/黑区域）
- 提高扫描可靠性和视觉平衡

**八种标准模式**
- 模式0：(行 + 列) mod 2
- 模式1：行 mod 2
- 模式2：列 mod 3
- 模式3：(行 + 列) mod 3
- 模式4：(floor(行/2) + floor(列/3)) mod 2
- 模式5：((行 * 列) mod 2) + ((行 * 列) mod 3)
- 模式6：(((行 + 列) mod 2) + ((行 * 列) mod 3)) mod 2
- 模式7：(((行 + 列) mod 2) + ((行 + 列) mod 3)) mod 2

### 惩罚评分

**评估标准**
- **规则1**：相同颜色的相邻模块
- **规则2**：相同颜色的2x2块
- **规则3**：特定模式（1:1:3:1:1比率）
- **规则4**：暗模块比率（应接近50%）

**模式选择**
- 应用所有8种掩码模式
- 计算每种模式的惩罚分数
- 选择惩罚最低的模式

## 高级功能

### 微型二维码
- 用于有限空间应用的较小版本
- M1-M4版本，容量减少
- 单个定位图案，无对齐图案

### 模型2二维码
- 标准二维码规范
- 包括所有功能：定位图案、对齐图案、时序图案
- 完整纠错和掩码支持

### 结构化附加
- 多个二维码协同工作
- 序列号和总数
- 适用于大型数据集

- 日本工业标准
- Denso Wave的原始规范
- 国际标准的基础
