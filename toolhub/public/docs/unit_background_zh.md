# 单位换算器 — 技术背景

单位换算这事，听起来简单到不值一提，但当你面对一个全公制的菜谱而手边全是英制量杯的时候，或者想知道 100 km/h 在德国高速上够不够用的时候，就没那么简单了。换算器涵盖长度、质量、温度、面积、体积、速度、压强、能量、功率、数据存储和时间——基本上专业工程工具以外的日常换算需求全包了。

## 度量体系

你反复碰到的其实是两套体系：

**SI（国际单位制/公制）**是全世界大多数国家和科学界使用的体系。基本单位是米（长度）、千克（质量）、秒（时间）、开尔文（温度）。其他单位都从这些派生出来。公制的优雅之处在于所有单位按 10 的幂次缩放——千代表 1,000，厘代表 1/100，诸如此类。没有奇怪的换算比例需要死记。

**英制/美制**是美国、利比里亚和缅甸在用的体系。比较混乱：12 英寸一英尺、3 英尺一码、1,760 码一英里。这些数字跟 10 的幂次毫无关系。但这一套体系不会消失——美国的菜谱、建筑、限速标志全是英制。

换算器在所有类别上支持双向转换，你不用记住一磅等于 453.592 克或者一英亩是 4,047 平方米。

## 温度比较特殊

大多数单位换算只是乘以一个常数——1 英寸 = 2.54 厘米，永恒不变。温度不一样。摄氏和华氏的零点不同（水在 0degC 结冰但在 32degF 结冰），所以换算需要加上偏移量：

- degF = (degC x 9/5) + 32
- degC = (degF - 32) x 5/9

开尔文以绝对零度（-273.15degC）为零点，所以 K = degC + 273.15。摄氏和开尔文之间不用乘法——它们用同样的「度的大小」，只是起点不同。

这就是为什么换算器把温度单独处理的原因。不能只是乘以一个比例就完事。

## 常用换算因子

你实际会用到的那些：

| 类别 | 从 | 到 | 换算 |
|---|---|---|---|
| 长度 | 英寸 | 厘米 | x 2.54 |
| 长度 | 英里 | 千米 | x 1.60934 |
| 长度 | 英尺 | 米 | x 0.3048 |
| 质量 | 磅 | 千克 | x 0.453592 |
| 质量 | 盎司 | 克 | x 28.3495 |
| 体积 | 美制加仑 | 升 | x 3.78541 |
| 体积 | 美制杯 | 毫升 | x 236.588 |
| 速度 | 英里/时 | 千米/时 | x 1.60934 |
| 速度 | 节 | 千米/时 | x 1.852 |
| 面积 | 英亩 | 平方米 | x 4046.86 |
| 面积 | 平方英尺 | 平方米 | x 0.092903 |
| 数据 | GB | GiB | x 0.931323 |

等下，最后那个——GB 和 GiB 还不一样？没错。硬盘厂商用的是十进制千兆字节（1 GB = 10^9 字节），而操作系统按二进制吉比字节显示（1 GiB = 2^30 字节 = 1,073,741,824 字节）。这就是为什么你买的「1 TB」硬盘在 Windows 里显示是 931 GB。换算器两种都支持，你可以验证自己没被坑（确实没被坑——只是用了不同的单位）。

## 代价高昂的换算事故

火星气候探测器（1999 年）——一颗价值 1.25 亿美元的航天器——在火星大气层中烧毁，因为洛克希德·马丁的导航软件输出的推力数据是磅力·秒（英制），而 NASA 喷气推进实验室期望的是牛顿·秒（公制）。飞行器以偏低了 57 公里的高度进入大气层，解体了。

1983 年，加拿大航空 143 号航班飞行途中耗尽燃油，因为地勤用磅代替公斤计算了加油量——飞机实际只有所需燃油的一半。飞行员设法将飞机滑翔到曼尼托巴省吉姆利的一条废弃跑道上紧急迫降。这件事现在被称为「吉姆利滑翔机」。

这些不是冷知识——它们说明单位换算器不是可有可无的工具。把换算做对，真的很重要。
