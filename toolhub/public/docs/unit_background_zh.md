# 单位换算器 — 技术背景

## 什么是计量单位？

计量单位是某个量的特定量值，通过约定或法律定义并采用，作为测量的标准。科学和工程工作依赖准确的单位换算来避免错误。

## 测量体系

### SI（国际单位制）
现代公制系统，被科学界和全球大多数国家使用：
- 长度：米（m）
- 质量：千克（kg）
- 温度：开尔文（K）、摄氏度（°C）
- 时间：秒（s）

### 英制 / 美制
仍在美国等少数国家使用：
- 长度：英寸（in）、英尺（ft）、码（yd）、英里（mi）
- 质量：盎司（oz）、磅（lb）、吨
- 温度：华氏度（°F）

## 各类别概览

### 长度
`1 英里 = 1.60934 千米`
`1 英寸 = 2.54 厘米`
`1 英尺 = 30.48 厘米`

### 质量 / 重量
`1 磅 = 453.592 克`
`1 千克 = 2.20462 磅`

### 温度
- 摄氏转华氏：`°F = (°C × 9/5) + 32`
- 华氏转摄氏：`°C = (°F − 32) × 5/9`
- 摄氏转开尔文：`K = °C + 273.15`

### 面积
`1 英亩 = 4,047 m²`
`1 公顷 = 10,000 m²`

### 体积
`1 美制加仑 = 3.78541 升`
`1 升 = 1,000 cm³`

### 速度
`1 英里/时 = 1.60934 千米/时`
`1 海里/时（节）= 1.852 千米/时`

## 著名单位换算失误

**火星气候探测器**（1999年）迷失，原因正是一个团队使用公制单位而另一个团队使用英制单位，导致飞船以错误角度进入大气层。
