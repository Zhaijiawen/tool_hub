# 图片转 SVG：原理与背景

## 为什么需要把图片转成 SVG

位图（PNG / JPG / WebP）由像素构成，放大到一定程度就会失真、出现锯齿与马赛克。SVG 是矢量格式，用数学曲线描述图形，因此在任意尺寸下都能保持锐利，文件体积通常也更小，色彩还能在后期随意修改。

常见的转换需求包括：

- 把散落的 Logo 草图变成可复用的矢量素材
- 将手写签名、印章扫描件用于电子文档
- 提取图案线条供激光切割、刻字、数控雕刻使用
- 让图标在高清屏与大幅印刷中保持清晰

## 本站做的是「追踪」而不是「魔法还原」

需要明确一点：**把位图变成矢量是有损的信息重建过程**，不存在"一键完美还原"的技术。

本站采用的是 **Potrace** 算法 —— 一个经典的位图追踪（bitmap tracing）引擎，由 Peter Selinger 开发，以 GPL-2.0 授权开源。它的工作方式可以概括为三步：

1. **二值化**：把图像按亮度拆成纯粹的黑白两色
2. **路径提取**：识别黑色区域的边界轮廓
3. **曲线拟合**：用直线段与贝塞尔曲线逼近这些轮廓，输出 SVG 路径

由于 Potrace 是**单色（monochrome）**追踪引擎，它只能表达"有"和"无"两种状态。这意味着：

- ✅ **适合**：Logo、图标、签名、线稿、拓印图案、图表线框 —— 本身黑白分明、边界清晰的图像
- ❌ **不适合**：彩色照片、渐变背景、写实插画 —— 会被强制压成黑白轮廓，结果通常是无法使用的色块堆积

如果只需要"把照片变清晰"，那属于超分辨率（超分）范畴，与本工具的技术路线不同。

## 核心技术参数：阈值与反色

由于算法在二值化阶段就要做取舍，本站把最关键的两个控制权交给了用户：

**黑白阈值（0–255）**
系统会计算每个像素的亮度，亮度**低于**阈值的像素被涂黑并成为 SVG 中的图形，高于阈值的则变为白色背景。
- 阈值调**高**：更多像素被判为深色 → 描摹区域变大、线条变粗
- 阈值调**低**：只有非常深的像素才被保留 → 线条纤细，浅色笔迹容易丢失

**反色**
Potrace 默认以「深色为前景」。所以：
- 白底黑线的稿件 → 保持**关闭**
- 黑底白线的稿件 → 需要**开启**，把深浅关系翻转

这两个参数决定了输出成败，比任何事后处理都重要。

## 关于 SVG 的填充规则

Potrace 在输出带"洞"的图形（例如一个黑色方框中间挖空一个圆）时，使用多条闭合子路径来表达。经实际浏览器渲染验证，其输出的路径方向已天然适配 SVG 默认的 `nonzero` 填充规则，挖空效果正确，无需额外修改 `fill-rule`。

## 隐私与技术说明

- 图片上传后**不会离开你的设备**，全部处理在浏览器本地完成，无需联网也能使用（首次加载页面后）
- 矢量化引擎来自 `potrace-wasm`，是 Potrace 的 WebAssembly 移植版本，wasm 已内联在代码包中（约 230KB），不会向第三方 CDN 请求任何资源
- 处理宽度可选原图尺寸或限制为 1600 / 1000 / 600 px —— 追踪算法耗时随像素面积增长，缩小处理宽度能显著加快速度
- 透明区域会自动按白底处理，避免 PNG 的透明像素被误判成黑色块
- 许可证：Potrace 为 GPL-2.0，`potrace-wasm` 移植版本同样遵循该许可；完整的许可声明与源代码获取方式见站点「开源许可」页面
