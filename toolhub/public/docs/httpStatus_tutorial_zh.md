# HTTP 状态码参考 — 使用教程

## 使用步骤

### 按状态码搜索
在搜索框中输入状态码（如 `404`、`500`），查看其含义、类别和说明。

### 按关键词搜索
输入关键词（如 "redirect"、"unauthorized"、"timeout"）查找所有匹配的状态码。

### 按类别浏览
按类别（1xx、2xx、3xx、4xx、5xx）筛选列表，查看该分组内的所有状态码。

## 快速参考

| 我想要... | 常用状态码 |
|---|---|
| 告知客户端请求成功 | `200 OK` |
| 告知客户端资源已创建 | `201 Created` |
| 永久重定向 | `301 Moved Permanently` |
| 告知客户端请求无效 | `400 Bad Request` |
| 要求登录 | `401 Unauthorized` |
| 拒绝访问 | `403 Forbidden` |
| 返回页面不存在 | `404 Not Found` |
| 告知客户端请求过于频繁 | `429 Too Many Requests` |
| 通知未处理的服务器错误 | `500 Internal Server Error` |
| 通知服务不可用 | `503 Service Unavailable` |

## 使用技巧

- **401 vs 403**：用户未登录时用 401；已登录但权限不足时用 403
- **301 vs 302**：URL 永久更改用 301（对 SEO 友好）；临时重定向用 302
- **500 vs 502**：500 表示自身服务器故障；502 表示上游服务器返回错误
