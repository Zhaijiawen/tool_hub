# JSONPath 技术背景

## 什么是 JSONPath？

JSONPath 是一种用于查询 JSON 文档的路径表达式语言，类似于 XPath 之于 XML。它由 Stefan Goessner 于 2007 年提出，被广泛应用于 API 测试（如 Postman）、日志分析、数据提取等场景。

## 语法速查表

| 表达式 | 说明 |
|--------|------|
| `$` | 根节点 |
| `.` | 子节点（点记法） |
| `..` | 递归下行（任意深度） |
| `*` | 通配符（所有元素） |
| `[n]` | 数组下标（从0开始） |
| `[start:end]` | 数组切片 |
| `[a,b,c]` | 多选 |
| `[?(@.key)]` | 过滤：存在某字段 |
| `[?(@.price<10)]` | 过滤：条件判断 |
| `@` | 当前节点（用于过滤器中） |

## 示例

| 表达式 | 含义 |
|--------|------|
| `$.store.book[*].author` | 所有书的作者 |
| `$..author` | 任意位置的 author 字段 |
| `$.store.book[0,1]` | 第一和第二本书 |
| `$.store.book[?(@.isbn)]` | 有 isbn 字段的书 |
| `$.store.book[?(@.price < 10)]` | 价格低于10的书 |

## 本工具使用的库

基于 `jsonpath-plus`（npm），支持完整的 JSONPath 语法规范，并扩展支持 `@path`、`@property` 等增强特性。
