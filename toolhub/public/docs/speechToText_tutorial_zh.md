# 语音转文字 — 使用教程

上传音频或视频文件，选择任务，得到文字。首次使用会下载引擎和模型（约 52MB，带进度与取消）；之后全部走缓存。

## 转写：保持原语言

1. 上传音频文件（MP3 / WAV / M4A / OGG / Opus / FLAC）或带音轨的视频
2. 任务选择 **转写**
3. 语言留 **自动检测**，或已知语言时手动指定
4. 点击 **开始识别**

输出为原语言文本。日语录音得到日语文字，英语得到英语。

## 翻译：任意语言转英文

步骤相同，任务改为 **翻译为英文**。无论说什么语言，输出都是英文文本。典型场景：从外语视频、播客中抽取英文字幕。

## 时间戳与字幕

打开 **片段时间戳**，转写结果下方会显示每段的时间码。开启时间戳后可下载 **SRT**——标准字幕文件，可直接放入任意播放器或视频剪辑软件：

```
1
00:00:00,000 --> 00:00:04,320
And so my fellow Americans, ask not

2
00:00:04,320 --> 00:00:07,480
what your country can do for you
```

未开时间戳也可以下载纯文本 **TXT**。

## 实时中间结果

打开 **实时中间结果**，每个 30 秒分块处理时中间文字会持续回流。长录音场景实用——不必等整段跑完就能开始阅读（或提前中止）。

## 选项说明

**语言**——超过约 10 秒的片段自动检测效果良好。过短的片段可能误判，不确定时手动指定。提供 12 种语言（中、英、日、韩、法、德、西、俄、意、葡、荷、土耳其语）。

**取消**——进度旁的按钮可中止下载与推理。已处理的分块会被丢弃，下次从头开始。

## 预期表现

- **首次运行**：下载约 52MB（引擎约 10.5MB + 模型约 41.6MB），随后开始推理
- **速度**：约为实时的 1–3 倍——10 分钟音频通常几分钟内完成
- **保持标签页前台**：浏览器会限制后台标签，推理随之变慢

## 建议

- 音频嘈杂？可先用站内「音视频工具箱」提取干净音轨，或用「音频转换器」去掉视频、统一格式
- 专有名词、行话、数字是 tiny 模型最弱的地方——预留一遍校对
- 追求准确率请使用近麦录制的文件；会议室远场录音衰减明显
