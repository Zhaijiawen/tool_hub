# Storage & Time Converter — Usage Tutorial

## How to Use

### Step 1: Select the Conversion Type
Choose whether you want to convert **Storage** units or **Time** units.

### Step 2: Enter the Value
Type the numeric value you want to convert in the input field.

### Step 3: Select Input Unit
Choose the unit of your input value from the dropdown (e.g., GB, MB, seconds, minutes).

### Step 4: View All Conversions
The tool displays the equivalent values in all other units simultaneously, making it easy to compare.

## Storage Conversion Examples

| Input | Output |
|---|---|
| `1 GB` | `1,000 MB` / `1,024 MiB` / `8,000,000,000 bits` |
| `1 TiB` | `1.0995 TB` / `1,099,511,627,776 bytes` |
| `100 Mbps` | `12.5 MB/s` actual speed |

## Time Conversion Examples

| Input | Output |
|---|---|
| `1 hour` | `60 min` / `3,600 s` / `3,600,000 ms` |
| `86400 seconds` | `1 day` / `24 hours` |
| `1 year` | `365 days` / `8,760 hours` |

## Tips
- For network speed, remember to divide Mbps by 8 to get MB/s
- Use this tool when configuring timeouts, cache TTLs, or token expiry
