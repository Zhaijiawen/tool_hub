# Number to Chinese — Examples

## Integer Examples

| Number | Uppercase | Lowercase |
|--------|-----------|-----------|
| 0 | 零 | 零 |
| 1 | 壹 | 一 |
| 10 | 壹拾 | 一十 |
| 100 | 壹佰 | 一百 |
| 1000 | 壹仟 | 一千 |
| 10000 | 壹万 | 一万 |
| 100000000 | 壹亿 | 一亿 |

## Financial Mode Examples

| Number | Financial Chinese |
|--------|-----------------|
| 0 | 零元整 |
| 1 | 壹元整 |
| 100.50 | 壹佰元伍角 |
| 1234.56 | 壹仟贰佰叁拾肆元伍角陆分 |
| 10000.01 | 壹万元零壹分 |
| 100000000 | 壹亿元整 |
| 123456789.99 | 壹亿贰仟叁佰肆拾伍万陆仟柒佰捌拾玖元玖角玖分 |

## Negative Number Examples

| Number | Uppercase |
|--------|-----------|
| -100 | 负壹佰 |
| -1234.56 | 负壹仟贰佰叁拾肆元伍角陆分 |
