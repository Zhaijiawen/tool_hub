# CSV/TSV 预览示例

实际会碰到的各种数据格式，以及工具如何处理。

## 标准 CSV（逗号分隔）

**粘贴以下内容，分隔符选"逗号"：**

```
姓名,部门,职位,入职日期
张三,工程部,高级工程师,2021-03-15
李四,产品部,产品经理,2020-07-01
王五,设计部,UI设计师,2022-01-10
```

**结果：**

| 姓名 | 部门 | 职位 | 入职日期 |
|---|---|---|---|
| 张三 | 工程部 | 高级工程师 | 2021-03-15 |
| 李四 | 产品部 | 产品经理 | 2020-07-01 |
| 王五 | 设计部 | UI设计师 | 2022-01-10 |

中规中矩的标准 CSV，四列三行数据。

## TSV（制表符分隔）

数据库导出常见格式。**分隔符选"Tab"：**

```
order_id	user_id	amount	status
10001	U1001	299.00	completed
10002	U1002	59.90	pending
10003	U1003	1299.00	refunded
```

制表符在大多数编辑器里不可见，所以 TSV 肉眼很难检查。预览工具让它一目了然。

## 含特殊字符的 CSV

**这才是考验解析能力的地方：**

```
name,address,note
Alice,"New York, NY","Works in finance,
part-time photographer"
Bob,Chicago,"Regular customer"
```

地址字段 `"New York, NY"` 里带逗号 -- 引号保护了它。Alice 的备注跨了两行 -- 同样因为引号包裹被正确处理。预览工具正确解析为两行数据，不会把跨行字段拆散。

## nginx 日志（空格分隔）

**分隔符选"空格"：**

```
127.0.0.1 - frank [10/Oct/2024:13:55:36 -0700] GET /index.html 200 2326
192.168.1.5 - - [10/Oct/2024:14:01:12 -0700] POST /api/login 401 128
```

空格分隔的日志比较棘手，因为方括号 `[...]` 里的时间戳包含空格。工具尽量处理，但复杂日志格式用专门的日志解析器效果更好。不过快速扫一眼还是够用的。

## 欧洲 Excel 导出（分号分隔）

欧洲很多国家的 Excel 用逗号当小数点，所以导出 CSV 时分号当分隔符：

**分隔符选"分号"：**

```
Produkt;Preis;Menge
Laptop;999,99;5
Maus;29,99;50
Monitor;349,00;10
```

注意 `999,99` -- 这是欧洲写法的 999.99。如果拿逗号当分隔符解析就全乱了。自动检测通常能正确识别。

## JSON 导出

解析示例 1 后点击复制：

```json
[
  { "姓名": "张三", "部门": "工程部", "职位": "高级工程师", "入职日期": "2021-03-15" },
  { "姓名": "李四", "部门": "产品部", "职位": "产品经理", "入职日期": "2020-07-01" },
  { "姓名": "王五", "部门": "设计部", "职位": "UI设计师", "入职日期": "2022-01-10" }
]
```

直接粘到代码里用。注意所有值都是字符串（CSV 没有类型信息），需要数字或日期的话自己转一下。
