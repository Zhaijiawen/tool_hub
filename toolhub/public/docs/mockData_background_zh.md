# Mock 数据生成 - 技术背景

## 什么是 Mock 数据

**Mock 数据**（模拟数据）是在开发和测试阶段用来代替真实数据的伪造数据。它具有与真实数据相同的结构，但内容是随机生成的，不含真实用户的敏感信息。

## 为什么需要 Mock 数据

### 前后端并行开发

前端开发通常需要真实的接口返回数据才能完成页面开发，但后端接口往往还未就绪。Mock 数据让前端无需等待后端：

```
后端还在开发：/api/users  →  使用 Mock 数据暂代
前端照常开发页面，联调时替换真实接口
```

### 测试场景覆盖

单元测试、集成测试都需要多种形态的输入数据，手写测试数据费时且容易遗漏边界情况。Mock 生成器可以：
- 批量生成边界值（如极长字符串、极大数值）
- 生成大量数据测试列表性能
- 覆盖多种状态组合（active/inactive/pending）

### 演示与展示

产品演示、UI 设计验收时，用真实用户数据存在隐私风险。Mock 数据让演示既直观又安全。

## 常见 Mock 数据方案对比

| 方案 | 代表工具 | 适用场景 |
|------|---------|---------|
| 代码生成库 | Faker.js、@faker-js/faker | 程序化批量生成 |
| 在线可视化 | 本工具、Mockaroo | 快速一次性生成 |
| Mock 服务器 | JSON Server、MSW | 完整 API Mock 服务 |
| 接口平台 | Apifox、RAP2 | 团队协作 Mock |

## JSON 数据格式基础

本工具生成标准 **JSON 数组**格式，每条记录为一个 JSON 对象：

```json
[
  {
    "id": 4512,
    "name": "张三",
    "email": "zhangsan@example.com",
    "status": "active",
    "tags": ["vue", "node"]
  },
  {
    "id": 7834
  }
]
```

这种格式可直接用于：
- 前端 `JSON.parse()` 解析
- 数据库批量导入（如 MongoDB `insertMany`）
- API Mock 服务器的静态数据文件

## 数据类型覆盖

一个完善的 Mock 数据应覆盖各种常见字段类型：

| 类别 | 示例字段 |
|------|---------|
| 标识符 | id、uuid |
| 个人信息 | 姓名、邮箱、手机号 |
| 时间 | 创建时间、更新时间 |
| 状态枚举 | status: active/inactive |
| 数值范围 | 价格、年龄、数量 |
| 复杂结构 | 嵌套地址对象、标签数组 |
