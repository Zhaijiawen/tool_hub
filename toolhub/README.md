# ToolHub

一个在线工具集合网站，提供各种实用的开发工具。

## 功能特点

- 格式化工具（JSON、XML、代码等）
- 加密工具（AES、RSA等）
- 转换工具（时间戳、进制等）
- 图片工具（压缩、转换等）
- 文本工具（大小写转换等）
- 其他实用工具

## 技术栈

- Vue 3
- Vite
- Naive UI
- Pinia
- Vue Router
- Vue I18n
- Axios
- js-beautify
- Prettier
- Highlight.js

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 国际化

支持中文和英文两种语言，可以通过界面切换。

## 主题

支持浅色和深色两种主题，可以通过界面切换。
